# 01. GitHub Copilot이란? — 비개발자 관점

## 학습 목표

- Copilot이 무엇이고, **무엇이 아닌지** 명확히 구분
- 비개발자 업무에서 Copilot이 시간을 절약하는 5가지 시나리오
- Copilot의 **한계**를 미리 알고 헛된 기대를 피하기

---

## 1.1 Copilot은 "AI 짝꿍(pair)"입니다

한 마디로: **여러분이 편집기에서 뭔가를 쓸 때, 옆에서 실시간으로 다음 내용을 제안하는 AI**입니다.

```
"짝꿍(pair)" 프로그래밍 → 짝꿍(pair) 작업
- 사람이 방향을 잡고
- AI가 반복적·기계적 부분을 채우고
- 사람이 최종 검토/승인
```

### Copilot ≠ ChatGPT

| 구분 | Copilot | ChatGPT |
|------|---------|---------|
| **어디서 쓰나** | VS Code, JetBrains 등 편집기 내부 | 브라우저, 별도 앱 |
| **뭘 알고 있나** | **여러분이 지금 열어놓은 파일의 맥락** | 대화창에 붙여넣은 것만 |
| **결과 형태** | 파일에 바로 삽입되는 텍스트/코드 | 대화 응답 |
| **강점** | 파일 편집, 코드/문서 생성, 반복 자동화 | 자유로운 대화, 이미지 분석 |
| **비용** | $10/월 (Individual) | 무료~$20/월 |

**포인트**: Copilot의 진짜 무기는 "**지금 편집 중인 파일의 맥락을 이해한다**"입니다. 이게 ChatGPT와 결정적으로 다른 점입니다.

---

## 1.2 비개발자가 Copilot을 쓰는 5가지 실전 시나리오

### 시나리오 1. 문서 작성 (전 직군)

**상황**: 신제품 소개 자료를 Markdown으로 만들어야 함

**Copilot 없이**: 목차부터 하나하나 타이핑, 표 구조 매번 헷갈림
**Copilot과 함께**:
```
[프롬프트]
신제품 "스마트 워치 X" 소개 자료 목차를 Markdown으로 만들어줘.
섹션: 개요, 주요 기능(표), 스펙(표), 경쟁 제품 비교(표), FAQ.
각 표는 3열 이상.
```
→ **30초 만에** 완성된 골격, 여러분은 내용만 채우면 됨.

### 시나리오 2. 엑셀 수식 / 데이터 정제 (재무·마케팅·오피스)

**상황**: 100개 셀에 "이름 (직급)" 형식으로 되어 있는데, 이름과 직급을 두 열로 분리해야 함

**Copilot 없이**: 인터넷에서 `LEFT`, `FIND`, `MID` 수식 검색, 조합 시도
**Copilot과 함께**:
```
[프롬프트]
A1 셀에 "김철수 (팀장)" 형식으로 들어있어.
이름만 B1에, 괄호 안 직급만 C1에 뽑는 엑셀 수식 각각 알려줘.
```
→ **바로 붙여넣기 가능한 수식**을 설명과 함께 제공.

### 시나리오 3. SQL로 데이터 뽑기 (마케팅·데이터·재무)

**상황**: 지난달 매출 상위 10개 상품을 DB에서 뽑아야 함

**Copilot 없이**: 개발자에게 요청 → 대기 → 결과 받음 (하루 소요)
**Copilot과 함께**:
```
[프롬프트]
테이블 orders(id, product_id, amount, created_at)와
products(id, name)가 있어.
지난달(2026-06) 매출 합계 기준 상위 10개 상품명과 매출액을 뽑는 SQL 짜줘.
```
→ **바로 실행 가능한 SQL**, 5초 후 결과. (BI 도구나 DBeaver 등에서 실행)

### 시나리오 4. 이메일 / HTML 템플릿 (영업·마케팅·CS)

**상황**: 뉴스레터 HTML 이메일 템플릿 필요

**Copilot 없이**: 웹에서 무료 템플릿 검색, 원하는 디자인 없음, 결국 텍스트 이메일
**Copilot과 함께**:
```
[프롬프트]
반응형 HTML 이메일 템플릿 만들어줘.
- 상단 로고, 배너 이미지 자리
- 본문 3섹션 (제목 + 이미지 + 설명)
- 하단 CTA 버튼, 회사 정보
- Gmail·Outlook 호환 (table 기반)
```
→ 붙여넣어서 사내 이미지 URL만 교체하면 발송 가능.

### 시나리오 5. 반복 업무 자동화 스크립트 (전 직군)

**상황**: 매일 아침 특정 폴더의 PDF 파일 이름을 "날짜_회사명_제목" 형식으로 일괄 변경

**Copilot 없이**: 수동으로 하나씩 이름 변경 (30분/일 × 20일 = 월 10시간)
**Copilot과 함께**:
```
[프롬프트]
Windows PowerShell 스크립트 짜줘.
- C:\Reports 폴더의 PDF들
- 파일 생성일자를 이용해서 "YYYYMMDD_원본파일명" 형식으로 rename
- 이미 날짜가 앞에 붙어있으면 건너뛰기
```
→ 스크립트 하나로 매일 30초에 끝남.

## 1.3 Copilot의 한계 (반드시 알고 시작)

| 한계 | 예시 | 대처 |
|------|------|------|
| **환각(Hallucination)** | 존재하지 않는 API·함수를 자신 있게 제안 | 항상 실행/검증. 특히 URL·통계 수치는 100% 확인 |
| **최신 정보 부족** | 2024년 이후 라이브러리 변경 반영 안 됨 | 공식 문서 링크로 재확인 |
| **회사 내부 정보 모름** | 사내 시스템·용어 이해 못 함 | Instruction 파일로 맥락 주입 (뒤에서 배움) |
| **긴 맥락에서 실수** | 파일 여러 개 걸치면 놓침 | 한 번에 한 파일·한 작업 |
| **정확한 계산 취약** | 큰 숫자 곱셈, 통계 등 | 계산은 엑셀·Python에게, Copilot은 수식·코드 생성만 |

**핵심 원칙**: Copilot은 **"초안 생성기"**입니다. **검증은 여러분의 몫**입니다.

---

## 1.4 이 커리큘럼에서 배우는 것과 배우지 않는 것

### ✅ 배우는 것
- 여러분 직군의 실전 업무에 Copilot을 어떻게 녹여 쓸 것인가
- 결과물 품질을 높이는 프롬프트 작성법
- AI 결과를 검증하는 습관
- 반복 업무를 자동화하는 스크립트/템플릿

### ❌ 배우지 않는 것
- 프로그래밍 언어 자체 (Python, JavaScript 등) 문법 심화
- 대규모 소프트웨어 아키텍처 설계
- ChatGPT나 M365 Copilot (별개 도구, 이 커리큘럼은 **GitHub Copilot** 전용)

## 실습

### 실습 1. 내 업무의 "Copilot 시나리오" 3개 적기

빈 종이나 메모장에 이렇게 적어보세요:

```
1. 내가 매주/매일 반복하는 업무: ________________
   → Copilot으로 자동화 가능한가? 어떻게?

2. 내가 자주 검색하는 것 (수식/템플릿 등): ________________
   → Copilot에게 물어보면 더 빠를까?

3. 내가 시간을 가장 많이 쓰는 문서 작업: ________________
   → Copilot이 초안을 만들어줄 수 있을까?
```

이 3개는 2일 과정을 마친 후 **실제로 자동화/개선**해볼 후보입니다.

### 실습 2. 짝꿍 인터뷰 (팀 워크숍인 경우)

옆 사람과 3분씩 서로에게:
- "어제 업무에서 가장 시간 오래 쓴 일이 뭐예요?"
- "그거 반복적인 부분이 있어요?"

→ 상대의 답을 듣고 "이 부분은 Copilot으로 초안이 나올 수 있겠네요"라고 제안해보기.

---

## 핵심 포인트

1. **Copilot ≠ ChatGPT**: 편집기 안에서, 여러분의 파일 맥락을 이해하며 동작
2. 비개발자에게 특히 강력: **문서, 수식, SQL, HTML 이메일, 스크립트** 5대 영역
3. **AI는 초안, 검증은 사람**의 원칙을 처음부터 몸에 배게 할 것
4. 이 커리큘럼은 **여러분의 진짜 업무를 재료로** 학습합니다
