# 03. Copilot 기본 사용법 — Tab / Chat / Inline Chat

## 학습 목표

- Copilot의 **3가지 상호작용 방식**을 구분해서 쓸 수 있다
- 각 방식이 **언제 유리한지** 판단 기준을 익힌다
- `@workspace`, `@terminal` 같은 **Chat 참여자(participant)**를 활용할 수 있다
- 파일·선택 영역을 **맥락(context)**으로 넘기는 법을 안다

**예상 소요**: 20분 (실습 포함 30분)

---

## 3.1 세 가지 상호작용 방식 개요

Copilot과 대화하는 방법은 3가지이며, 각각 **다른 상황에 최적**입니다.

| 방식 | 단축키 | 언제 쓰나 | 결과 형태 |
|------|--------|-----------|-----------|
| **Tab 자동완성** | `Tab` (수락) | 타이핑 중 다음 내용 자동 채움 | 회색 미리보기 → Tab으로 삽입 |
| **Inline Chat** | `Ctrl+I` (`Cmd+I`) | 특정 위치에 무언가를 삽입/수정 | 커서 위치에 코드/텍스트 삽입 |
| **Chat 사이드바** | `Ctrl+Alt+I` (`Cmd+Alt+I`) | 질문·설명·긴 대화 | 사이드바에 답변, 복사해서 사용 |

**한 문장 요약**
- **Tab** = 다음 줄이 뭘까? 예측해줘
- **Inline Chat** = 여기에 이런 걸 넣어줘
- **Chat** = 이거 어떻게 하는지 알려줘

---

## 3.2 Tab 자동완성 (Ghost Text)

### 어떻게 작동하나

여러분이 타이핑하는 동안, Copilot이 **다음 몇 줄**을 회색 글씨로 미리 보여줍니다.

```markdown
# 회의록: 2026-07-20

## 참석자
- 김철수 (팀장)
- 이영희 (개발자)
- █    ← 여기서 Copilot이 "박민수 (디자이너)" 같은 다음 항목 제안
```

- `Tab` → 수락
- `Esc` → 무시하고 계속 내가 타이핑
- `Alt + ]` / `Alt + [` → 다른 제안 보기

### Tab이 잘 발동되는 조건

Copilot은 **패턴을 인식**할 때 잘 뜹니다.

| 잘 됨 | 이유 |
|-------|------|
| 이미 몇 줄을 같은 형식으로 썼을 때 | 패턴이 명확 |
| 목록·표·JSON·CSV 같은 구조화된 형식 | 반복 패턴 |
| 파일 상단에 주석/제목으로 목적을 명시 | 맥락이 강함 |

| 잘 안 됨 | 이유 |
|----------|------|
| 완전히 새로운 파일의 첫 줄 | 맥락 부족 |
| 창의적인 문장 (마케팅 카피 등) | 정답이 없음 |
| 파일 형식이 특수함 (.xlsx 등) | 지원 안 됨 |

### 실전 예시 — 회의록 자동 완성

**입력**:
```markdown
# 마케팅 팀 주간 회의 - 2026-07-20

## 참석자
- 김철수 (마케팅 팀장)
- 이영희 (콘텐츠 담당)

## 안건
1. 지난주 캠페인 성과 리뷰
2.
```

**Tab 뜨는 것 예시**: `2. 이번 주 신규 캠페인 기획` — 여러분이 원하는 방향이면 Tab.

## 3.3 Inline Chat (`Ctrl+I`)

### 어떻게 작동하나

파일 안의 **특정 위치**에서 `Ctrl+I` → 작은 입력창 → **한글로 요청** → **미리보기** → Accept.

### 언제 쓰나

- "**여기**에 표 하나 삽입해줘"
- "이 문단 3줄로 요약해줘"
- "위의 목록을 Markdown 표로 바꿔줘"
- "이 SQL을 설명하는 주석 추가해줘"

**핵심**: Inline Chat은 **커서 위치가 곧 맥락**입니다.

### 실전 예시 — 선택 영역 변환

**Before**:
```markdown
회사에서 매일 아침 스탠드업을 한다. 각자 어제 한 일, 오늘 할 일,
막힌 부분을 공유한다. 시간은 15분 이내로 짧게 유지한다.
스탠드업은 서서 하는 것이 원칙이나 요즘은 앉아서 하기도 한다.
```

1. 위 문단을 **드래그로 선택**
2. `Ctrl+I` → 입력창에: `이 문단을 3개 항목의 불릿 리스트로 바꿔줘`
3. `Enter` → 미리보기:

```markdown
- 매일 아침 15분 이내의 스탠드업 진행
- 각자 어제 한 일, 오늘 할 일, 막힌 부분 공유
- 원칙은 서서 하지만 앉아서 진행하기도 함
```

4. 마음에 들면 **Accept**, 아니면 Discard.

### Inline Chat 잘 쓰는 팁

1. **선택 영역을 먼저 지정**하면 그 부분만 다룸 → 정확도 급상승
2. 프롬프트를 **명령형**으로: "요약해줘", "표로 바꿔줘", "번역해줘"
3. **형식을 명시**: "3줄로", "표로", "JSON으로"

## 3.4 Chat 사이드바 (`Ctrl+Alt+I`)

### 어떻게 작동하나

VS Code 우측(또는 좌측)에 채팅 사이드바가 열립니다. **긴 대화·설명·질문**에 적합.

### 언제 쓰나

- "**어떻게** 하는지 알려줘" (설명·튜토리얼)
- 여러 파일을 걸치는 질문 → `@workspace` 사용
- 터미널 명령어 물어보기 → `@terminal` 사용
- 결과를 **복사해서 다른 곳에 붙일** 때 (Inline Chat과 대비)

### 유용한 Chat 참여자(participant)

`@`로 시작해서 특별한 능력을 부여합니다.

| Participant | 역할 | 예시 |
|-------------|------|------|
| `@workspace` | 열린 폴더 전체를 뒤져서 답변 | "@workspace 매출 관련 파일 어디 있어?" |
| `@vscode` | VS Code 기능·단축키 안내 | "@vscode 정규식으로 찾아 바꾸기 어떻게 해?" |
| `@terminal` | 터미널 명령어 생성 | "@terminal 폴더 안 pdf만 zip으로 묶기" |

### 유용한 슬래시 명령

`/`로 시작하는 **미리 정의된 작업**입니다.

| 명령 | 하는 일 |
|------|---------|
| `/explain` | 선택한 코드·텍스트 설명 |
| `/fix` | 오류 수정 제안 |
| `/tests` | 테스트 케이스 생성 |
| `/doc` | 문서(주석) 생성 |
| `/new` | 새 프로젝트 초안 생성 |

### 실전 예시 — @workspace로 문서 찾기

폴더에 문서가 20개 있는데, "매출 리포트 관련 파일이 어디에 있는지" 모르겠다면:

```
@workspace 매출 리포트나 판매 분석 관련 파일 목록 알려줘
```

→ Copilot이 폴더를 뒤져서 관련 파일 목록 + 각 파일 간단 설명을 답해줍니다.

---

## 3.5 세 방식을 언제 어떻게 선택할까 — 결정 트리

```
질문 시작 →

  "지금 타이핑 중인데, 다음 줄 예측이면 좋겠다"
    → 그대로 계속 타이핑, Copilot이 알아서 회색으로 제안
    → Tab 자동완성 사용

  "지금 커서 위치에 뭔가 넣고 싶다" or "선택한 부분을 바꾸고 싶다"
    → Ctrl+I (Inline Chat) 사용

  "이거 어떻게 하는지 설명이 필요하다" or "여러 파일에 걸친 질문"
    → Ctrl+Alt+I (Chat 사이드바) 사용
```

## 3.6 맥락(Context)을 잘 주는 법

Copilot이 좋은 결과를 내는 핵심은 **얼마나 좋은 맥락을 주느냐**입니다.

### Context 소스 4가지

| 소스 | 얼마나 강한가 | 어떻게 활용 |
|------|---------------|-------------|
| **현재 파일 내용** | ★★★★★ | 파일 상단에 목적/규칙 주석으로 명시 |
| **선택 영역** | ★★★★★ | 대화 전에 관련 텍스트 드래그 |
| **열려 있는 다른 탭** | ★★★☆☆ | 관련 파일 미리 열어두기 |
| **`@workspace`** | ★★★★☆ | 전체 폴더 탐색이 필요할 때 |

### 실전 팁 — 파일 상단 "안내 주석"

Markdown이라면 이렇게 시작:

```markdown
<!--
목적: 신제품 스마트워치 X 마케팅 소개서
독자: 30~40대 여성, 헬스케어 관심층
톤: 친근하지만 신뢰감 있게
길이: A4 2페이지 분량
-->

# 스마트워치 X — 당신의 건강을 매일 곁에서
```

이렇게 해두면 이후 Tab 자동완성이 훨씬 정확해집니다.

## 실습

### 실습 1. Tab 자동완성 — 표 채우기

`practice.md` 파일을 만들고 다음까지 타이핑:

```markdown
# 직원 명단

| 이름 | 부서 | 직급 |
|------|------|------|
| 김철수 | 마케팅 | 팀장 |
| 이영희 | 개발 | 시니어 |
|
```

`|` 다음에 스페이스 → Tab 제안 확인 → 3~5명 더 자동완성으로 채워보기.

### 실습 2. Inline Chat — 형식 변환

같은 파일에 다음 문단 추가:

```
우리 팀의 주요 원칙은 첫째 사용자 우선, 둘째 데이터 기반 의사결정,
셋째 빠른 실험과 학습이다.
```

1. 드래그로 선택
2. `Ctrl+I` → `번호 매긴 목록으로 바꿔줘`
3. 결과 확인 → Accept

### 실습 3. Chat 사이드바 — 설명 요청

`Ctrl+Alt+I` → 다음 질문:

```
Markdown에서 접을 수 있는 섹션(<details>)을 만드는 문법 알려줘.
FAQ 예시도 3개 포함해줘.
```

답변을 받아서 `practice.md`에 붙여넣기 → 미리보기(`Ctrl+K V`)로 접었다 펴봄.

### 실습 4. `@workspace` 활용

- `copilot-test` 폴더에 지금까지 만든 `.md` 파일이 3~4개 있어야 함
- Chat에서:
  ```
  @workspace 이 폴더에 어떤 파일들이 있고, 각각 무슨 내용이야?
  ```
- Copilot이 폴더를 파악해서 요약해주면 성공.

---

## 핵심 포인트

1. **3가지 방식 구분**: Tab(예측) · Inline(삽입/수정) · Chat(대화/설명)
2. **가장 자주 쓸 것은 Tab과 Inline Chat** — Chat은 하루 몇 번
3. **선택 영역 + Inline Chat**이 정확도 최고 콤보
4. **`@workspace`**로 폴더 전체를 맥락으로 활용
5. **파일 상단 안내 주석**으로 이후 모든 제안 품질 상승
