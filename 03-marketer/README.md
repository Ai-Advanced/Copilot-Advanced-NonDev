**과정 후 추가 실습:** [Copilot CLI로 랜딩 페이지를 Azure에 배포](../09-azure-capstone/README.md) · [직군별 요구사항](../09-azure-capstone/roles.md). 기존 2일 과정 외 별도 편성입니다.

> **대상**: 디지털 마케터 · 퍼포먼스 마케터 · 그로스 해커 · 콘텐츠 마케터

## 이 과정이 마케터에게 특별한 이유

마케터의 하루를 잠깐 떠올려보세요.

광고 소재 10개 변형 만들기, 뉴스레터 HTML 깨짐 수정, GA4에서 이벤트 왜 안 잡히는지 개발자에게 물어보기, 지난주 캠페인 성과 엑셀 정리, 경쟁사 카피 벤치마킹... 이 중에서 **"진짜 마케팅 판단"에 해당하는 건 얼마나 될까요?**

Copilot은 반복적인 생산 작업을 압축시켜서, 마케터가 전략과 판단에 집중할 시간을 돌려줍니다.

| 기존 방식 | Copilot과 함께 |
|-----------|----------------|
| 광고 카피 10개 → 1시간 브레인스토밍 | 프롬프트 1개 → 30개 배리언트 → 상위 3개 선택 (15분) |
| HTML 이메일 템플릿 → 외주 or 웹 검색 30분 | Copilot으로 table 기반 반응형 완성 (10분) |
| GA4 이벤트 설계 → 개발자 미팅 잡기 | 이벤트 스키마 + JS 스니펫 직접 초안 (20분) |
| 매출 데이터 → 개발팀에 SQL 요청 (1일 대기) | Copilot SQL 생성 → 직접 실행 (10분) |
| 주간 리포트 → 수동 집계 2시간 | pandas 스크립트로 자동 생성 (설정 30분, 이후 자동) |

## 학습 목표

이 과정을 마치면:

1. **광고 카피와 이메일 소재**를 Copilot으로 채널별 변형 생산할 수 있다
2. **HTML 이메일**을 직접 만들고 수정할 수 있다 (개발팀 의존 탈출)
3. **마케터가 자주 쓰는 SQL 20개 패턴**을 Copilot으로 생성·검증할 수 있다
4. **GA4 이벤트 스키마**와 dataLayer JSON을 직접 설계할 수 있다
5. **캠페인 리포트 자동화 스크립트**를 만들어서 반복 집계 업무를 없앨 수 있다

## AI가 실수하는 마케팅 예시 (필독)

Copilot은 강력하지만, 마케팅 업무에서 특히 주의해야 할 실수 유형이 있습니다.

| 실수 유형 | 예시 | 대처법 |
|-----------|------|--------|
| **가짜 벤치마크 수치** | "업계 평균 CTR은 3.5%입니다" → 실제 산업/채널마다 다름 | 수치는 공식 리포트(Meta, Google 공식 벤치마크)로 직접 확인 |
| **규제 위반 카피** | 효능 과장 문구, "최고" "1위" 등 광고법 위반 표현 | 법무/컴플라이언스 팀 검토 후 사용 |
| **개인정보 포함 예시** | 실제 고객 이름·이메일을 프롬프트에 포함하면 안 됨 | 항상 **가명/익명 처리** 후 프롬프트에 입력 |
| **GA4 이벤트 이름 오기** | `AddToCart` 대신 `add_to_cart` — GA4는 snake_case | 공식 GA4 권장 이벤트 이름 목록으로 검증 |
| **채널별 문자 제한 무시** | 구글 검색 광고 헤드라인 30자 제한 초과 | 생성 후 반드시 문자 수 카운트 |
| **오래된 API/플랫폼 정보** | 2022년 기준의 Facebook 광고 스펙 제안 | 각 플랫폼 공식 가이드라인 최신 버전 확인 |

**황금 규칙**: Copilot이 수치와 규정을 말하면, 100% 직접 확인하세요. 초안 생성은 Copilot, 검증은 마케터.

## 개인정보 처리 주의사항

마케터는 이메일 리스트, 고객 구매 데이터, 행동 데이터를 자주 다룹니다.

**절대 금지**
- 실제 고객 이메일 주소를 VS Code 파일이나 프롬프트에 입력
- 주민번호, 연락처 등 식별 정보가 포함된 CSV를 그대로 열기
- 회사 내부 CRM 데이터를 Copilot에 직접 붙여넣기

**올바른 방법**
- 실습 데이터는 항상 **가상/익명 데이터** 사용
- 실제 업무 자동화 스크립트는 데이터 없이 "스키마만" Copilot에게 보여주기
- SQL 쿼리 생성 시 "테이블 구조(스키마)만" 알려주고 실제 데이터 행은 입력 금지

> GitHub Copilot은 기본 설정에서 입력 내용을 모델 학습에 사용하지 않도록 설정되어 있지만, 사내 보안 정책 및 개인정보보호법(PIPA)을 항상 우선 준수하세요.
