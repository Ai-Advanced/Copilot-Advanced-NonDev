## 3S 프롬프트 원칙

| 원칙 | 체크 |
|------|------|
| **Simple**: 인사말 없이, 명령형으로 | "광고 카피 10개 작성." |
| **Specific**: 채널 + 문자수 + 타겟 명시 | "페북, 125자, 20대 여성" |
| **Structured**: 목록으로 요구사항 분리 | 번호나 불릿으로 정리 |

## 카피 프레임워크 한 줄 정리

| 프레임워크 | 구조 | 언제 |
|-----------|------|------|
| **PAS** | Problem → Agitation → Solution | 문제 기반 타겟팅 |
| **AIDA** | Attention → Interest → Desire → Action | 퍼널 전체 커버 |
| **FAB** | Feature → Advantage → Benefit | 제품 소개/리뷰 |
| **4U** | Urgent·Unique·Ultra-specific·Useful | 헤드라인 점검 |

## 마케터 TOP 10 프롬프트 패턴

```
1. [채널] 광고 카피 [N]개. 제품: [X]. 타겟: [Y]. [글자수]자 이내.

2. A/B 테스트용 카피 페어 [N]쌍. 각 쌍은 [요소]만 다르게.

3. [이메일 유형] 이메일 초안. 톤: [X]. CTA: [Y]. [글자수]자 이내.

4. Subject line [N]개. 목표: 오픈율 최대화. [글자수]자 이내.

5. GA4 이벤트 스키마 표 작성. 이벤트: [목록]. 파라미터 포함.

6. dataLayer.push() 코드 작성. 이벤트: [X]. 파라미터: [목록].

7. PostgreSQL 쿼리. 테이블: [스키마]. 목표: [집계 내용].

8. 성과 데이터 인사이트 [N]개. 액션 아이템 포함. 없는 수치 만들지 말 것.

9. pandas 스크립트. 입력: [CSV]. 동작: [처리]. 출력: [결과].

10. 위 결과에서 광고법 위반 소지 있는 표현 체크해줘.
```

## SQL 기본 패턴

```sql
-- 집계 기본형
SELECT 그룹열, COUNT(*), SUM(금액열)
FROM 테이블
WHERE 날짜열 >= 'YYYY-MM-DD'
GROUP BY 그룹열
ORDER BY SUM(금액열) DESC;

-- JOIN 기본형
SELECT a.열, b.열
FROM 테이블A a
JOIN 테이블B b ON a.공통키 = b.공통키
WHERE 조건;
```

## 주의사항 (체크리스트)

- [ ] Copilot이 제시한 수치는 **반드시 공식 출처 확인**
- [ ] 광고 카피의 "최고/1위/효과 보장" 표현 → **광고법 검토**
- [ ] SQL은 **read-only 환경**에서 먼저 실행
- [ ] 프롬프트에 **실제 고객 개인정보** 절대 입력 금지
- [ ] GA4 이벤트 이름 → **GA4 예약 이벤트 이름** 목록으로 충돌 확인
