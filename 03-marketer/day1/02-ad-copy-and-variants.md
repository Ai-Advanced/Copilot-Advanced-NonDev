# 02. 광고 카피 A/B 변형 생산

## 학습 목표

- 페이스북·구글·네이버·카카오 채널별 문자 제한과 규격을 완벽히 숙지
- PAS, AIDA, FAB 카피 프레임워크를 Copilot 프롬프트에 녹여서 사용
- Copilot으로 30개 배리언트를 뽑고 상위 3개를 선정하는 워크플로우 체득
- A/B 테스트를 설계하는 카피 페어 생성법 익히기

**예상 소요**: 60~75분

---

## 2.1 채널별 광고 규격 완전 정리

광고 카피를 만들기 전에, 채널마다 다른 문자 제한을 반드시 알아야 합니다. Copilot은 이 제한을 항상 정확히 지키지 않으므로, 생성 후 직접 카운트하는 습관을 들이세요.

### 구글 검색 광고 (Google Search Ads)

| 구성 요소 | 제한 | 비고 |
|-----------|------|------|
| 헤드라인 | 30자 | 최대 3개 작성 (최소 2개 필수) |
| 설명 | 90자 | 최대 2개 |
| 표시 URL 경로 | 15자 × 2 | |

**주요 특성**
- 키워드 의도 기반: 검색어에 직접 반응하는 텍스트가 효과적
- 헤드라인에 주요 키워드 포함이 QS(Quality Score)에 영향
- 사용자가 이미 구매 의도를 가진 상태 — 이성 소구가 잘 통함

### 메타 (페이스북/인스타그램)

| 구성 요소 | 제한 | 비고 |
|-----------|------|------|
| 기본 텍스트 | 125자 (잘리기 전) | 최대 400자까지 가능하나 "더 보기" 클릭 필요 |
| 헤드라인 | 40자 | 이미지/영상 하단 |
| 설명 | 30자 | 헤드라인 아래 |
| CTA 버튼 | 사전 정의된 목록 | 지금 쇼핑하기, 자세히 알아보기 등 |

**주요 특성**
- 스크롤 중 멈추게 하는 후킹이 핵심 — 첫 줄이 가장 중요
- 비주얼과 텍스트가 함께 작동 — 이미지를 보완하는 카피
- 인지/관심 단계 사용자 — 감성 소구와 스토리텔링이 효과적

### 네이버 검색광고

| 구성 요소 | 제한 | 비고 |
|-----------|------|------|
| 제목 | 15자 | 한글 기준 |
| 설명 | 45자 | 한글 기준 |

**주요 특성**
- 극도로 짧은 제한 — 핵심 키워드 + 혜택을 압축
- 한국어 특성상 조사 포함 글자수 계산 필요
- 네이버 쇼핑 광고는 별도 규격 적용

### 카카오 비즈보드

| 구성 요소 | 제한 | 비고 |
|-----------|------|------|
| 메인 카피 | 20자 | |
| 서브 카피 | 30자 | |

**주요 특성**
- 카카오톡 피드 내 노출 — 생활 밀착형 메시지가 효과적
- 이모지 사용 가능 (채팅 맥락)
- 일상 대화 느낌의 친근한 톤

## 2.2 카피 프레임워크 3가지

프레임워크는 카피의 "뼈대"입니다. Copilot에게 프레임워크를 지정하면 결과 품질이 눈에 띄게 달라집니다.

### PAS (Problem-Agitation-Solution)

```
Problem:   타겟의 핵심 불편/문제를 콕 집어서 공감 유발
Agitation: 그 문제가 얼마나 고통스러운지 감정을 증폭
Solution:  제품/서비스가 어떻게 해결하는지 제시
```

**언제 쓰나**: 명확한 페인포인트가 있는 제품, 전환 캠페인

**예시 (스마트워치)**
```
P: 오늘 몇 걸음 걸었는지, 수면 질이 어땠는지 모르셨죠?
A: 느낌으로만 건강을 관리하다 놓치는 것들이 쌓입니다.
S: TimeX가 24시간 정확하게 기록해 드립니다. 지금 20% 할인.
```

### AIDA (Attention-Interest-Desire-Action)

```
Attention: 스크롤을 멈추게 하는 후킹
Interest:  제품의 핵심 기능/혜택으로 관심 유지
Desire:    사회적 증거, 희소성 등으로 갖고 싶은 마음 자극
Action:    명확한 CTA로 행동 유도
```

**언제 쓰나**: 신제품 인지도 캠페인, 퍼널 전체를 커버하는 단일 광고

**예시 (스마트워치)**
```
A: 수면 6시간 자도 왜 항상 피곤할까요?
I: TimeX는 수면 단계별 분석으로 진짜 원인을 찾아줍니다.
D: 이미 47,000명이 TimeX로 수면 질을 개선했습니다.
A: 지금 바로 확인하기 →
```

### FAB (Feature-Advantage-Benefit)

```
Feature:   제품의 실제 기능/스펙
Advantage: 그 기능이 경쟁 대비 뛰어난 이유
Benefit:   사용자 삶에서 어떤 변화가 생기는가
```

**언제 쓰나**: 제품 사양이 강점인 경우, 기술 제품, 비교 광고

**예시 (스마트워치)**
```
F: 혈중산소 측정 + 7일 연속 배터리
A: 충전 걱정 없이 일주일 내내 정확한 건강 데이터
B: 운동·수면·일상에서 건강 공백 없이 관리
```

## 2.3 Copilot으로 30개 배리언트 뽑기

### Step 1. 브리프 파일 만들기

실습 시작 전에 `campaign-brief.md` 파일을 만들고 아래 내용을 채웁니다. Copilot이 파일 맥락을 읽으면 더 나은 결과를 냅니다.

```markdown
# 캠페인 브리프: TimeX 여름 세일

## 제품 정보
- 제품명: TimeX Pro 스마트워치
- 주요 기능: 수면 추적, 혈중산소 측정, 심박수 모니터링, 7일 배터리
- 가격: 정가 199,000원 → 여름 세일 159,200원 (20% 할인)
- 판매 기간: 2026.07.21~07.31

## 타겟
- 주 타겟: 30~45세 직장인, 건강/피트니스 관심
- 서브 타겟: 20대 후반 사회초년생, 첫 스마트워치 구매 고려층

## 핵심 메시지
- 가성비: 프리미엄 기능을 합리적 가격에
- 신뢰: 이미 사용 중인 고객 47,000명
- 긴박감: D-10, 한정 수량

## CTA
- 지금 구매하기
- 특가 확인하기
- 무료 배송으로 받아보기
```

### Step 2. 채널별 15개 뽑기

파일을 열어놓은 상태에서 Copilot Chat에:

```
위 캠페인 브리프를 바탕으로 페이스북 광고 카피 15개 작성.

형식: 헤드라인(25자 이내) + 본문(90자 이내), 번호 매기기
구성:
- 1~5번: PAS 프레임워크
- 6~10번: AIDA 프레임워크
- 11~15번: 감성 소구 (스토리텔링)

각 카피 아래 [프레임워크] 태그 표시.
```

### Step 3. 선별 기준 표 만들기

생성된 15개를 아래 기준으로 점수 매기기:

| 번호 | 글자수 OK? | 타겟 공감? | 차별화? | 총점(3점 만점) |
|------|-----------|-----------|---------|----------------|
| 1 | | | | |
| 2 | | | | |
| ... | | | | |

### Step 4. 상위 3개 심화 개선

```
[N번], [M번], [K번] 카피가 가장 좋아.
각각 2가지 변형을 더 만들어줘:
- 변형 A: 더 직접적인 혜택 소구
- 변형 B: 감성적 각도로 재작성

총 6개 (각 2개씩).
```

## 2.4 A/B 테스트 카피 페어 설계

좋은 A/B 테스트는 **하나의 요소만** 다릅니다. Copilot에게 이 원칙을 지키도록 명시해야 합니다.

```
A/B 테스트용 카피 페어 5쌍 생성.
캠페인 브리프의 TimeX 여름 세일 기준.
채널: 페이스북, 헤드라인 25자 + 본문 90자.

각 쌍은 하나의 요소만 다르게:
쌍 1: 감성 소구 vs 이성 소구
쌍 2: 질문형 헤드라인 vs 선언형 헤드라인
쌍 3: 혜택 강조 vs 손실 회피 강조
쌍 4: 숫자 포함 (47,000명, 20%) vs 숫자 없음
쌍 5: 짧고 강렬 vs 풍부한 설명

표 형식으로 정리:
| 쌍 | 테스트 요소 | A 버전 | B 버전 |
```

## 2.5 후킹 원칙 7가지

카피의 첫 줄이 광고의 승패를 가릅니다. Copilot에게 후킹 원칙을 명시하면 훨씬 예리한 첫 줄이 나옵니다.

| 후킹 유형 | 예시 | 효과 |
|-----------|------|------|
| **질문** | "수면 6시간인데 왜 항상 피곤할까요?" | 자기 문제인지 확인하게 만듦 |
| **숫자** | "47,000명이 선택한 이유" | 신뢰와 사회적 증거 |
| **도발** | "당신의 건강관리가 틀렸을 수도 있습니다" | 충격과 호기심 |
| **혜택 직접 제시** | "수면 질 30% 개선, 2주 만에" | 명확한 가치 제안 |
| **공감** | "운동 앱 3개, 다 작심삼일인 분들께" | 감정적 동조 |
| **뉴스/새로움** | "드디어 7일 배터리 스마트워치 등장" | FOMO와 호기심 |
| **긴박감** | "D-3. 이번 주 안에만 20% 할인" | 즉각 행동 유도 |

```
위 7가지 후킹 유형별로 TimeX 스마트워치 카피 첫 줄만 각 1개씩 작성.
채널: 페이스북, 25자 이내.
후킹 유형을 각 줄 앞에 [태그]로 표시.
```

## 2.6 AI가 실수하는 카피 예시

Copilot이 광고 카피 작업에서 자주 하는 실수 유형을 알아두세요.

| 실수 유형 | 예시 | 왜 문제인가 |
|-----------|------|------------|
| **효능 과장** | "수면 질 100% 개선 보장" | 광고법 위반 소지 (표시광고법) |
| **글자수 초과** | 헤드라인 35자 생성 | 채널에서 잘리거나 심사 탈락 |
| **경쟁사 비방** | "○○브랜드보다 3배 우수" | 근거 없는 비교 광고 금지 |
| **최상급 남발** | "국내 최고의 스마트워치" | 근거 없으면 광고법 위반 |
| **가짜 긴박감** | "단 오늘만 할인" (실제로 매일 반복) | 소비자기본법 위반 가능성 |
| **가격 오류** | 실제와 다른 할인율 제시 | Copilot은 계산 실수를 함 |

**검증 프롬프트**: 카피를 생성한 후 반드시 한 번 더:

```
위에서 생성한 카피들 중:
1. 광고법(표시광고법) 위반 소지가 있는 표현 목록
2. 근거 자료 없이 쓰기 어려운 주장
3. 문자 제한 초과 가능성 있는 항목

각각 지적하고 수정안 제시.
```

## 실습: 스마트워치 광고 카피 15개 → 상위 3개 선정

### 준비

1. VS Code에서 `campaign-brief.md` 파일 생성 후 2.3절의 브리프 내용 복붙
2. Copilot Chat 열기 (`Ctrl+Alt+I`)

### Step 1. 15개 생성 (10분)

```
위 캠페인 브리프를 바탕으로 구글 검색 광고 카피 15개 작성.

형식 (채널 스펙 준수 필수):
- 헤드라인 1: 30자 이내
- 헤드라인 2: 30자 이내
- 설명: 90자 이내

구성:
- 1~5번: 키워드 직접 매칭형 ("스마트워치 추천" 검색자 대상)
- 6~10번: 혜택 강조형
- 11~15번: 긴박감/프로모션형

번호 매겨서 구분.
```

### Step 2. 검증 (5분)

생성된 15개를 보고:
- 글자수 직접 카운트 (VS Code에서 드래그 → 우측 하단 글자수 표시)
- 타겟 관점에서 공감 가는지 읽어보기
- 광고법 검토 프롬프트 실행

### Step 3. 상위 3개 선정 기준 (5분)

```
위 15개 카피를 아래 기준으로 5점 만점 채점해줘:
1. 후킹 강도 (첫 인상)
2. 혜택 명확성
3. CTA 명확성
4. 채널 적합성 (구글 검색)
5. 브랜드 톤 일관성

표 형식으로 채점 + 상위 3개 추천. 추천 이유도 한 줄씩.
```

### Step 4. 상위 3개 심화 (10분)

```
[N번], [M번], [K번]이 선정됐어.
각각을 다음 방향으로 1개씩 개선해줘:
- N번: 긴박감을 더 강하게
- M번: 가격 혜택을 더 직접적으로
- K번: 신뢰 지표(고객 수) 포함

개선 전 / 개선 후 비교 형식으로 제시.
```

## 핵심 포인트

1. **채널 규격 먼저**: 프롬프트에 항상 문자 제한 명시 + 생성 후 직접 카운트
2. **프레임워크 지정**: PAS, AIDA, FAB 중 캠페인 목표에 맞는 것 선택
3. **많이 뽑고 선별**: 15~30개 생성 → 상위 3~5개 선정이 효율적
4. **A/B는 하나만 다르게**: 여러 요소를 동시에 바꾸면 무엇이 효과적인지 알 수 없음
5. **검증 필수**: 광고법 위반 소지, 글자수 초과, 가격 오류는 Copilot이 잡지 못함
