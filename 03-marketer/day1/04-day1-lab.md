# 04. Day 1 종합 실습 — 여름 세일 캠페인

## 실습 목표

- 이 실습 하나로 Day 1에서 배운 내용을 실제 캠페인 패키지로 통합
- 5개 채널 × 3개 배리언트 = 15개 광고 소재 완성
- 뉴스레터 이메일 HTML 완성본 완성
- Copilot 워크플로우를 처음부터 끝까지 혼자 실행해보기

**예상 소요**: 75~90분

---

## 실습 시나리오

> **상황**: 여러분은 TimeX 스마트워치 브랜드의 디지털 마케터입니다.
> 이번 주 목요일부터 "여름 세일" 캠페인이 시작됩니다.
> 오늘 오후까지 5개 채널 광고 소재와 뉴스레터를 모두 준비해야 합니다.
> 팀원 한 명이 갑자기 아파서 당신 혼자 처리해야 합니다.
> 남은 시간: 90분.

## 준비 (10분)

### 파일 구조 만들기

VS Code에서 새 폴더 `summer-sale-campaign/`을 만들고 아래 파일들을 생성합니다.

```
summer-sale-campaign/
├── brief.md              (캠페인 브리프)
├── ad-copies.md          (광고 카피 모음)
└── newsletter.html       (뉴스레터 이메일)
```

### 캠페인 브리프 작성

`brief.md`에 아래 내용을 붙여넣고, `[비어 있는 부분]`에 자신의 아이디어를 채워넣으세요.

```markdown
# 여름 세일 캠페인 브리프

## 기본 정보
- 캠페인명: TimeX 여름 세일 2026
- 기간: 2026.07.21 ~ 07.31 (11일)
- 목표: 전환 최대화, ROAS 300% 이상
- 예산: 채널별 일 50만원 (총 일 200만원)

## 제품 및 혜택
- 제품: TimeX Pro 스마트워치 (정가 199,000원)
- 할인: 최대 20% → 159,200원
- 무료배송: 전 상품
- 추가 혜택: 구매 시 실리콘 밴드 추가 증정 (선착순 500명)

## 타겟
- 주 타겟: 30~45세 직장인, 건강·피트니스 관심, 모바일 사용자
- 서브 타겟: 20대 후반, 첫 스마트워치 구매 고려

## 핵심 메시지
- 메시지 1 (기능): 수면·활동·혈중산소를 7일 배터리로 끊김없이 추적
- 메시지 2 (가격): 프리미엄 기능, 합리적 가격
- 메시지 3 (긴박감): 여름 세일, 7/31까지

## 채널별 목표
| 채널 | 목표 | 주요 지표 |
|------|------|-----------|
| 구글 검색 | 전환 | ROAS, CPA |
| 페이스북 | 인지+전환 | CTR, 전환율 |
| 인스타그램 | 인지+참여 | 도달, 저장수 |
| 네이버 | 전환 | 클릭, 전환 |
| 카카오 | 재타겟팅 | CTR, 전환 |
```

## Part 1. 5개 채널 × 3개 배리언트 광고 소재 (45분)

`ad-copies.md` 파일을 열고 시작합니다.

### 채널 1. 구글 검색 광고 (10분)

```
brief.md의 캠페인 브리프를 바탕으로 구글 검색 광고 카피 9개 작성.

규격 (엄수):
- 헤드라인 1: 30자 이내
- 헤드라인 2: 30자 이내
- 설명: 90자 이내

3개 배리언트로 구분:
- 배리언트 A: 기능 강조형 (수면·건강 트래킹)
- 배리언트 B: 가격 혜택형 (할인율, 특가)
- 배리언트 C: 긴박감형 (D-11, 한정 혜택)

각 배리언트마다 3개씩 작성 (헤드라인1·2·설명 세트).
Markdown 표로 정리.
```

**생성 후 체크**

- [ ] 헤드라인 1·2 각각 30자 이내 (VS Code 드래그 글자수 확인)
- [ ] 설명 90자 이내
- [ ] 키워드 포함 여부 ("스마트워치", "TimeX")

---

### 채널 2. 페이스북 광고 (8분)

```
구글 완성된 배리언트 3개를 페이스북 규격으로 변환 + 페이스북 전용 3개 추가.
총 6개.

페이스북 규격:
- 기본 텍스트: 125자 이내 (이 안에 핵심 담기)
- 헤드라인: 40자 이내
- CTA 버튼 텍스트: "지금 쇼핑하기" or "자세히 알아보기"

페이스북 전용 3개는 이모지 포함, 스크롤 멈추는 첫 줄 강조.
배리언트 레이블: FB-A, FB-B, FB-C, FB-D, FB-E, FB-F
```

---

### 채널 3. 인스타그램 (8분)

```
인스타그램 피드 + 스토리 카피 각 3개씩, 총 6개.

피드 카피 (3개):
- 캡션 형식: 후킹 첫 줄 + 본문 2~3문장 + CTA + 해시태그 8개
- 총 300자 이내

스토리 카피 (3개):
- 텍스트만: 슬라이드 2장 구성 (각 20자 이내)
- 슬라이드 1: 관심 유발 질문 or 후킹
- 슬라이드 2: 혜택 + CTA ("스와이프 업" or "링크 클릭")

배리언트: INST-A, INST-B, INST-C (피드), INST-D, INST-E, INST-F (스토리)
```

---

### 채널 4. 네이버 검색광고 (5분)

```
네이버 검색광고 3개 배리언트.

규격 (엄수):
- 제목: 15자 이내 (한글 기준)
- 설명: 45자 이내

배리언트:
- NAV-A: 기능 포커스
- NAV-B: 가격/할인 포커스
- NAV-C: 브랜드/신뢰 포커스

각 배리언트 제목 + 설명 한 쌍씩. Markdown 표로.
```

**주의**: 네이버 15자는 정말 짧습니다. Copilot이 자주 초과합니다. 생성 후 반드시 카운트.

---

### 채널 5. 카카오 비즈보드 (5분)

```
카카오 비즈보드 재타겟팅 카피 3개.

타겟: 사이트 방문했지만 미구매 사용자 (재타겟팅)
규격:
- 메인 카피: 20자 이내
- 서브 카피: 30자 이내

카카오 특성: 일상적·친근한 톤, 이모지 가능
배리언트: KKO-A, KKO-B, KKO-C

형식: 각 배리언트별 메인 + 서브 쌍.
```

### 소재 최종 정리 (9분)

```
위에서 작성한 5개 채널 광고 카피 전체를 다음 기준으로 검토해줘:

1. 각 채널 문자 제한 준수 여부 (제한 초과한 것 명시)
2. 캠페인 핵심 메시지(기능·가격·긴박감)가 균형 있게 포함됐는지
3. 채널별 톤이 해당 플랫폼에 적합한지
4. 광고법 측면에서 주의해야 할 표현 (있으면 지적)
5. A/B 테스트 추천: 가장 먼저 테스트하면 좋을 배리언트 페어 3개

표 형식으로 정리 + 권고사항.
```

## Part 2. 뉴스레터 이메일 완성 (25분)

### Step 1. 뉴스레터 HTML 생성 (15분)

`newsletter.html` 파일을 열고 Inline Chat(`Ctrl+I`):

```
여름 세일 캠페인용 HTML 뉴스레터 완성본 작성.

브랜드: TimeX 스마트워치
이메일 제목 줄: "[광고] ☀️ 여름 세일 D-11 — TimeX Pro 20% 할인"

섹션 구성:
1. 헤더
   - 배경: #0A2E4A
   - 로고: 중앙 배치, "TimeX" 텍스트 (흰색, 24px 굵게)
   - 하단 네비: 제품소개 | 기능 | 리뷰 | 고객센터 (링크 {{nav_url_*}})

2. 히어로
   - 배너 이미지 (600×280): {{hero_image_url}}
   - 배경 타이틀: "여름 세일, 시작합니다"
   - 서브: "TimeX Pro 20% 할인 · 7월 31일까지"
   - CTA 버튼: "지금 구매하기" (#E8501A)

3. 카운트다운 바
   - 배경: #FFF3E0
   - 텍스트: "⏰ 여름 세일 마감까지 D-11 | 선착순 500명 밴드 증정"
   - 중앙 정렬, 14px

4. 3혜택 카드
   배경: #F8F9FA, 각 카드 테두리 1px
   - 카드 1: 아이콘 {{icon_sleep}} | "수면 추적" | "렘수면까지 정밀 분석"
   - 카드 2: 아이콘 {{icon_oxygen}} | "혈중산소" | "실시간 SpO2 모니터링"
   - 카드 3: 아이콘 {{icon_battery}} | "7일 배터리" | "매일 충전 없이 일주일"

5. 제품 하이라이트
   - 좌: 제품 이미지 {{product_image}} (260×260)
   - 우: 제품명 "TimeX Pro", 특징 4개 불릿, 정가 ~~199,000원~~ 할인가 159,200원 (빨간 #E84040), "무료배송" 뱃지, CTA "구매하기"

6. 고객 리뷰 3개
   배경: #F0F4FF
   - 각 리뷰: 별점 ★★★★★, 이름(가명), 한 줄 후기

7. 최종 CTA 배너
   - 배경: #0A2E4A
   - 텍스트: "지금 구매하고 무료 밴드 받기" (흰색 24px)
   - 서브: "선착순 500명 한정 · 7월 31일 마감" (연회색)
   - 버튼: "여름 세일 바로가기" (#E8501A)

8. 푸터
   - (광고) 표시
   - 수신거부 링크: {{unsubscribe_url}}
   - 무료 수신거부 안내
   - 주소: {{company_address}}
   - 저작권: © 2026 TimeX. All rights reserved.

요구사항:
- Gmail + Outlook 2016+ 호환
- 인라인 CSS 우선
- @media (max-width: 600px) 반응형
- 다크모드 CSS (@media prefers-color-scheme: dark)
- 교체 항목 모두 {{변수명}} 처리
- 최대 너비 600px
```

### Step 2. 브라우저 확인 (5분)

1. Chrome에서 파일 열기 → 레이아웃 확인
2. DevTools → 반응형 모드 → 375px 모바일 확인
3. 깨진 부분 있으면 Chat에 "N번 섹션 레이아웃이 깨져. 수정해줘" 요청

### Step 3. Outlook 호환성 점검 (5분)

```
위 HTML 이메일의 Outlook 호환성 문제 전체 체크.

확인 항목:
1. display: flex 또는 grid 사용 여부
2. CSS 속성 중 Outlook 미지원 목록
3. 인라인 style 누락된 주요 요소
4. 이미지 width/height 속성 없는 것
5. <!--[if mso]> 분기처리 필요한 부분

각 문제에 수정 코드 제시.
```

## Part 3. 소재 패키지 최종 정리 (10분)

### 캠페인 소재 체크리스트 생성

```
여름 세일 캠페인 소재 패키지 최종 체크리스트 작성.

포함할 내용:
1. 각 채널 소재 완성 여부 체크 박스
2. 발송/업로드 전 검토 항목 (글자수, 이미지 사이즈, 링크 등)
3. 법적 필수 항목 체크 (광고 표시, 수신거부 등)
4. A/B 테스트 세팅 체크
5. 성과 추적 UTM 파라미터 예시 (각 채널별)

Markdown 체크리스트 형식. 팀원에게 공유할 수 있는 수준으로.
```

### UTM 파라미터 설계

```
여름 세일 캠페인 UTM 파라미터 세트 작성.

캠페인: summer_sale_2026

5개 채널별 UTM 예시:
- utm_source: 소스
- utm_medium: 미디엄
- utm_campaign: summer_sale_2026
- utm_content: 배리언트 구분 (A/B/C)
- utm_term: 키워드 (검색 광고만)

예시 URL: https://timex.kr/product/pro?utm_source=...

Markdown 표로 정리. 각 채널별 완성 URL 예시 1개씩.
```

## 핵심 포인트

1. **캠페인 브리프 파일을 먼저 만들어라** — Copilot이 맥락을 읽어서 더 일관된 결과를 냄
2. **채널별 규격은 매번 프롬프트에 명시** — "알아서" 지키는 경우가 드묾
3. **소재 생성 → 검증 → 개선 순환** — 한 번에 완벽한 결과를 기대하지 말 것
4. **UTM 파라미터를 처음부터 설계** — 나중에 성과 분석을 위해 필수
5. **수신거부 링크는 법적 의무** — 뉴스레터 푸터에 항상 포함
