# 08. 캡스톤: 신제품 런칭 캠페인 A~Z

**완성 후 Azure로:** 아래 산출물 검증을 마치면 [공통 배포 캡스톤](../../09-azure-capstone/README.md)에서 가상 캠페인 페이지를 게시합니다. [직군별 요구사항·프롬프트](../../09-azure-capstone/roles.md)를 사용하며, 기존 과정과 별도 편성입니다.

## 캡스톤 목표

2일 과정에서 배운 **모든 기술을 하나의 실제 캠페인 패키지**로 통합합니다.

- 타겟팅 설계 → 카피 세트 → 이메일 시리즈 → GA4 이벤트 → SQL 쿼리 → 리포트 자동화

혼자 처음부터 끝까지 완주하는 것이 목표입니다. Copilot을 최대한 활용하되, 모든 결과물은 직접 검증하세요.

**예상 소요**: 90~120분

---

## 캡스톤 시나리오

> **상황**: TimeX가 차세대 제품 **"TimeX Ultra"**를 출시합니다.
>
> - 제품: TimeX Ultra 스마트워치
> - 특징: 심전도(ECG) 측정, 14일 배터리, 티타늄 케이스, IP68 방수
> - 가격: 349,000원 (얼리버드 279,200원, 20% 할인)
> - 런칭일: 2026년 8월 11일 (월요일)
> - 얼리버드 기간: 8월 4일~8월 10일 (D-7~D-1)
>
> 당신은 이 런칭 캠페인의 유일한 디지털 마케터입니다.
> 오늘 마감까지 아래 패키지를 준비해야 합니다.

## Phase 1. 전략 수립 (15분)

### Step 1-1. 캠페인 브리프 작성

`brief.md` 파일 생성 후 Inline Chat:

```
TimeX Ultra 신제품 런칭 캠페인 브리프 작성.

제품 정보:
- 제품명: TimeX Ultra
- 주요 특징: 심전도(ECG), 14일 배터리, 티타늄 케이스, IP68 방수
- 정가: 349,000원 / 얼리버드: 279,200원 (D-7~D-1)
- 런칭일: 2026년 8월 11일

섹션 구성:
1. 캠페인 개요 (목표, 기간, 예산 배분 가이드)
2. 핵심 메시지 3가지 (기능/가격/긴박감 각각)
3. 채널별 목표 표 (5개 채널, 주요 KPI)
4. 성공 기준 (ROAS, CPA, 얼리버드 판매량 목표 예시)
5. 리스크 및 대응 방안

Markdown 형식. 실제 사용 가능한 수준으로.
```

### Step 1-2. 타겟 페르소나 3개 설계

`target-personas.md` 파일 생성 후:

```
TimeX Ultra 런칭 캠페인 타겟 페르소나 3개 작성.

기존 TimeX Pro 구매층 분석 기반으로:
- 페르소나 1: 얼리어답터 (신기술 관심, 30대 남성 직장인)
- 페르소나 2: 건강 관리자 (심장 건강 관심, 40대 남녀)
- 페르소나 3: 프리미엄 추구자 (디자인·소재 중시, 30대 여성)

각 페르소나:
- 이름/나이/직업 (가상)
- 하루 일과 스냅샷 (2~3문장)
- 핵심 욕구 / 핵심 불안
- TimeX Ultra가 해결하는 문제
- 가장 반응할 광고 채널 + 소구 방식
- 소구하지 말아야 할 것 (역소구)

Markdown 형식.
```

## Phase 2. 광고 소재 세트 (25분)

`ad-copies.md` 파일 생성.

### Step 2-1. 채널별 카피 생성

```
brief.md와 target-personas.md를 참고해서
TimeX Ultra 런칭 광고 카피 세트를 작성해줘.

각 채널별 3개 배리언트:

1. 구글 검색 (헤드라인1 30자 + 헤드라인2 30자 + 설명 90자)
   - A: 심전도 기능 강조
   - B: 배터리 + 방수 강조
   - C: 얼리버드 특가 강조

2. 페이스북 (기본텍스트 125자 + 헤드라인 40자)
   - A: 페르소나1 (얼리어답터) 타겟
   - B: 페르소나2 (건강관리자) 타겟
   - C: 얼리버드 긴박감

3. 인스타그램 피드 캡션 (300자 이내 + 해시태그 8개)
   - A: 감성 라이프스타일
   - B: 기술/스펙 강조
   - C: 사회적 증거

4. 네이버 검색광고 (제목 15자 + 설명 45자)
   - A/B/C 3개

5. 카카오 비즈보드 (메인 20자 + 서브 30자)
   - A: 얼리버드 타이머
   - B: 기능 차별화
   - C: 가격 소구

각 배리언트에 레이블 붙여서 구분.
생성 후 채널별 문자 제한 준수 여부 자체 체크 포함.
```

### Step 2-2. 카피 검증

```
위 광고 카피 전체를 검토해줘.

체크 항목:
1. 각 채널 문자 제한 초과 여부 (초과한 것 명시)
2. 광고법 위반 소지 (최상급, 효능 보장 등)
3. 제품 스펙과 다른 주장 (ECG는 의료기기 아님 주의)
4. 채널 특성에 맞지 않는 톤
5. A/B 테스트 추천 페어 3개

수정 필요한 항목은 수정안 포함.
```

## Phase 3. 이메일 시리즈 (20분)

`email-series.html` 파일 생성.

### Step 3-1. 3단계 시리즈 계획

```
TimeX Ultra 런칭 이메일 3단계 시리즈 계획 작성.

시리즈:
- 이메일 1 (D-7, 8월 4일): 얼리버드 오픈 + 신제품 티저
- 이메일 2 (D-3, 8월 8일): 주요 기능 상세 + 사회적 증거
- 이메일 3 (D-1, 8월 10일): 마감 긴박감 + 최후 혜택

각 이메일:
- 제목 줄 (Subject Line) 3가지 제안
- 핵심 메시지 1줄
- 섹션 구성 (헤더/본문/CTA)
- 예상 오픈율 목표치 (업계 벤치마크는 직접 확인 요망)

표 형식으로 정리.
```

### Step 3-2. 이메일 3 (마감 긴박감) HTML 완성

```
Gmail·Outlook 호환 HTML 이메일 작성.
이메일 시리즈 3번 (D-1 마감 긴박감).

구조:
1. 헤더: "TimeX" 로고 (배경 #1A1A2E, 흰색)
2. 히어로: "마감 24시간 전입니다" (큰 글씨, 붉은 강조), 서브: "얼리버드 혜택이 곧 사라집니다"
3. 카운트다운 배너: "⏰ 남은 시간: {{countdown}}" 배경 #FFE8E8
4. 혜택 요약 (3가지):
   - 20% 할인 (349,000 → 279,200원)
   - 선착순 200명 추가 실리콘 밴드
   - 무료 익일 배송
5. 핵심 기능 2개만 (ECG + 14일 배터리)
6. 고객 리뷰 1개 (TimeX Pro 기존 사용자)
7. 강한 CTA: "지금 바로 얼리버드 구매" 버튼 (#E84040)
8. 마감 후 가격 공지: "내일부터 349,000원으로 돌아갑니다"
9. 푸터: (광고) 표시, 수신거부 링크

인라인 CSS, Outlook 호환, 반응형, {{변수명}} 처리.
```

## Phase 4. GA4 이벤트 설계 (15분)

`ga4-schema.md`와 `ga4-events.js` 파일 생성.

### Step 4-1. 런칭 캠페인 전용 이벤트 설계

```
TimeX Ultra 런칭 캠페인에 맞는 GA4 이벤트 스키마 문서 작성.

표준 E-commerce 이벤트 5개 + 런칭 전용 커스텀 이벤트 3개:

표준:
1. view_item (상품 상세)
2. add_to_cart
3. begin_checkout
4. purchase
5. sign_up

커스텀 (런칭 캠페인 특화):
6. earlybird_cta_click - 얼리버드 CTA 클릭 (히어로 배너)
7. email_open_by_series - 이메일 시리즈별 오픈 추적
8. countdown_viewed - 카운트다운 배너 노출 및 인터랙션

각 이벤트: 트리거, 파라미터 표, dataLayer 코드, GA4 보고서 활용법
snake_case 준수, 개인정보 파라미터 금지.
```

### Step 4-2. 중요 검증 포인트

```
ga4-events.js에서 생성된 코드를 검토해줘.

체크:
1. purchase 이벤트에 transaction_id 있는지
2. ecommerce: null 초기화 순서
3. snake_case 위반 여부
4. 개인정보 파라미터 포함 여부
5. earlybird_cta_click 이벤트가 40자 이내인지
6. GA4 예약 이벤트 이름 충돌 여부

발견된 문제와 수정 코드.
```

## Phase 5. SQL 대시보드 쿼리 (20분)

`dashboard-queries.sql` 파일 생성.

### Step 5-1. 런칭 성과 대시보드 쿼리 세트

```
TimeX Ultra 런칭 성과 측정용 SQL 쿼리 5개 작성.
DB: PostgreSQL
테이블: ad_performance, orders, customers, products

쿼리 1: 런칭 이후 일별 매출 및 주문건수 추이
(8월 11일 이후, 일별, product_name = 'TimeX Ultra' 필터)

쿼리 2: 채널별 ROAS + CPA + 전환율
(런칭 이후 전체 기간)

쿼리 3: 얼리버드(8월 4~10일) vs 정상 판매(8월 11일~) 비교
(주문건수, 평균 주문가, 총 매출)

쿼리 4: 신규 고객 채널별 획득 현황
(TimeX Ultra 첫 구매 고객의 유입 채널 분포)

쿼리 5: 재구매 현황
(TimeX Pro 기존 구매 고객 중 TimeX Ultra 추가 구매한 비율)

각 쿼리 앞에:
-- 목적: [이 쿼리가 답하는 비즈니스 질문]
-- 사용 시점: [언제 실행]
주석 포함.
```

### Step 5-2. 쿼리 검증

```
위 5개 SQL 쿼리를 검토해줘.

체크:
1. 날짜 범위 로직 오류 여부
2. NULL 처리 (NULLIF, IS NULL 등)
3. 개인정보 컬럼 노출 여부 (email 등)
4. 성능 개선 가능한 부분
5. 비즈니스 로직이 의도와 다를 수 있는 부분

각 문제에 수정 코드.
```

## Phase 6. 리포트 자동화 스크립트 (10분)

`report-automation.py` 파일 생성.

### Step 6-1. 런칭 전용 리포트 스크립트

```
TimeX Ultra 런칭 성과 자동 리포트 Python 스크립트 작성.

입력: ad_report.csv (동일 스키마)
런칭일: '2026-08-11' (상수로 정의)

스크립트 동작:
1. CSV 불러오기
2. 런칭 이후 데이터와 런칭 이전(얼리버드 기간) 분리
3. 각각 채널별 집계: impressions, clicks, cost, conversions, revenue
4. KPI 계산: CTR, ROAS, CPA
5. 얼리버드 vs 런칭 후 성과 비교 표 출력
6. ROAS 200% 미만 채널에 [경고] 표시
7. 결과를 launch_report_YYYYMMDD.csv로 저장

에러 처리 + 한국어 주석 + 실행 방법 상단 docstring.
```
