# 마케터용 Copilot 프롬프트 치트시트

**Azure 확장:** [직군별 웹 변환 프롬프트](../09-azure-capstone/roles.md) · [계획·배포·재배포 프롬프트](../09-azure-capstone/README.md).

> **사용 방법**: Copilot Chat 사이드바(`Ctrl+Alt+I`)에 복붙 후, `[대괄호]` 안의 내용을 교체하세요.
> BAD vs GOOD 비교를 통해 프롬프트 감각을 익혀보세요.

## 1. 광고 카피 (Ad Copy)

### 1-1. 기본 카피 배리언트 생성

**❌ BAD**
```
광고 카피 만들어줘
```

**✅ GOOD**
```
[제품명] 페이스북 광고 카피 10개 생성.

제품: [제품명 + 한 줄 설명]
타겟: [연령대, 성별, 관심사]
핵심 혜택: [주요 혜택 2~3가지]
톤: [친근한/전문적/긴박한 중 택1]
형식: 각 카피는 헤드라인(25자 이내) + 본문(90자 이내) 두 줄.
번호를 매겨서 구분.
```

---

### 1-2. 채널별 문자 제한 준수 카피

```
아래 광고 콘셉트를 각 채널 규격에 맞게 변환해줘.

콘셉트: [핵심 메시지 한 줄]
제품: [제품명]
혜택: [주요 혜택]

출력 형식:
1. 구글 검색 광고: 헤드라인 3개(각 30자 이내) + 설명 2개(각 90자 이내)
2. 페이스북/인스타: 기본 텍스트(125자 이내) + 헤드라인(40자 이내)
3. 네이버 검색광고: 제목(15자 이내) + 설명(45자 이내)
4. 카카오 비즈보드: 메인 카피(20자 이내) + 서브 카피(30자 이내)
```

---

### 1-3. PAS 프레임워크 카피

```
PAS(Problem-Agitation-Solution) 프레임워크로 광고 카피 3버전 작성.

제품: [제품명]
타겟의 핵심 문제: [문제 상황]
타겟 독자: [타겟 설명]

각 버전:
- Problem: 문제를 1문장으로 찌르기
- Agitation: 그 문제가 얼마나 고통스러운지 1문장
- Solution: 제품이 어떻게 해결하는지 1문장 + CTA
전체 200자 이내.
```

---

### 1-4. AIDA 프레임워크 카피

```
AIDA 프레임워크로 인스타그램 피드 광고 카피 작성.

제품: [제품명]
가격: [가격 또는 할인율]
타겟: [타겟 설명]

형식:
- Attention: 첫 줄 후킹 (이모지 활용, 20자 이내)
- Interest: 핵심 기능/혜택 2~3개 불릿
- Desire: 사회적 증거 또는 희소성 1문장
- Action: CTA 버튼 텍스트 3가지 제안
```

---

### 1-5. A/B 테스트용 카피 페어 생성

```
동일 캠페인의 A/B 테스트용 카피 페어 5쌍 생성.

제품: [제품명]
캠페인 목표: [인지도/클릭/전환 중 택1]
각 쌍은 하나의 요소만 다르게:
- 쌍 1: 감성 소구 vs 이성 소구
- 쌍 2: 질문형 헤드라인 vs 선언형 헤드라인
- 쌍 3: 혜택 강조 vs 공포/손실 강조
- 쌍 4: 숫자 포함 vs 숫자 없음
- 쌍 5: 짧은 카피 vs 긴 카피

채널: [채널명], 문자 제한: [글자수]
```

---

### 1-6. 시즌/이벤트 카피

```
[이벤트명] 시즌 한정 광고 카피 8개 작성.

브랜드: [브랜드명]
이벤트: [이벤트 이름, 기간, 할인율]
강조 포인트: 시즌 긴박감, 한정 재고, 특별 혜택
채널: [채널명]
문자 제한: [글자수]
톤: 설레고 긴박하게. 이모지 적절히 포함.
```

### 1-7. 카피 개선 요청

```
아래 광고 카피를 개선해줘.

현재 카피:
[카피 붙여넣기]

개선 방향:
- 클릭률(CTR)을 높이는 방향으로
- 타겟: [타겟 설명]
- 채널: [채널명]
- 기존 카피의 핵심 메시지는 유지

개선안 3가지 + 각각 왜 더 나은지 한 줄 이유.
```

### 1-8. 경쟁사 카피 벤치마킹 분석

```
아래 경쟁사 광고 카피를 분석하고 인사이트를 정리해줘.

경쟁사 카피들:
[카피 1]
[카피 2]
[카피 3]

분석 항목:
1. 공통적으로 강조하는 혜택/소구점
2. 자주 쓰는 단어와 톤
3. 채운 포지션 vs 비어있는 포지션
4. 우리 브랜드가 차별화할 수 있는 각도 3가지 제안
```

## 2. 이메일 마케팅

### 2-1. 뉴스레터 초안

**❌ BAD**
```
뉴스레터 써줘
```

**✅ GOOD**
```
HTML 뉴스레터 본문 텍스트 작성 (HTML 태그 없이, 구조만).

브랜드: [브랜드명]
주제: [이번 호 주제]
독자: [구독자 특성]
섹션 구성:
1. 인사말 + 이번 호 요약 (3문장)
2. 메인 기사: [주제] — 400자 이내
3. 제품/이벤트 소개: [내용] — 200자 이내
4. CTA 버튼 텍스트 3가지 제안
5. 마무리 문구

톤: [브랜드 보이스]
```

---

### 2-2. 제품 런칭 이메일 시리즈

```
신제품 런칭 이메일 3단계 시리즈 작성.

제품: [제품명 + 설명]
발송 일정: D-7 / D-1 / D-Day

이메일 1 (D-7, 티저): 궁금증 유발, 제품 이름 공개 안 함, 200자
이메일 2 (D-1, 예고): 제품 공개 + 핵심 혜택 3가지, 사전 등록 CTA, 300자
이메일 3 (D-Day, 런칭): 공식 출시 + 얼리버드 혜택 + 강한 CTA, 400자

각 이메일: 제목 줄(subject line) 3가지 제안 포함.
```

---

### 2-3. 제목 줄(Subject Line) A/B 테스트

```
아래 이메일 내용에 맞는 제목 줄(Subject Line) 10개 생성.

이메일 내용: [이메일 주제/내용 한 줄 요약]
목표: 오픈율 최대화
수신자: [구독자 특성]

형식 다양하게:
- 질문형 2개
- 숫자 포함 2개
- 개인화 ([이름] 사용) 2개
- 긴박감/희소성 2개
- 혜택 직접 제시 2개

각 제목 줄 40자 이내. 이모지 포함/미포함 각각 제안.
```

---

### 2-4. 재구매 유도 이메일

```
구매 후 30일 경과 고객 대상 재구매 유도 이메일 초안 작성.

이전 구매 제품: [제품명]
추천 후속 제품: [제품명 + 연관성]
인센티브: [할인율/쿠폰]

구조:
1. 개인화 인사 ({{first_name}} 변수 사용)
2. 이전 구매에 대한 감사 + 가치 확인 (2문장)
3. 자연스러운 업셀/크로스셀 제안
4. 시간 제한 인센티브
5. CTA 1개 (명확하게)

전체 길이: 250자 이내. 톤: 친근하고 자연스럽게.
```

---

### 2-5. 장바구니 이탈 복구 이메일

```
장바구니에 상품을 담고 24시간 내 미결제한 고객 대상 이메일 작성.

상품: [상품명]
이탈 가능 이유 추정: [가격/결정 고민/다른 옵션 탐색]
제공할 인센티브: [5% 추가 할인 or 무료배송]

시리즈 2개:
- 1차 (1시간 후): 부드럽게, 인센티브 없이, "아직 고민 중이신가요?"
- 2차 (24시간 후): 직접적으로, 인센티브 포함, 재고 한정 언급

각 이메일: 제목 줄 2가지 + 본문 200자 이내 + CTA 버튼 텍스트.
```

---

### 2-6. 환영(Welcome) 이메일 시리즈

```
신규 구독자 대상 온보딩 이메일 시리즈 3개 작성.

브랜드: [브랜드명]
구독자가 기대하는 것: [혜택/콘텐츠 유형]

이메일 1 (즉시): 환영 + 브랜드 소개 + 즉시 혜택 (쿠폰)
이메일 2 (3일 후): 베스트셀러 소개 + 사용 후기
이메일 3 (7일 후): 커뮤니티/SNS 참여 유도 + 첫 구매 독려

각 이메일: 제목 줄 + 본문 300자 이내 + CTA.
```

## 3. 랜딩 페이지 카피

### 3-1. 히어로 섹션 카피

```
랜딩 페이지 히어로 섹션 카피 작성.

제품/서비스: [설명]
타겟 방문자: [설명]
핵심 가치 제안(USP): [한 줄로]

출력:
- 메인 헤드라인: 60자 이내, 타겟의 욕구나 문제를 직접 겨냥
- 서브 헤드라인: 120자 이내, 헤드라인 보완 + 혜택 구체화
- CTA 버튼 텍스트: 5가지 제안 (동사로 시작)
- 신뢰 지표 한 줄: 숫자나 사실로 신뢰 구축

헤드라인 3가지 변형 제공.
```

---

### 3-2. 혜택/기능 섹션 카피

```
랜딩 페이지 혜택 섹션 카피 작성 (6개 항목).

제품: [제품명]
주요 기능: [기능 목록]

각 항목 형식:
- 아이콘 키워드: [2~3단어]
- 제목: [15자 이내]
- 설명: [50자 이내, 기능(Feature)이 아닌 혜택(Benefit) 중심]

기능 → 혜택 변환 원칙 적용:
"XX 기능이 있어요" X → "여러분이 YY를 할 수 있어요" O
```

---

### 3-3. FAQ 섹션

```
랜딩 페이지 FAQ 10개 작성.

제품/서비스: [설명]
예상 구매 장벽: [가격/신뢰/복잡성/호환성 등]
타겟: [설명]

형식:
Q: [질문 — 실제 고객이 할 법한 말투로]
A: [답변 — 150자 이내, 장벽 제거 + 자신감 부여]

마지막 2개는 반드시 가격과 환불 정책 관련.
```

## 4. 소셜 미디어 콘텐츠

### 4-1. 인스타그램 캡션

```
인스타그램 피드 게시물 캡션 5개 작성.

브랜드: [브랜드명]
게시물 주제: [설명]
톤: [브랜드 보이스]

각 캡션 구조:
1. 첫 줄 후킹 (피드에서 잘리는 부분, 20자 이내)
2. 본문 2~3문장
3. CTA (저장/링크/댓글 유도)
4. 해시태그 10개 (관련성 높은 것, 너무 포화되지 않은 것 섞어서)

각 캡션은 서로 다른 각도에서 접근.
```

---

### 4-2. 유튜브 설명란 템플릿

```
유튜브 영상 설명란 템플릿 작성.

영상 주제: [설명]
채널: [채널명]
핵심 키워드: [SEO 키워드 3~5개]

구조:
1. 첫 2줄 (접히기 전 노출): 영상 핵심 + 클릭 유도 (키워드 자연 포함)
2. 타임스탬프 목록 (챕터 5개 예시)
3. 링크 섹션: 홈페이지, SNS, 구독 CTA
4. 키워드 단락: 자연스럽게 키워드 포함된 200자 설명
5. 해시태그 3개 (#)

전체 500자 이내.
```

## 5. SQL (데이터 추출)

### 5-1. 기간별 매출 집계

**❌ BAD**
```
매출 쿼리 짜줘
```

**✅ GOOD**
```
PostgreSQL 쿼리 작성.

테이블: orders(id, customer_id, product_id, amount, created_at, channel)
목표: 채널별 일별 매출 집계 (최근 30일)
결과 열: date, channel, total_revenue, order_count, avg_order_value
정렬: date DESC, total_revenue DESC
날짜 형식: YYYY-MM-DD
```

---

### 5-2. 코호트 분석 쿼리

```
월별 신규 고객 코호트의 재구매율을 보는 SQL 작성.

테이블:
- orders(id, customer_id, amount, created_at)
- customers(id, signup_date)

목표: 각 코호트(첫 구매 월 기준)가 이후 각 월에 재구매한 비율
결과: 코호트 월 × 이후 월 수 매트릭스
DB: PostgreSQL (WITH, DATE_TRUNC 사용 가능)
각 쿼리 구문마다 주석으로 설명 포함.
```

---

### 5-3. 채널별 어트리뷰션 쿼리

```
채널별 전환 기여 현황 SQL 작성.

테이블:
- conversions(id, customer_id, order_id, channel, conversion_type, created_at)
- orders(id, customer_id, amount, created_at)

목표: 채널별 전환건수, 기여 매출, CPA(비용/전환, cost 테이블 있다고 가정)
기간: 최근 7일
결과: channel, conversions, attributed_revenue, cpa
라스트 터치 어트리뷰션 기준.
```

---

### 5-4. 이탈 위험 고객 세그먼트

```
재구매 이탈 위험 고객 세그먼트 SQL 작성.

테이블: orders(id, customer_id, amount, created_at)
로직:
- 평균 구매 주기 계산 (고객별)
- 마지막 구매일이 평균 구매 주기의 1.5배 이상 지난 고객
- 단, 총 구매 2회 이상인 고객만

결과: customer_id, last_purchase_date, avg_days_between_orders, days_since_last_order
정렬: days_since_last_order DESC
DB: PostgreSQL
```

---

### 5-5. 광고 성과 데이터 집계

```
광고 성과 데이터 집계 SQL 작성.

테이블: ad_performance(campaign_id, campaign_name, channel, date, impressions, clicks, cost, conversions, revenue)

목표: 캠페인별 주간 집계 (ISO 주 기준)
결과 열: week, campaign_name, channel, total_impressions, total_clicks, ctr, total_cost, total_conversions, total_revenue, roas, cpa

계산식:
- CTR = clicks / impressions * 100 (소수점 2자리)
- ROAS = revenue / cost * 100
- CPA = cost / conversions (conversions > 0일 때만)

정렬: week DESC, roas DESC
```

---

### 5-6. RFM 분석 기초 쿼리

```
RFM(Recency, Frequency, Monetary) 분석 SQL 작성.

테이블: orders(id, customer_id, amount, created_at)
기준일: CURRENT_DATE

각 고객별:
- R: 마지막 구매일로부터 경과 일수
- F: 총 구매 횟수
- M: 총 구매 금액

그 다음, R/F/M 각각을 1~5점으로 ntile 처리
rfm_score = R점수 || F점수 || M점수 (문자 연결)

DB: PostgreSQL
주석으로 각 단계 설명 포함.
```
