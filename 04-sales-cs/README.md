# 영업 / CS — GitHub Copilot 2일 심화 과정

> **대상**: B2B 영업 담당자, 인사이드 세일즈, CS/CX 팀, 고객 성공(Customer Success) 담당자
> **전제 조건**: `00-basics/` 5개 문서 완료
> **총 소요 시간**: Day 1 (3~4시간) + Day 2 (3~4시간) = 6~8시간

## 이 과정에서 얻는 것

영업과 CS는 **매일 수십 통의 이메일, 제안서, 응대 스크립트, 리포트**를 다룹니다. 반복적인 텍스트 작업에 쓰는 시간이 전체 업무의 40~60%를 차지한다는 연구 결과도 있습니다.

Copilot을 도입하면 이렇게 바뀝니다:

| 작업 | 기존 소요 시간 | Copilot 활용 후 | 절감 |
|------|--------------|-----------------|------|
| 콜드 이메일 1통 작성 | 20~30분 | 3~5분 (검토 포함) | 85% |
| 제안서 초안 | 2~4시간 | 30~45분 | 80% |
| CS 응대 매크로 1개 | 15~20분 | 2~3분 | 85% |
| 월간 매출 리포트 | 3~5시간 | 45~60분 | 80% |
| 팔로업 시퀀스 3단계 | 1~2시간 | 15~20분 | 85% |

단순히 빠른 게 전부가 아닙니다. Copilot이 초안을 잡아주면 **여러분은 전략과 관계에 집중**할 수 있습니다. 그게 진짜 가치입니다.

## 학습 원칙

1. **Copilot은 초안 생성기** — 최종 발송 전 반드시 사람이 검토
2. **개인화는 변수로** — `{{firstName}}`, `{{company}}`, `{{painPoint}}` 시스템을 체득
3. **정직한 세일즈** — 과장·허위 제안 초안은 즉시 폐기. Copilot이 만들어도 책임은 발송자
4. **작게 시작** — 템플릿 1개를 완벽하게 만드는 게 10개를 어설프게 만드는 것보다 낫습니다
5. **루프를 돌려라** — 프롬프트 → 초안 확인 → 개선 요청 → 재확인, 이 흐름이 전부입니다
