# 영업 / CS Copilot 치트시트

> 이 한 장을 모니터 옆에 붙여두세요. 가장 자주 쓰는 것들만 모았습니다.

---

## 황금 프롬프트 공식

```
[역할/톤] + [대상] + [목적] + [형식/길이] + [금지 사항]
```

**예시**
```
B2B SaaS 영업 담당자로서, 제조업 IT팀장에게 보내는
콜드 이메일 초안 작성. 150자 이내, 클릭률 높은 제목 3개 포함.
과장 표현("혁신적", "독보적") 금지.
```

---

## 세일즈 퍼널별 핵심 프롬프트

| 단계 | 할 일 | 프롬프트 키워드 |
|------|-------|----------------|
| **Awareness** | 콜드 이메일, LinkedIn 메시지 | "콜드 이메일 + {{painPoint}} + 150자 이내" |
| **Consideration** | 팔로업, 데모 후 요약, 제안서 | "팔로업 3단계 시퀀스", "데모 미팅 후 요약 이메일" |
| **Decision** | 최종 제안, 할인 협상, 계약 | "최종 제안 이메일 + 유효기간 + 압박 없이" |
| **Retention** | 이탈 방지, 업셀, 갱신 | "이탈 신호 감지 + 진심 어린 관심 톤" |

## 개인화 변수 시스템

이메일에 아래 변수를 넣으면 Copilot이 각 리드에 맞게 채워줍니다.

```
{{firstName}}        수신자 이름
{{company}}          회사명
{{jobTitle}}         직책
{{industry}}         업종
{{painPoint}}        추정 Pain Point
{{currentTools}}     현재 쓰는 유사 솔루션
{{senderName}}       발신자 이름
{{senderTitle}}      발신자 직책
{{meetingDate}}      미팅 날짜
{{nextSteps}}        다음 단계
```

## 이메일 톤 조절 명령어

| 원하는 톤 | 프롬프트에 추가할 말 |
|-----------|---------------------|
| 따뜻하고 공감적 | "고객 감정을 충분히 인정하는 따뜻한 톤" |
| 간결하고 프로페셔널 | "핵심만, 150자 이내, 영업 냄새 없이" |
| 자신 있되 부드럽게 | "자신감 있지만 강요하지 않는 톤" |
| 공식적 | "격식체, 법적 표현 피하되 비즈니스 문어체" |
| 친근한 | "구어체, 짧은 문장, 말하듯 쓰기" |

## CS 응대 5대 상황 즉시 프롬프트

```
1. 환불 수락
"환불 수락 이메일. 고객명: {{firstName}}, 금액: {{amount}}.
진심 어린 사과 + 처리 기간 {{days}}일 안내. 5문장 이내."

2. 환불 거절 + 대안 제시
"환불 거절 이메일. 사유: {{reason}}.
공감 먼저, 정책 설명, 대안({{alternative}}) 제시. 단호하되 차갑지 않게."

3. 배송/납품 지연 사과
"배송 지연 사과 이메일. 원래 {{originalDate}} → 새 예정일 {{newDate}}.
사유 간략 설명, 보상 {{compensation}}, 추적 방법 안내."

4. 기술 문의 응대
"기술 문의 응대. 문의: {{inquiry}}. 해결책: {{solution}}.
단계별로 쉽게, 전문 용어 최소화. 추가 문의 채널 포함."

5. 컴플레인 에스컬레이션 (내부)
"컴플레인 에스컬레이션 내부 이메일. 고객: {{client}}.
사실 중심, 타임라인, 제안 조치, 긴급도 명시."
```

## 엑셀/스프레드시트 수식 요청 패턴

```
"엑셀 수식: [열 설명] 에서 [조건] 인 경우 [계산].
Excel/Google Sheets 양쪽 호환으로."
```

**자주 쓰는 수식 키워드**
- `COUNTIF` / `COUNTIFS` — 조건부 개수
- `SUMIF` / `SUMIFS` — 조건부 합계
- `XLOOKUP` — 테이블 참조 (VLOOKUP 대체)
- `IFERROR` — 오류 처리
- `TEXT(TODAY(),"YYYY-MM-DD")` — 오늘 날짜

## 반복 사용 프롬프트 5선

1. **콜드 이메일 생성**
```
{{firstName}}, {{company}} ({{industry}}) 대상 콜드 이메일.
Pain Point: {{painPoint}}. 제목 3개 + 본문 150자. 영업 냄새 최소화.
```

2. **팔로업 시퀀스**
```
{{firstName}}에게 응답 없음. Day3 / Day7 / Day14 팔로업 3단계.
각각 제목 + 100자 이내 + 새 가치 1개씩 추가.
```

3. **제안서 초안**
```
{{company}} 대상 {{productName}} 제안서 초안.
섹션: 문제 → 솔루션 → 가격 → 도입 사례 → 일정.
업종 {{industry}} 맞춤 표현 사용.
```

4. **CS 응대 3가지 톤**
```
아래 응대 이메일을 따뜻한 / 간결한 / 상세한 3가지 톤으로 재작성.
[원본 붙여넣기]
```

5. **미팅록 구조화**
```
아래 메모를 회의록으로 변환. 요약 / 고객 발언 / Pain Point /
다음 단계(표) 포함. 영업 기회 점수 1~10 평가.
[메모 붙여넣기]
```

## 절대 하지 말 것

- 실제 고객 데이터를 프롬프트에 붙여넣기 (개인정보 보호법)
- Copilot 초안을 검토 없이 바로 발송
- 경쟁사 비방 초안 생성 요청
- 가격·성능 수치 Copilot이 만든 것 그대로 사용 (반드시 확인)
- 과장·오해를 유발하는 표현 그대로 쓰기
