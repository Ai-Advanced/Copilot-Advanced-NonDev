# 01. 영업/CS 담당자의 하루 재분석 — Copilot 15가지 활용

## 학습 목표

- 영업/CS 하루 업무를 Copilot 관점에서 분해하고 자동화 가능한 부분 찾기
- Copilot이 실제로 어떤 영업/CS 작업을 처리할 수 있는지 15가지 시나리오로 확인
- Before/After 3가지 비교로 시간 절감의 실체를 체감
- 이 과정의 학습 방향과 실습 시나리오 이해

**예상 소요**: 30분

---

## 1부. 영업/CS 담당자의 하루를 해부해보면

아침에 출근해서 퇴근할 때까지, 영업이나 CS 담당자의 하루는 대략 이렇게 생겼습니다.

```
09:00 - 어제 들어온 CS 티켓 확인 + 응대 이메일 작성 (1시간)
10:00 - 신규 리드 리스트 검토 + 콜드 이메일 작성 (1.5시간)
11:30 - 고객 미팅 준비 (사전 조사, 데모 자료 정리)
14:00 - 고객 미팅
15:00 - 미팅 후 팔로업 이메일 + 회의록 작성 (45분)
15:45 - 제안서 작성 or 수정 (1~2시간)
17:30 - 파이프라인 업데이트 (CRM 입력)
18:00 - 주간 리포트 초안 작성
```

이 하루에서 **Copilot이 개입할 수 있는 지점**을 표시해보겠습니다.

| 시간대 | 업무 | Copilot 개입 가능 여부 | 예상 절감 |
|--------|------|----------------------|-----------|
| 09:00 | CS 응대 이메일 | ✅ 매크로 초안 생성 | 60~70% |
| 10:00 | 콜드 이메일 작성 | ✅ 개인화 초안 생성 | 80~85% |
| 11:30 | 미팅 사전 조사 브리핑 | ✅ 공개 정보 기반 브리핑 | 50% |
| 14:00 | 고객 미팅 | ❌ 사람의 영역 | - |
| 15:00 | 팔로업 이메일 | ✅ 미팅 메모 → 이메일 | 75% |
| 15:00 | 회의록 작성 | ✅ 메모 → 구조화 | 70% |
| 15:45 | 제안서 작성 | ✅ 구조 + 초안 생성 | 75% |
| 17:30 | CRM 입력 | 🔶 스크립트로 반자동화 | 40% |
| 18:00 | 주간 리포트 | ✅ 데이터 → 리포트 초안 | 70% |

**핵심**: 미팅 자체를 빼면, 영업/CS 업무의 **약 70~80%는 텍스트 생성·편집**입니다. Copilot은 바로 이 부분을 담당합니다.

## 2부. Copilot 15가지 활용 시나리오

### 그룹 A. 아웃바운드 영업 (Lead Generation → Close)

**1. 콜드 이메일 개인화 생성**
리드 리스트(이름, 회사, 업종, 직책)를 넣으면 각각 다른 개인화 초안을 생성합니다. 100명 리드에게 100가지 다른 이메일을 만드는 데 30분이면 충분합니다.

**2. 팔로업 시퀀스 제작**
응답 없는 리드에게 Day 3, Day 7, Day 14로 보낼 팔로업 이메일 3단계를 한 번에 만들어 냅니다. 각 단계마다 새로운 가치나 관점을 추가해서 반복 느낌을 없앱니다.

**3. 콜드 콜 스크립트**
전화하기 전 미리 오프닝 스크립트, 예상 반박, 대화 가이드를 준비합니다. 상황별(게이트키퍼, 결정권자, 바쁜 상황) 버전도 각각 생성할 수 있습니다.

**4. 데모 미팅 후 팔로업**
미팅에서 메모한 내용을 붙여넣으면, 미팅 요약 + 고객 관심사 + 다음 단계가 포함된 팔로업 이메일이 나옵니다. 미팅 직후 10분 안에 발송 가능합니다.

**5. 오브젝션(반박) 처리 응답**
"예산이 없어요", "현재 솔루션이 있어요", "복잡할 것 같아요" 같은 반박에 대한 응대 스크립트를 미리 준비합니다. 실제 미팅에서 당황하지 않게 됩니다.

### 그룹 B. 제안서 & 계약

**6. 제안서 초안 생성**
고객사 이름, 업종, 주요 니즈를 넣으면 문제-솔루션-가격-사례-일정 구조의 제안서 초안이 나옵니다. 처음부터 쓰는 게 아니라 초안을 편집하는 방식으로 전환됩니다.

**7. 견적서 + 가격 옵션 표**
요금제별 기능 비교 표, 볼륨 할인 계산, 연간/월간 비교를 Markdown 표로 즉시 생성합니다. Excel에 붙여넣거나 PDF로 만들 수 있습니다.

**8. RFP 응답 구조화**
고객사가 보낸 RFP(제안 요청서) 요구사항 목록을 붙여넣으면, 각 요구사항에 대한 응답 구조를 잡아줍니다. 빠진 항목 없이 체계적으로 대응할 수 있습니다.

**9. 계약서 검토 지원**
계약서 조항을 붙여넣고 "이 조항에서 우리 회사에 불리한 부분이 있나?" 라고 물으면 주의할 지점을 짚어줍니다. (법적 효력은 없으므로 법무팀 검토는 별도로 필수)

### 그룹 C. CS 응대

**10. 상황별 응대 매크로**
환불, 배송 지연, 기술 문의, 컴플레인 등 반복되는 상황에 대한 응대 매크로를 만들어 둡니다. 한 번 만들어두면 상황에 맞게 변수만 바꿔서 씁니다.

**11. 이탈 방지 이메일**
사용량 감소나 불만 징후가 보이는 고객에게 보낼 '근황 확인 + 도움 제안' 이메일을 자연스럽게 작성합니다. 영업 냄새 없이, 진심 어린 관심처럼 느껴지도록 합니다.

**12. NPS 낮은 고객 대응**
NPS 점수와 피드백을 붙여넣으면 해당 고객 상황에 맞는 개인화된 후속 이메일이 나옵니다. 형식적인 사과문이 아닌, 실질적 해결 의지를 보여주는 내용으로.

### 그룹 D. 리포트 & 자동화

**13. 파이프라인 리포트 초안**
이번 주 딜 현황 데이터를 텍스트나 CSV로 넣으면 임원 보고용 주간 리포트 초안이 나옵니다. 숫자 해석과 인사이트도 같이 제안해줍니다.

**14. 엑셀/시트 수식 생성**
파이프라인 시트에서 필요한 SUMIFS, XLOOKUP, 조건부 서식 수식을 즉시 만들어줍니다. 함수 이름을 몰라도 "이런 걸 하고 싶어"라고 말하면 됩니다.

**15. 반복 업무 스크립트**
매월 동일한 보고서 형식으로 데이터를 재정리하는 작업, 리드 리스트 포맷 통일, 이메일 발송 로그 자동 업데이트 등을 Google Apps Script로 자동화합니다.

## 3부. Before / After — 실제 차이를 눈으로 확인

### Before/After 1: 콜드 이메일 작성

**Before (Copilot 없이)**

상황: 제조업 IT팀장 이승현 차장에게 보내는 첫 콜드 이메일

```
[작성 과정]
1. 어떻게 시작할지 5분 고민
2. "안녕하세요" 쓰고 지우고 "이승현 차장님께" 로 수정
3. 회사 소개 문장 작성, 과도하게 어필하는 느낌이라 다시 수정
4. 혜택 설명 쓰다가 너무 길어서 다시 줄이기
5. CTA 쓰고, 너무 강압적인 것 같아서 또 수정
6. 제목 5개 생각하다 그냥 "CloudPipe 소개드립니다"로 결론

총 소요 시간: 25~30분
결과물 품질: 무난하지만 개인화 없음
```

**After (Copilot 활용)**

```
프롬프트:
B2B SaaS "CloudPipe" 콜드 이메일. 수신자: 이승현 차장, 제조업 IT팀장.
Pain Point: 현재 데이터 파이프라인이 수동이고 개발팀 리소스 부족.
제목 3개 + 본문 150자. 영업 냄새 최소화. 서명: "김민준 / 영업팀".
```

```
[Copilot 결과 — 약 20초]

제목 옵션:
A. "이승현 차장님, 개발팀 없이도 ETL 자동화하는 팀들이 있습니다"
B. "제조업 IT팀에서 수작업 파이프라인 줄인 방법 (3분 요약)"
C. "차장님 팀, 혹시 이런 상황 아닌가요?"

본문:
이승현 차장님, 안녕하세요.
제조업 IT팀에서 데이터 파이프라인을 수동으로 관리하다 보면
개발 리소스가 예상보다 훨씬 많이 소모되더라고요.
CloudPipe를 도입한 팀들은 평균 ETL 작업 시간을 70% 줄였습니다.
15분만 시간 내주시면, 현재 상황에 맞게 어떻게 적용할 수 있는지 보여드릴게요.

김민준 / 영업팀 / tangunsoft@example.com
```

총 소요 시간: **3~5분** (검토 및 수정 포함)
결과물 품질: Pain Point 반영, 개인화, 구체적 수치 포함

### Before/After 2: CS 응대 이메일

**Before (Copilot 없이)**

상황: 고객이 "서비스가 3시간 다운됐다, 당장 환불해달라"는 컴플레인 이메일 수신

```
[작성 과정]
1. 화난 고객이라 어떻게 시작할지 막막
2. "죄송합니다"만 반복하는 초안 작성
3. 환불 정책 찾아보기 (5분)
4. 어떤 보상을 제안할지 팀장에게 물어보기 (10분)
5. 결국 "확인 후 연락드리겠습니다"로 발송

총 소요: 20~30분
결과물: 애매한 답변, 고객 불만 지속
```

**After (Copilot 활용)**

```
프롬프트:
CS 응대 이메일. 고객 박지영님이 서비스 3시간 다운 컴플레인 + 환불 요청.
우리 정책: SLA 99.9% 보장, 장애 시 서비스 크레딧 1일치 제공.
이번 장애 사유: 데이터센터 네트워크 이슈 (외부 원인).
톤: 진심 어린 사과 + 명확한 보상안 + 재발방지 약속.
환불 대신 크레딧 제안. 5문장 이내.
```

```
[Copilot 결과 — 약 15초]

박지영님,

3시간 동안 서비스를 이용하지 못하셔서 정말 불편하셨겠습니다. 진심으로 사과드립니다.
이번 장애는 외부 데이터센터 네트워크 이슈로 발생했으며,
이미 복구 완료 후 원인 분석을 마쳤습니다.
보상으로 서비스 이용료 1일치에 해당하는 크레딧을 계정에 즉시 적립해드렸으며,
재발 방지를 위한 이중화 조치를 이번 주 안에 완료할 예정입니다.
추가 문의가 있으시면 언제든 cs@tangunsoft.com으로 연락 주세요.

[담당자명] / 고객경험팀
```

총 소요: **2~3분**
결과물: 사과 + 원인 + 보상 + 재발방지 + 연락처 포함

### Before/After 3: 주간 파이프라인 리포트

**Before (Copilot 없이)**

```
[작성 과정]
1. 엑셀에서 데이터 복사
2. PPT 또는 워드에 표 붙여넣기
3. 숫자 옆에 코멘트 달기 (30분)
4. 임원 메일 양식에 맞게 포맷 정리 (20분)
5. 오탈자 검토 (10분)

총 소요: 1~1.5시간
```

**After (Copilot 활용)**

```
프롬프트:
영업팀 주간 리포트 Markdown 초안. 임원 보고용.

이번 주 데이터:
- 신규 리드: 28건 (목표 25건, +12%)
- 미팅: 8건 (목표 10건, -20%)
- 제안서 발송: 3건
- 클로즈 딜: 1건 (1,200만원)
- 파이프라인 총액: 4억 8천만원

인사이트도 3~5개 포함. 다음 주 액션 1~3개 제안.
```

결과: **2분 안에** 수치 해석, 인사이트, 액션 플랜이 포함된 임원 보고 초안 완성

## 4부. 이 과정에서 다루는 것과 다루지 않는 것

### 다룰 것

- 1:1 개인화 세일즈 이메일 (콜드, 팔로업, 이탈방지, 갱신)
- 제안서/견적서 구조 + Copilot으로 초안 생성
- CS 응대 매크로 5가지 상황별 완성
- CRM 데이터 관리 (엑셀/Google Sheets) + 수식 자동화
- 대량 발송 설정 (Google Apps Script + 개인정보 준수)
- 매출/파이프라인 리포트 반자동화

### 다루지 않을 것

- 브랜드 캠페인 이메일, 뉴스레터 (→ 03-marketer)
- 딥 프로그래밍 (Python, SQL 고급 분석)
- 실제 CRM 시스템 내부 설정 (Salesforce, HubSpot 설정 방법)
- 협상 전략 자체 (Copilot은 문서 초안 도구. 협상은 사람이)

### 실습 2. 첫 Copilot Chat 경험

VS Code의 Copilot Chat 사이드바를 열고, 아래 프롬프트를 그대로 붙여넣어 실행해보세요.

```
B2B SaaS 영업 담당자입니다. 
아래 상황에 맞는 콜드 이메일 제목 5개를 만들어주세요.

상황:
- 수신자: 이커머스 회사의 데이터 분석 팀장
- 우리 제품: 데이터 파이프라인 자동화 SaaS
- 수신자 Pain Point: 수작업 데이터 정리에 시간을 너무 많이 씀

조건:
- 각 제목 30자 이내
- 클릭하고 싶은 제목 (숫자 or 질문 포함)
- 영업 냄새 최소화
```

→ 결과 5개를 보고 어느 것이 가장 클릭하고 싶은지 판단해보세요.

### 실습 3. 결과 평가 기준 만들기

좋은 콜드 이메일 제목의 기준을 Chat에 물어보세요:

```
B2B 콜드 이메일 제목을 평가하는 기준 5가지를 알려줘.
각 기준에 BAD 예시와 GOOD 예시도 1개씩 포함.
```

이 기준을 앞으로 Copilot 결과를 검토할 때 사용하세요.

1. 영업/CS 업무의 70~80%는 텍스트 생성/편집이라 Copilot 개입 여지가 매우 큼
2. Copilot은 **초안 생성기** — 미팅, 협상, 관계 구축은 여전히 사람의 몫
3. **15가지 시나리오** 모두 이 과정에서 직접 실습
4. Before/After의 핵심 차이: 시간 절감이 아니라 **더 많은 리드에게 더 좋은 이메일을**
5. 프롬프트에 Pain Point, 톤, 길이, 금지사항 4가지를 항상 명시
