# 02. 이메일 템플릿 & 개인화 시스템

## 학습 목표

- 콜드 이메일, 팔로업, 이탈방지 이메일의 구조와 원리 이해
- `{{변수}}` 기반 개인화 시스템을 직접 설계하고 적용
- Copilot으로 리드 리스트 → 개인화 초안 100개를 만드는 워크플로우 체득
- BAD vs GOOD 이메일 3가지 비교로 실력 간격 체감

**예상 소요**: 60분 (실습 포함)

---

## 1부. 이메일 개인화가 왜 중요한가

### 숫자로 보는 현실

B2B 이메일 마케팅 통계(업계 평균)를 보면, 개인화 이메일과 일반 이메일의 차이가 분명합니다.

| 지표 | 일반 이메일 | 개인화 이메일 | 차이 |
|------|------------|------------|------|
| 오픈율 | 15~20% | 29~35% | +2배 |
| 클릭율 | 2~3% | 5~8% | +2.5배 |
| 응답율 (콜드) | 1~3% | 8~15% | +5배 |
| 미팅 전환율 | 0.5~1% | 3~5% | +5배 |

"개인화"가 단순히 이름 넣는 수준에서 끝나면 의미가 없습니다. 진짜 개인화는 **수신자의 상황, 업종, Pain Point, 현재 쓰는 도구**까지 반영하는 것입니다.

그리고 Copilot은 이걸 100명에게 각각 다르게 만들어줄 수 있습니다.

## 2부. 개인화 변수 시스템 설계

### 변수 시스템이란?

```
"안녕하세요, {{firstName}}님. {{company}}에서 {{jobTitle}}으로 계시는 것 봤는데요."
```

위처럼 `{{변수명}}` 형태로 자리를 만들어두고, 리드 데이터로 채우는 방식입니다. 이메일 템플릿 1개로 수백 명에게 각각 다른 이메일처럼 보이도록 할 수 있습니다.

### 기본 변수 세트 (영업/CS용)

```
개인 정보:
  {{firstName}}        → 이름 (예: 김민준)
  {{lastName}}         → 성 (예: 김)
  {{fullName}}         → 전체 이름 (예: 김민준)
  {{jobTitle}}         → 직책 (예: 데이터팀 팀장)
  {{email}}            → 이메일

회사 정보:
  {{company}}          → 회사명 (예: 스타트업 A)
  {{industry}}         → 업종 (예: 이커머스)
  {{companySize}}      → 규모 (예: 50~100명)
  {{region}}           → 지역 (예: 서울 강남)

세일즈 컨텍스트:
  {{painPoint}}        → 추정 Pain Point (영업팀이 직접 입력)
  {{currentTool}}      → 현재 쓰는 유사 솔루션 (예: 엑셀, Zapier)
  {{triggerEvent}}     → 연락 계기 (예: 채용공고, 뉴스, 이벤트 만남)
  {{referrer}}         → 소개해준 사람 (있는 경우)

발신자:
  {{senderName}}       → 발신자 이름
  {{senderTitle}}      → 발신자 직책
  {{senderEmail}}      → 발신자 이메일
  {{senderPhone}}      → 발신자 전화번호

제품/솔루션:
  {{productName}}      → 제품명
  {{keyBenefit}}       → 핵심 혜택 (1문장)
  {{caseCompany}}      → 비슷한 사례 회사명
  {{caseMetric}}       → 성과 지표 (예: "3개월 만에 70% 시간 절감")
```

### Fallback 값 설정 (변수가 없을 때)

변수 데이터가 없는 리드가 있을 때 이메일이 어색해지지 않으려면 기본값(Fallback)을 정해야 합니다.

```
{{firstName}} 없을 때   → "안녕하세요" (이름 없이 시작)
{{company}} 없을 때     → "귀사" 또는 생략
{{painPoint}} 없을 때   → 업종 기반 일반 Pain Point 문장
{{currentTool}} 없을 때 → "현재 사용하시는 툴과 비교해서"
{{triggerEvent}} 없을 때 → 연락 계기 문장 전체 생략
```

## 3부. BAD vs GOOD 이메일 비교

### 비교 1: 콜드 이메일

**❌ BAD — 개인화 없는 콜드 이메일**

```
제목: CloudPipe 소개드립니다

이철수 팀장님,

안녕하세요. 저는 탠건소프트 김민준이라고 합니다.
저희 회사의 CloudPipe 솔루션을 소개드리고 싶어 연락드립니다.

CloudPipe는 데이터 파이프라인 자동화 솔루션으로, 많은 기업들이
사용하고 있는 혁신적인 제품입니다. 귀사에서도 꼭 도입해보시길 추천드립니다.

관심 있으시면 연락 주세요.

김민준 드림
```

**문제점**:
- 수신자가 특별히 선택받은 느낌이 전혀 없음
- "혁신적인" 같은 상투어 사용
- "관심 있으시면" — 모호하고 수동적인 CTA
- 왜 이 사람에게 보냈는지 이유 없음
- 수신자 상황이나 Pain Point 전혀 반영 안 됨

---

**✅ GOOD — Copilot으로 생성한 개인화 콜드 이메일**

```
프롬프트:
B2B SaaS "CloudPipe" 콜드 이메일.
수신자: 이철수, 이커머스 회사 데이터팀 팀장, 50인 기업.
Pain Point: 현재 엑셀로 수동 ETL하고 있어 개발팀 리소스 부족.
최근 트리거: 데이터 엔지니어 채용공고 올라온 것 발견.
제목 3개 + 본문 170자. 영업 냄새 최소화.
```

```
제목 옵션:
A. "이철수 팀장님, 데이터 엔지니어 채용 전에 먼저 확인해보실 것 있어요"
B. "이커머스 팀에서 엑셀 ETL 없애는 데 3주 걸린 이야기"
C. "팀장님 회사랑 비슷한 상황에서 개발팀 없이 파이프라인 자동화한 방법"

본문:
이철수 팀장님, 안녕하세요.

최근 데이터 엔지니어 채용 공고를 보게 됐는데요.
혹시 ETL 자동화 때문에 리소스를 더 뽑아야 하는 상황인 건 아닐까 싶어 연락드렸습니다.

저희가 비슷한 상황의 이커머스 팀들과 작업해보니,
채용보다 먼저 파이프라인 자동화 도구를 도입하는 게
빠르고 비용도 훨씬 덜 들더라고요.

15분만 시간 내주시면 현재 상황에 딱 맞는 접근법을 보여드릴 수 있을 것 같습니다.

김민준 / 탠건소프트 영업팀 / 010-xxxx-xxxx
```

**좋은 이유**:
- 채용공고라는 구체적 트리거 활용 (내가 주목하고 있다는 신호)
- 수신자의 Pain Point(엑셀 ETL, 리소스 부족) 정확히 반영
- 수신자 관점에서 시작 ("혹시 이런 상황 아닌가요?")
- 구체적이고 행동 가능한 CTA

---

### 비교 2: 팔로업 이메일

**❌ BAD — 재촉하는 팔로업**

```
제목: 안녕하세요, 확인 부탁드립니다

이철수 팀장님,

지난번에 보내드린 이메일 확인하셨나요?
바쁘신 건 알지만 답장 좀 주시면 감사하겠습니다.

기다리고 있겠습니다.

김민준
```

**문제점**:
- 죄책감 유발 ("확인하셨나요?")
- 새로운 가치가 전혀 없음 — 리마인드만
- 수동적인 기다림 표현
- 수신자가 이 이메일에서 얻는 것이 없음

---

**✅ GOOD — 가치를 추가하는 팔로업**

```
프롬프트:
첫 콜드 이메일 후 7일 경과, 응답 없음.
이철수 팀장(이커머스, 데이터팀)에게 보내는 팔로업.
새로운 가치로 이커머스 업종 ETL 자동화 케이스 스터디 공유.
100자 이내, 압박 없이.
```

```
제목: "이커머스 팀이 ETL 수동 작업 없앤 방법 (사례 공유)"

이철수 팀장님,

지난 주에 연락드렸었는데요.
혹시 도움이 될까 싶어 비슷한 이커머스 팀의 사례를 하나 공유드립니다.

→ [사례: 30명 이커머스 팀, 주 15시간 수작업 ETL → CloudPipe 도입 후 2시간으로]
(링크 또는 파일 첨부)

관심 있으시면 편하실 때 연락 주세요.
없으셔도 괜찮습니다 — 그냥 참고 자료로만 보셔도 됩니다.

김민준
```

**좋은 이유**:
- 새로운 가치 (케이스 스터디) 제공
- 부담 제거 ("없으셔도 괜찮습니다")
- 짧고 집중적

---

### 비교 3: 이탈방지 이메일

**❌ BAD — 영업스러운 이탈방지**

```
제목: 특별 할인 제안 드립니다!

박지영님,

저희 서비스를 한동안 이용 안 하신 것 같아서요.
지금 바로 돌아오시면 30% 할인 혜택 드립니다!
이번 달 말까지만 유효합니다! 빨리 결정하세요!

탠건소프트 팀
```

**문제점**:
- 고객이 "잡으려는 것"이 노골적으로 드러남
- 감정적 관심 없이 할인 카드만 꺼냄
- 긴급성 강요 ("빨리 결정하세요!")
- 왜 사용하지 않는지 전혀 파악하려 하지 않음

---

**✅ GOOD — 진심 어린 이탈방지**

```
프롬프트:
박지영님 (B2B SaaS 고객, Growth 플랜)이 최근 3주간 로그인 안 함.
이탈 방지 이메일 작성. 영업 냄새 없이 진심 어린 관심으로.
현재 막히는 부분 있는지 확인. 신기능 1~2개 소개 (파이프라인 템플릿 라이브러리, 알림 연동).
150자 이내.
```

```
제목: "박지영님, 요즘 잘 지내고 계신가요?"

박지영님, 안녕하세요.

최근 접속이 뜸하셔서 혹시 막히는 부분이 있으신 건 아닌가 걱정돼서 연락드렸습니다.

사용하다가 불편하거나 헷갈리는 부분이 있으시면 말씀해 주세요 — 직접 도와드리고 싶습니다.
참고로 지난달 업데이트된 파이프라인 템플릿 라이브러리가 꽤 편리하다는 피드백이 있어서,
한 번 써보시면 좋을 것 같아요.

편하실 때 10분만 시간 주시면 현재 상황 들어보고 싶습니다.

김민준 / 탠건소프트 CSM
```

**좋은 이유**:
- 관심과 우려에서 시작
- 판매 압박 없이 도움 제안
- 새 기능을 자연스럽게 언급 (밀어붙이지 않음)
- 구체적인 행동 제안 (10분 대화)

## 4부. Copilot으로 100개 개인화 이메일 만들기

### 전략: 1개의 마스터 템플릿 + 변수 치환

실제 업무에서 100명에게 각각 다른 이메일을 보내야 한다면, 아래 흐름으로 진행합니다.

```
Step 1. CRM/스프레드시트에서 리드 데이터 추출 (CSV)
  → 필드: firstName, company, industry, jobTitle, painPoint, triggerEvent

Step 2. Copilot으로 마스터 템플릿 1개 작성
  → 변수는 {{변수명}} 형태로 자리 잡기

Step 3. Copilot에게 "이 템플릿 + 10명 데이터로 각각 다른 버전 만들어줘" 요청
  → 10명 × 변수 치환 결과물 생성

Step 4. 결과물 검토 후 어색한 것 수동 수정

Step 5. 나머지 90명은 같은 방식으로 배치 처리
```

### 마스터 템플릿 예시

```markdown
제목: {{triggerEvent}}를 보고 연락드립니다

{{firstName}}님, 안녕하세요.

{{triggerEvent}} 내용을 보게 됐는데요, {{company}}에서도
{{painPoint}} 문제를 다루고 계신 건 아닐까 싶었습니다.

저희가 {{industry}} 업계 팀들과 이 문제를 해결한 경험이 있어서 —
{{caseCompany}}의 경우 {{caseMetric}} 성과를 낸 사례가 있거든요.

15분만 시간 주시면, {{company}} 상황에 맞게 어떻게 적용할 수 있는지
바로 보여드릴 수 있을 것 같습니다.

{{senderName}} / {{senderTitle}}
{{senderEmail}} | {{senderPhone}}
```

### Copilot 프롬프트 (배치 처리용)

```
아래 마스터 이메일 템플릿에 10명의 리드 데이터를 각각 채워서
개인화된 이메일 10개를 만들어줘.

마스터 템플릿:
[위 템플릿 붙여넣기]

리드 데이터:
| firstName | company | industry | jobTitle | painPoint | triggerEvent | caseCompany | caseMetric |
|-----------|---------|----------|----------|-----------|-------------|-------------|------------|
| 이민수 | ABC물산 | 제조업 | IT팀장 | 수동 데이터 정리 | 데이터 엔지니어 채용공고 | D제조 | 작업시간 60% 절감 |
| 박수진 | XYZ커머스 | 이커머스 | 데이터분석팀장 | 실시간 재고 데이터 지연 | 기술 블로그 포스팅 공유 | E커머스 | 재고 정확도 95% |
| 최준호 | 한빛금융 | 금융 | 디지털전환TF | 레거시 시스템 연동 | FinTech 컨퍼런스 만남 | F금융 | 연동 시간 3일→4시간 |
[나머지 7명 데이터 계속]

각 이메일: 제목 + 본문. 개인화 수준이 높아야 함 — 이름만 다른 것처럼 보이면 안 됨.
```

## 5부. 이메일 유형별 구조 가이드

### 콜드 이메일 구조 (5문장 법칙)

```
문장 1: 왜 이 사람에게 연락하는지 (관찰 또는 공통점)
문장 2: 이 사람의 Pain Point를 정확히 짚기
문장 3: 우리가 그 문제를 해결한 경험/데이터 (증거)
문장 4: CTA — 구체적이고 부담 없는 제안
문장 5: 서명
```

### 팔로업 이메일 3단계 구조

```
Day 3 팔로업 — "가볍게 확인"
  목적: 첫 이메일 상기 + 새 정보 1개
  길이: 80자 이내
  톤: 부담 없이, "혹시 보셨나요?" 수준
  금지: "빨리 결정하세요", 재촉 표현

Day 7 팔로업 — "가치 추가"
  목적: 케이스 스터디 or 관련 인사이트 공유
  길이: 100~150자
  톤: 도움을 주려는 느낌
  포함: 구체적 수치 또는 링크

Day 14 팔로업 — "마지막 시도"
  목적: 정중하게 close
  길이: 60자 이내
  톤: "관심 없으시면 괜찮습니다"로 끝내기
  포함: 열린 문 남기기 ("나중에라도 필요하시면")
```

### 이탈방지 이메일 구조

```
문장 1: 안부 인사 (이름 포함, 따뜻하게)
문장 2: 연락 이유 — "걱정이 돼서"
문장 3: 도움 제안 — "막히는 부분이 있으신가요?"

문장 5: 가벼운 CTA — 10분 대화 또는 답장
```

## 핵심 포인트

1. **개인화 = 이름이 아니라 상황 반영** — 업종, Pain Point, 트리거가 진짜 개인화
2. **변수 시스템** `{{firstName}}` 으로 템플릿 1개 → 100개 이메일 생산 가능
3. **5문장 콜드 이메일 법칙**: 관찰 → Pain Point → 증거 → CTA → 서명
4. **팔로업 3단계**: Day 3 리마인드 / Day 7 가치 추가 / Day 14 정중히 close
5. **이탈방지의 핵심**: 영업 냄새 없는 진심 어린 관심 + 새 가치 1개
6. Copilot 결과는 항상 **검토 후 발송** — 수치나 사례는 반드시 확인
