# 03. 제안서 & 견적서 작성

## 학습 목표

- 설득력 있는 제안서의 구조(문제-솔루션-가격-사례-일정)를 이해하고 적용
- Copilot으로 산업별 맞춤 제안서 초안을 30분 안에 만들기
- 가격표, 비교표, 옵션 제안을 Markdown으로 즉시 생성
- BAD vs GOOD 제안서 섹션 3개 비교로 수준 차이 확인
- 견적서 자동화 — 요금제 옵션, 볼륨 할인, 연간/월간 비교표

**예상 소요**: 60분 (실습 포함)

---

## 1부. 좋은 제안서의 구조

### 왜 대부분의 제안서가 읽히지 않는가

영업 현장에서 제안서를 보내고 나서 아무 연락도 없는 경험, 다들 있을 겁니다. 대부분의 경우, 제안서가 **우리 이야기만** 하기 때문입니다.

나쁜 제안서는 이렇게 생겼습니다:
```
1. 우리 회사 소개
2. 우리 제품 기능 목록
3. 가격
4. 문의하세요
```

고객이 읽다가 "그래서 나한테 뭐가 좋다는 거지?"라는 생각이 드는 순간, 닫습니다.

좋은 제안서는 **고객의 이야기로 시작**합니다:

```
1. Executive Summary — 고객이 1분 안에 핵심을 파악
2. 고객 상황 이해 — "우리가 당신의 문제를 이해합니다"
3. 문제 정의 — 현재 상황의 비용/리스크 수치화
4. 솔루션 제안 — 왜 우리인가 (기능이 아닌 결과 중심)
5. 도입 사례 — 비슷한 업종의 성과 증거
6. 가격 옵션 — 명확하고 투명하게
7. 구현 일정 — 언제, 어떻게 시작할 수 있는지
8. 다음 단계 — CTA
```

## 2부. 섹션별 작성 원칙 + BAD vs GOOD

### Executive Summary

이 섹션은 의사결정자가 **읽는 유일한 섹션**일 수 있습니다. 1페이지 이내, 결론이 먼저여야 합니다.

**❌ BAD — 자사 소개로 시작**

```markdown
## Executive Summary

탠건소프트는 2019년 설립된 B2B SaaS 회사로,
데이터 파이프라인 자동화 솔루션 CloudPipe를 제공합니다.
현재 100개 이상의 기업 고객이 사용 중이며,
업계 최고의 기술력으로...
```

**✅ GOOD — 고객 문제와 결론이 먼저**

```markdown
## Executive Summary

ABC제조는 현재 생산 데이터를 엑셀로 수동 관리하고 있어
주 15~20시간의 IT 리소스가 반복 작업에 소모되고 있습니다.
이 제안서는 CloudPipe를 활용해 이 작업을 90% 자동화하고,
ABC제조 IT팀이 본래 업무에 집중할 수 있도록 하는 방안을 담고 있습니다.

**도입 예상 효과**: 주 15시간 → 1.5시간, 연간 IT 공수 절감 약 3,600시간
**투자 회수 기간**: 약 2개월
**제안 요금제**: Growth (월 89만원, 팀 20명)
```

---

### 문제 정의 섹션

문제를 수치로 만들어야 결정권자가 움직입니다.

**❌ BAD — 추상적 문제 기술**

```markdown
## 현재 상황

귀사는 데이터 관리에 어려움을 겪고 계십니다.
수작업이 많아서 비효율적이고 실수가 발생할 수 있습니다.
이런 상황은 개선이 필요합니다.
```

**✅ GOOD — 수치화된 문제 기술**

```markdown
## 현재 상황 — 숨겨진 비용

미팅에서 파악한 ABC제조의 현황:

| 항목 | 현재 상황 | 비용 환산 |
|------|-----------|----------|
| 주간 ETL 작업 | 수동, 3명 × 5시간 | 연 2,340시간 |
| 데이터 오류 수정 | 월 평균 8건 | 건당 평균 2시간 |
| 보고서 생성 지연 | 매주 월요일 3시간 | 연 156시간 |
| **합계** | | **연 약 2,652시간** |

IT 담당자 평균 연봉 4,800만원 기준, **연간 약 6,100만원 규모**의 비용이
반복 업무에 소모되고 있습니다.
```

---

### 솔루션 섹션

기능 목록이 아닌, **고객의 문제 해결 스토리**로 씁니다.

**❌ BAD — 기능 목록**

```markdown
## CloudPipe 주요 기능

- 200+ 데이터 소스 연동
- 드래그 앤 드롭 파이프라인 빌더
- 실시간 모니터링 대시보드
- 슬랙/이메일 알림
- API 지원
- 역할 기반 접근 제어
```

**✅ GOOD — 고객 문제 → 해결 스토리**

```markdown
## ABC제조에 CloudPipe가 하는 일

**문제 1: 주 15시간 수동 ETL**
→ CloudPipe의 ERP/DB 직접 연동으로 데이터 수집을 완전 자동화.
   담당자가 파이프라인을 클릭 몇 번으로 설정하면, 이후엔 자동 실행.

**문제 2: 월 8건 데이터 오류**
→ 빌트인 데이터 검증 규칙으로 오류 데이터를 파이프라인 단계에서 자동 감지.
   오류 발생 시 슬랙으로 즉시 알림.

**문제 3: 월요일 보고서 3시간**
→ 대시보드 자동 갱신으로 매주 월요일 00:00에 자동 생성 및 이메일 발송.
   담당자는 확인만 하면 됨.
```

## 3부. 가격표 & 견적서 자동 생성

### 요금제 비교표 Copilot 생성

```
프롬프트:
SaaS 요금제 비교 표를 Markdown으로 작성.

제품: CloudPipe
요금제:
  Starter: 월 29만원, 팀 5명, 파이프라인 10개, 이메일 지원
  Growth: 월 89만원, 팀 20명, 파이프라인 50개, 채팅+이메일 지원, 대시보드 포함
  Enterprise: 협의, 무제한, 전담 CSM, SLA 보장, 커스텀 온보딩

추가:
  - 연간 결제 시 20% 할인
  - 각 요금제별 "이런 팀에 맞습니다" 한 줄 설명 추가
  - ABC제조 (팀 15명, 파이프라인 30개)에 적합한 요금제 강조 표시
```

생성 예시:

```markdown
## 요금제 비교

| 항목 | Starter | **Growth** ⭐ | Enterprise |
|------|---------|------------|------------|
| **월 요금** | 29만원 | **89만원** | 협의 |
| **연간 요금** | 278만원 (월 23만원) | **854만원 (월 71만원)** | 협의 |
| 팀 규모 | 최대 5명 | **최대 20명** | 무제한 |
| 파이프라인 수 | 10개 | **50개** | 무제한 |
| 지원 방식 | 이메일 | **채팅 + 이메일** | 전담 CSM |
| 대시보드 | - | **✅ 포함** | ✅ 포함 |
| SLA | - | - | ✅ 99.9% 보장 |
| 커스텀 온보딩 | - | - | ✅ 포함 |
| **적합 대상** | 5인 이하 팀, 소규모 파이프라인 | **15~20인 팀, 중규모** | 엔터프라이즈 |

> ⭐ **ABC제조 권장 요금제**: Growth — 팀 15명, 파이프라인 30개 이내로 여유 있게 사용 가능
```

### 볼륨 할인 계산 표

```
프롬프트:
CloudPipe Growth 요금제 기준 볼륨 할인 제안 표 Markdown으로 작성.

조건:
- 기본 월 89만원
- 연간 선불 결제 시 20% 할인
- 3년 약정 시 추가 10% 할인
- 파이프라인 100개 초과 시 추가 협의

표 구성:
- 계약 기간별 (월간 / 연간 / 3년) 월 환산 요금, 총 결제액, 절감액
- ABC제조 권장 옵션 강조
```

```markdown
## 가격 옵션 비교

| 계약 조건 | 월 환산 | 총 결제액 | 절감액 | 비고 |
|----------|---------|---------|--------|------|
| 월간 결제 | 89만원 | 89만원/월 | - | 최소 약정 없음 |
| 연간 선불 | **71.2만원** | **854만원/년** | **214만원 절감** | 권장 ⭐ |
| 3년 약정 | **64만원** | **2,304만원/3년** | **516만원 절감** | 장기 운영 시 |

> 연간 선불 결제 시 **첫 달 무료** + **무료 온보딩 세션 3회** 추가 제공
```

## 4부. 산업별 제안서 커스터마이징

Copilot에게 동일한 제안서 초안을 업종별로 다르게 커스터마이징하도록 요청할 수 있습니다.

### 프롬프트: 업종별 제안서 섹션 변형

```
아래 제안서의 "문제 정의" 섹션과 "도입 사례" 섹션을
3개 업종 버전으로 각각 수정해줘.

원본 (제조업 버전):
[붙여넣기]

수정 버전:
1. 이커머스 — 실시간 주문/재고 데이터, 마케팅 성과 리포트, 배송 추적
2. 금융/보험 — 규제 보고, 고객 데이터 통합, 위험 분석
3. 헬스케어 — 환자 데이터 통합, 임상 리포트, 개인정보 보호 강조

각 버전:
- 해당 업종 특유의 용어와 Pain Point 반영
- 업종에 맞는 성과 지표 (예: 이커머스는 CVR, 금융은 보고서 마감 시간)
- 실제처럼 보이도록 구체적인 수치 포함 (실제 데이터가 없으면 "예시" 명시)
```

## 5부. 제안서 작성 A to Z — SaaS 시나리오 실습

### 시나리오

```
고객: ABC제조 (주)
담당자: 이민수 차장 (IT팀)
미팅 날짜: 오늘
현황:
  - 생산/품질 데이터를 Excel로 수동 관리
  - 주 3회 수동 보고서 생성 (팀원 3명 × 5시간/회)
  - 데이터 오류로 인한 재처리 월 8건
  - ERP(SAP)와 분석 툴 간 연동 없음
  - IT 팀 5명 중 2명이 데이터 작업에 대부분의 시간 소모

요청: 다음 주 임원 보고 전에 제안서 받고 싶다
```

### Step 1. 제안서 구조 생성

```
프롬프트:
ABC제조 대상 CloudPipe 제안서 구조를 Markdown으로 작성.
아래 현황 기반으로 섹션 목차 + 각 섹션의 핵심 내용 개요를 만들어줘.

현황:
[위 시나리오 붙여넣기]

구조: 8섹션 (Executive Summary / 고객 상황 / 문제 정의 / 솔루션 / 도입 사례 / 가격 / 일정 / 다음 단계)
각 섹션 아래: 포함할 내용 불릿 2~4개
```

### Step 2. Executive Summary 생성

```
프롬프트:
ABC제조 대상 CloudPipe 제안서의 Executive Summary 작성.
A4 반 페이지 이내. 결정권자(임원) 눈높이.

포함:
- 현재 문제 (수치 포함)
- 제안 솔루션 요약
- 예상 효과 (수치)
- 투자 회수 기간 (ROI)
- 제안 요금제
- 다음 단계
```

### Step 3. 문제 정의 섹션 — 수치화

```
프롬프트:
ABC제조 문제 정의 섹션 작성. 수치 기반으로.

현황 데이터:
- 팀원 3명 × 주 3회 × 5시간 = 주 45시간 수동 데이터 작업
- 월 8건 데이터 오류, 건당 수정 2시간
- 보고서 지연으로 의사결정 지연 월 평균 2.3일

계산:
- 연간 수동 작업 시간
- 연간 오류 처리 시간
- IT 담당자 연봉 기준 비용 환산 (연봉 5,000만원 기준)
- 지연 의사결정의 기회비용 (간략히)

형식: Markdown 표 + 분석 텍스트 3~4문장
```

### Step 4. 솔루션 섹션 — 기능이 아닌 문제 해결로

```
프롬프트:
ABC제조의 3가지 문제에 CloudPipe가 어떻게 대응하는지
"문제 → 해결 스토리" 형식으로 작성.

문제 1: 주 45시간 수동 ETL → CloudPipe ERP 연동 자동화
문제 2: 월 8건 데이터 오류 → 빌트인 검증 + 알림
문제 3: 주 3회 수동 보고서 → 자동 생성 + 이메일 발송

각 문제별:
- 현재 방식 (Before)
- CloudPipe 도입 후 (After)
- 예상 효과 수치
```

### Step 5. 가격 제안 섹션

```
프롬프트:
ABC제조 대상 가격 제안 섹션.
팀 5명, 파이프라인 약 20개 필요.
Growth 요금제 권장.

포함:
1. 요금제 비교 표 (Starter / Growth / Enterprise)
2. 연간 결제 시 절감 비교
3. ROI 계산 — 현재 인력 비용 대비 CloudPipe 비용
4. 타 솔루션 대비 비교 (경쟁사 비방 없이, "일반적인 대안" 수준)
```

### Step 6. 구현 일정 + 다음 단계

```
프롬프트:
CloudPipe ABC제조 도입 일정 + 다음 단계 섹션.

도입 단계:
Week 1-2: 계약 + 킥오프 미팅 + 환경 설정
Week 3-4: ERP 연동 + 파이프라인 10개 설정
Week 5-6: 나머지 파이프라인 + 사용자 교육
Week 7: 테스트 운영 + 피드백
Week 8: 정식 운영 전환

다음 단계 CTA:
- 이번 주: 계약서 검토
- 다음 주: 킥오프 미팅 일정 확정
- 담당 CSM 배정 및 소개

형식: 타임라인 표 + 다음 단계 체크리스트
```

## 6부. 5가지 Copilot 프롬프트 — 제안서 실전

### 프롬프트 1. 빠른 제안서 구조 (10분용)

```
아래 고객 정보로 제안서 구조와 각 섹션의 핵심 포인트를 잡아줘.
실제 내용을 쓸 준비를 위한 뼈대만 필요.

고객: {{company}}, {{industry}}, {{size}}명
미팅에서 파악한 현황: {{situation}}
우리 제품: {{productName}}
제안 요금제: {{plan}}

출력: 8섹션 목차 + 각 섹션 포인트 2~3개 (불릿)
```

### 프롬프트 2. 경쟁 PT 상황 — 차별화 포인트 강조

```
고객사가 우리 포함 경쟁사 3곳의 제안을 동시에 받고 있는 상황.
우리 제안서를 차별화하는 섹션 작성.

경쟁사 일반적 약점:
- 해외 솔루션: 한국어 지원 미흡, 로컬 지원 없음
- 국내 경쟁사: 기능 제한, 엔터프라이즈 확장성 부족

우리 강점: {{ourStrengths}}

작성:
1. "왜 CloudPipe인가" 섹션 (비방 없이, 우리 강점 중심)
2. 차별화 비교 표 (기능 아닌 결과와 지원 중심)
3. 고객이 우리를 선택해야 하는 이유 3가지 (요약 불릿)
```

## 핵심 포인트

1. **고객 이야기로 시작** — 우리 소개가 아니라 고객 문제와 비용이 첫 페이지
2. **수치화** — "비효율적입니다" → "연간 2,652시간, 약 6,100만원 규모의 공수"
3. **기능 목록 → 해결 스토리** — 고객 문제 → 우리 해결 방식 → 예상 결과
4. **가격 + ROI** — 가격만 보여주는 것과 "2개월 안에 회수"를 보여주는 것은 다름
5. **Copilot 역할**: 구조 잡기 + 초안 생성 + 수치 계산 구조화. 실제 수치는 직접 확인!
