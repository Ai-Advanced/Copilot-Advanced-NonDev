## HR 5대 활용 영역 + 핵심 프롬프트 패턴

### 1. JD 작성

```
[역할명] JD 초안. 회사: [유형]. 구조: 소개/업무/자격/우대/팀/성장.
편향 표현(성별/연령/학벌/외모) 없이. Markdown.
```

편향 검토는 **반드시 별도로** 실행:
```
위 JD를 편향 언어 관점에서 검토. 발견된 표현→편향 유형→개선안 목록.
```

### 2. 인터뷰 질문

```
[역할명] BEI 인터뷰 질문 20개. 역량: [A/B/C/D].
STAR 유도형, 후속 질문 포함. 금지 질문(나이/결혼/자녀) 제외.
```

### 3. 온보딩 문서

```
[역할명] 90일 온보딩 플랜. 3단계(학습→기여→성과).
담당자·체크포인트 포함. Markdown 표.
```

### 4. 엑셀 수식

```
엑셀 수식: [목적]. 입력: [열/형식]. 출력: [결과].
한국어 함수명. 완성 수식으로.
```

### 5. 서베이

```
[목적] 서베이 [N]개 문항. 리커트 5점 [N개] + 서술형 [N개].
완료 시간 5분 이내. 익명성 보장 명시.
```

## 절대 금지 사항

| 금지 | 이유 |
|------|------|
| 실제 직원 이름/연락처/주민번호 입력 | 개인정보보호법 위반 |
| AI 결과로 바로 채용/탈락 결정 | 법적 위험, 편향 재생산 |
| 연봉·급여 상세 데이터 입력 | 개인정보보호법 |
| "알아서 해줘" 프롬프트 | 뻔한 결과 보장 |

---

## 면접에서 물으면 안 되는 질문 (채용절차법·근로기준법)

나이 / 혼인 여부 / 자녀 계획 / 가족 재산 / 종교 / 정치 성향 / 키·몸무게 / 출신 지역

→ 대신: **역량·경험·성과** 중심 질문으로 대체

---

## 프롬프트 개선 순환

```
1차: 기본 요청 → 결과 확인
2차: "위 결과에서 [A]를 [B]로 바꿔줘"
3차: "[C] 항목 추가"
4차: "Markdown 표로 다시 정리"
```

---

## 편향 언어 즉시 대체표

| ❌ 금지 | ✅ 대체 |
|---------|---------|
| 젊고 패기 있는 | 주도적이고 성장 지향적인 |
| 체력이 강한 | (삭제 or 현장 업무 명시) |
| 외향적인 성격 | 팀 협업에 적극적인 |
| 명문대 졸업 | (삭제) |
| 단정한 외모 | (삭제) |
| 남자/여자 직원 특성상 | (삭제) |
