# 04. Day 1 종합 실습 — "신규 포지션 채용 킥오프"

## 실습 목표

오늘 배운 내용을 하나의 흐름으로 연결합니다. 실습이 끝나면 실제 채용에 쓸 수 있는 패키지가 완성됩니다.

- JD 초안 생성 → 편향 검토 → 최종본
- 인터뷰 질문 세트 → 평가 루브릭
- 이력서 스크리닝 매트릭스
- 채용 공고 요약 (SNS용)

**예상 소요**: 50분

---

## 시나리오

> **가상 회사**: 주식회사 그린테크 (GreenTech)
> B2B 탄소 배출 관리 SaaS 스타트업, Series A, 직원 60명
> 서울 강남구 사무실, 주 3일 재택 가능
>
> **상황**: CMO 최유진 씨가 HRBP 이하나 씨에게 요청했습니다.
> "그로스 마케터 채용을 빠르게 시작해야 해요. 이번 분기 안에 꼭 채용하고 싶어요."
>
> **여러분의 역할**: HRBP 이하나 씨. Copilot을 활용해서 채용 킥오프 패키지를 오늘 오후 안에 완성하세요.

---

## Step 1. 역할 정의 (5분)

채용 킥오프 전에 역할을 명확히 정의합니다. 아래 프롬프트로 역할 정의 템플릿을 먼저 채웁니다.

**프롬프트**:
```
채용 킥오프 역할 정의 문서 작성.

역할명: 시니어 그로스 마케터
회사: B2B 탄소 배출 관리 SaaS (Series A, 60명)
보고: CMO 직속
팀 규모: 마케팅팀 3명 (이 역할 포함 4명)

포함:
1. 역할이 필요한 이유 (3~4문장, 비즈니스 맥락)
2. 성공 기준 (입사 90일 후 달성 목표 3개)
3. 핵심 기술 스택 / 도구
4. 이 역할이 협업하는 팀과 방식

출력: Markdown.
```

결과를 `role-definition-growth-marketer.md`로 저장하세요.

---

## Step 2. JD 초안 생성 (10분)

Step 1의 역할 정의를 참고해서 JD를 만듭니다.

**프롬프트**:
```
시니어 그로스 마케터 JD 초안 작성.

회사: GreenTech — B2B 탄소 배출 관리 SaaS (Series A, 60명)
특징: 환경·ESG 도메인, B2B 세일즈 사이클 6~18개월, 마케팅팀 신설 3번째 멤버

핵심 역할:
- B2B 인바운드 파이프라인 구축 (콘텐츠 마케팅, SEO, 웨비나)
- 계정 기반 마케팅(ABM) 전략 수립 및 실행
- 마케팅-세일즈 얼라인먼트 (HubSpot CRM 활용)
- 마케팅 성과 측정 및 경영진 보고

기술/도구: HubSpot, Google Analytics 4, LinkedIn Ads, Notion

구조: 포지션 소개(4문장) / 주요 업무(7개) / 자격 요건(5개) / 우대 사항(3개) / 팀 소개(3문장) / 성장 기회(2문장)

편향 없는 표현. Markdown 출력.
```

---

## Step 3. 편향 검토 (5분)

Step 2의 JD를 그대로 이어서 검토합니다.

**프롬프트**:
```
위 JD를 편향 언어 관점에서 검토.

항목:
1. 성별 편향 표현
2. 연령 편향 표현
3. 학력/출신 편향
4. 신체 조건 편향
5. 채용절차법 위반 소지 (혼인, 가족, 재산 등)
6. "B2B는 남성적 언어" "마케터는 여성적 언어" 같은 산업 고정관념

결과: 발견된 표현 → 편향 유형 → 개선안 목록
편향 제거된 최종 JD 전체 출력.
```

최종 JD를 `jd-growth-marketer-greentech.md`로 저장하세요.

---

## Step 4. 인터뷰 질문 세트 (15분)

B2B 마케터에 맞는 인터뷰 질문과 루브릭을 만듭니다.

**프롬프트**:
```
시니어 B2B 그로스 마케터 인터뷰 질문 세트 작성.

평가 역량 4개:
1. B2B 인바운드 마케팅 전략 수립
2. 데이터 기반 캠페인 최적화
3. 세일즈팀과의 협업 (마케팅-세일즈 얼라인먼트)
4. 실행력과 우선순위화

각 역량당:
- BEI 질문 4개 (STAR 유도형)
- 후속 질문(Probe) 1개씩

평가 루브릭:
- 역량 4개 각각 1점/3점/5점 기준 서술
- 실제 답변 예시 포함

금지: 나이·혼인·자녀·종교·외모 관련 질문 없음
출력: 전체 인터뷰 가이드, Markdown
```

결과를 `interview-guide-growth-marketer.md`로 저장하세요.

---

## Step 5. 이력서 스크리닝 매트릭스 (10분)

인터뷰 전에 이력서를 어떻게 걸러낼지 기준을 만듭니다.

**프롬프트**:
```
시니어 B2B 그로스 마케터 이력서 스크리닝 매트릭스 작성.

Pass/Fail 기준 (하나라도 Fail이면 탈락):
1. B2B 마케팅 실무 경험 3년 이상
2. 인바운드 마케팅 실제 실행 경험 (콘텐츠/SEO/웨비나 중 1개 이상)
3. 마케팅 성과 수치 제시 가능 (이력서에 정량 성과 있음)

역량 점수 항목 (1~5점, 합산 기준):
1. B2B 도메인 깊이 (탄소/ESG/SaaS 경험 가산점)
2. ABM 또는 HubSpot 경험
3. 성과 서술의 구체성 (수치 기반)
4. 커뮤니케이션 역량 (커버레터, 이력서 구조)

합산 점수 기준:
- 15점 이상: 1차 인터뷰 진행
- 10~14점: 보류 (채용 상황에 따라 검토)
- 9점 이하: 정중히 거절

출력: Markdown 표 형식 (각 항목 + 평가 기준 명시)
주의: 학력·나이·성별·혼인 여부는 평가 항목에 포함 않음
```

결과를 `screening-matrix-growth-marketer.md`로 저장하세요.

## Step 6. SNS 채용 공고 + 채용 거절 이메일 (5분)

마지막으로 외부 커뮤니케이션 자료를 만듭니다.

**프롬프트 A — LinkedIn 공고**:
```
GreenTech 시니어 그로스 마케터 LinkedIn 채용 공고 작성.

- 길이: 200자 이내
- 포함: 역할명, 핵심 키워드 2개, 회사 특징 1문장, 지원 CTA
- 이모지 2개 이하 (전문적인 느낌 유지)
- 편향 없는 표현
```

**프롬프트 B — 서류 탈락 이메일**:
```
서류 전형 탈락 안내 이메일 초안 작성.

- 발신: GreenTech 채용팀
- 수신: [지원자명] (자리표시자)
- 포함: 지원 감사, 결과 안내, 향후 재지원 안내
- 구체적 탈락 사유 X (법적 분쟁 방지)
- 길이: 150자 이내
- 톤: 정중하고 따뜻하게
```

## 핵심 요약

Day 1에서 만든 것들:

- **역할 정의** → JD 초안 → 편향 검토 → 최종 JD
- **인터뷰 질문 세트** (BEI + STAR + 컬처애드)
- **평가 루브릭** (역량별 1/3/5점 기준)
- **스크리닝 매트릭스** (Pass/Fail + 점수 기준)
- **채용 커뮤니케이션** (LinkedIn 공고 + 거절 이메일)

이 패키지는 어떤 포지션에도 재활용할 수 있습니다. 역할명과 핵심 역량만 바꾸면 됩니다.
