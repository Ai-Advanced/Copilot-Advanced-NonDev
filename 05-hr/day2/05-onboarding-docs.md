# 05. 온보딩 문서화 — 90일 플랜부터 웰컴 이메일까지

## 학습 목표

- 역할별 온보딩 문서를 Copilot으로 빠르게 생성하는 방법 습득
- 1주차/1개월/3개월 체크리스트 구조와 각 단계의 목적 이해
- 웰컴 이메일, 온보딩 FAQ, 버디 프로그램 가이드 생성
- 신규 마케터 90일 온보딩 플랜 완성

**예상 소요**: 60분 (실습 포함)

---

## 5.1 온보딩이 왜 중요한가 — 데이터로 보기

잘 설계된 온보딩은 단순한 서류 작업이 아닙니다.

- 체계적인 온보딩을 경험한 신입은 **생산성 달성 속도가 50% 빠름** (Brandon Hall Group)
- 온보딩 경험이 좋으면 **2년 후 재직률이 82% 높음** (Glassdoor)
- 신규 입사자의 **20%가 첫 45일 안에 퇴직 결심** — 대부분이 온보딩 경험 때문

반대로, 나쁜 온보딩의 패턴은 단순합니다.

1. 첫날 IT 계정이 없어서 멍하니 앉아 있음
2. 해야 할 일을 아무도 알려주지 않음
3. 누구와 이야기해야 하는지 모름
4. 90일이 지나도 자신이 성과를 내고 있는지 모름

Copilot은 이 네 가지 문제를 **미리 구조화된 문서**로 예방합니다.

---

## 5.2 온보딩 문서의 구조

좋은 온보딩 패키지는 다섯 가지로 구성됩니다.

| 문서 | 목적 | 타이밍 |
|------|------|--------|
| 웰컴 이메일 | 첫날 준비사항, 불안 해소 | 입사 3~5일 전 발송 |
| 역할별 온보딩 체크리스트 | 첫 4주간 할 일 명확화 | 입사 첫날 공유 |
| 90일 온보딩 플랜 | 30/60/90일 목표와 기준 | 입사 첫 주 관리자와 합의 |
| 신규 입사자 FAQ | 반복되는 질문 사전 답변 | Notion/Wiki에 상시 공개 |
| 버디 프로그램 가이드 | 비공식 관계 구축 지원 | 버디 배정 시 공유 |

---

## 5.3 3단계 온보딩 모델

### 1단계: 학습 모드 (1~30일)

신규 입사자의 목표는 하나입니다. **이해하기**.

- 회사의 비즈니스 모델, 제품, 고객을 이해
- 팀 구조와 각자의 역할 파악
- 내부 도구와 프로세스 익히기
- 관계 구축 시작 (1:1 미팅 일정 잡기)

**흔한 실수**: 1주차부터 "빨리 성과를 내야 한다"는 압박을 줌. 이 시기의 신규 입사자는 배우는 것이 성과입니다.

### 2단계: 기여 모드 (31~60일)

이해를 바탕으로 **작은 성과** 만들기.

- 팀의 실제 프로젝트에 참여
- 첫 번째 독립적 결과물 완성
- 피드백 수용 및 적응
- 강점과 개선 영역 파악

### 3단계: 성과 모드 (61~90일)

독립적으로 **목표를 달성**하기.

- 합의된 KPI 달성 시작
- 오너십을 가진 영역 확보
- 90일 리뷰 준비
- 다음 분기 목표 초안 작성

## 5.4 Copilot으로 온보딩 문서 만들기

### 프롬프트 1. 역할별 온보딩 체크리스트

```
[역할명] 신규 입사자 온보딩 체크리스트 작성.

기간: 1주차 / 2주차 / 3~4주차 / 2개월차 / 3개월차

각 기간별:
- IT·시스템 (계정, 도구, 장비)
- 역할 이해 (업무 파악, 팀 미팅 참석)
- 관계 구축 (1:1 일정, 점심, 슬랙 채널)
- 성과 기준 (KPI 합의, 목표 설정)

컬럼: 항목 | 담당자 | 완료 기한 | 확인 여부 (체크박스)
총 30~35개 항목.
출력: Markdown 표.
```

### 프롬프트 2. 웰컴 이메일

```
신규 입사자에게 보내는 웰컴 이메일 작성.

발신: HR팀 (김지은 / HRBP)
수신: [이름 자리표시자]님
입사일: [DATE]
역할: [역할명]

포함:
- 환영 메시지 (2~3문장, 진심이 느껴지게)
- 첫날 준비사항 (복장, 도착 시간, 주차, 점심 장소)
- 입사 전 받게 될 것들 (IT 계정 이메일, 노션 초대, 슬랙 초대)
- 담당 버디 소개 (버디 이름 자리표시자)
- 담당 HR 연락처
- 미리 읽을 자료 (회사 소개 링크 자리표시자)

톤: 따뜻하고 구체적. "모르는 게 있으면 언제든 연락하세요" 느낌.
길이: 이메일 기준 300~400자.
```

### 프롬프트 3. 90일 온보딩 플랜

```
[역할명] 신규 입사자 90일 온보딩 플랜 작성.

3단계:
- 1~30일 (학습): 이해·파악·관계 구축
- 31~60일 (기여): 작은 성과, 팀 협업
- 61~90일 (성과): KPI 달성, 오너십 확보

각 단계:
- 핵심 목표 3개
- 구체적 액션 아이템 (담당자 포함)
- 체크포인트 질문 3개 (관리자와 리뷰할 때 활용)

30/60/90일 리뷰 시 체크할 기준:
- 잘 되고 있는 것
- 조정이 필요한 것
- 다음 단계를 위한 지원 요청

출력: Markdown (표 + 텍스트 혼용).
```

### 프롬프트 4. 신규 입사자 FAQ

```
신규 입사자 FAQ 문서 작성.

카테고리 5개, 각 카테고리 4~5개 Q&A:

1. 복리후생 (연차, 재택, 점심 지원, 복지포인트, 교육비)
2. IT·시스템 (계정 발급, VPN, 장비 신청, 소프트웨어 구매)
3. 급여·정산 (급여일, 경비 처리, 야근 수당, 연말정산)
4. 문화·규범 (복장, 슬랙 에티켓, 회의 문화, 코드 리뷰)
5. 성장·평가 (리뷰 주기, KPI 설정, 승진 기준, 1:1 미팅)

각 Q&A: 질문 → 명확하고 구체적인 답변 (3~4줄)
없는 정보는 "[담당팀] 문의" 표시.
출력: Markdown.
```

### 프롬프트 5. 버디 프로그램 가이드

```
신규 입사자 버디(Buddy) 프로그램 가이드 작성.

버디 = 신규 입사자의 비공식 안내자 (관리자 X)

포함:
- 버디의 역할과 범위 (무엇을 해야 하는가, 하지 말아야 하는가)
- 버디 선발 기준 (재직 1년 이상, 자원자 우선)
- 1개월 활동 가이드 (1주차~4주차 미팅 의제 예시)
- 버디가 하면 안 되는 것 (성과 평가 공유, 퇴직 권유, 회사 불평 등)
- 버디와 신규 입사자 모두를 위한 피드백 양식 (5문항)

출력: Markdown.
```

## 5.5 온보딩 노션 페이지 구조

Copilot으로 만든 문서를 Notion에 올릴 때 아래 구조를 권장합니다.

```
📁 신규 입사자 온보딩
├── 👋 웰컴 메시지 (CEO/HR)
├── 📋 온보딩 체크리스트
│   ├── 1주차
│   ├── 2주차
│   └── 3~4주차
├── 🗺️ 90일 플랜
│   ├── 1~30일 목표
│   ├── 31~60일 목표
│   └── 61~90일 목표
├── ❓ FAQ
│   ├── 복리후생
│   ├── IT·시스템
│   ├── 급여·정산
│   ├── 문화·규범
│   └── 성장·평가
├── 👥 팀 소개 (팀원 프로필 링크)
└── 🔗 유용한 링크 모음
    ├── 회사 소개 자료
    ├── 제품 데모
    ├── 내부 도구 가이드
    └── 비상 연락처
```

**Copilot으로 Notion 구조 생성하기**

```
Notion 페이지 구조를 Markdown으로 작성.
신규 [역할명] 입사자를 위한 온보딩 허브 페이지.

섹션 7개:
1. 웰컴 메시지 (HR 사인 포함)
2. 첫날 할 일 (긴급도 높은 3가지)
3. 이번 주 목표
4. 만나야 할 사람들 (이름 자리표시자, 미팅 목적 포함)
5. 알아야 할 도구와 링크
6. FAQ 요약 (가장 자주 묻는 5개)
7. 버디 연락처

각 섹션에 Notion callout 블록, 체크박스 활용 안내 포함.
```

## 5.6 실전 예시 — 신규 마케터 웰컴 이메일

### Before (형식적인 이메일)

```
안녕하세요.

인사팀입니다.

다음 주 월요일 입사 예정임을 안내드립니다.
9시까지 5층 리셉션에 오시면 됩니다.

감사합니다.
인사팀 드림
```

**문제점**: 첫날 준비가 전혀 안 됨. 복장은? 점심은? 누구를 만나야 하나? 불안감 제거 X.

### After (Copilot 생성 + 수정)

```
안녕하세요, [이름]님!

다음 주 월요일부터 GreenTech 마케팅팀과 함께하시게 되어서 정말 기쁩니다.
[이름]님이 팀에 기여하실 모습이 벌써부터 기대됩니다.

**첫날 준비사항**
- 도착 시간: 오전 9:30 (9시 30분)
- 장소: 서울 강남구 [주소] 3층 (지하철 강남역 5번 출구 도보 5분)
- 복장: 캐주얼 (청바지 OK)
- 점심: 팀 런치로 함께 할 예정이에요 (예약해 뒀습니다!)

**입사 전날까지 받으실 것들**
- IT 계정 설정 이메일 (발신: it@greentech.io)
- Slack 초대 (마케팅팀 채널 자동 추가)
- Notion 온보딩 페이지 접근 링크

**버디 소개**
마케팅팀 [버디 이름]님이 첫 1개월 동안 함께해 주실 거예요.
업무 외 질문도 편하게 여쭤보세요.

궁금한 점이 있으시면 언제든 연락 주세요.
010-XXXX-XXXX / jieun.kim@greentech.io

월요일에 뵙겠습니다!

김지은 | HRBP, GreenTech
```

## 실습 — 신규 마케터 90일 온보딩 플랜 완성하기

### 시나리오

> GreenTech에 시니어 그로스 마케터 박수아 씨가 다음 주 월요일 입사합니다.
> Day 1 실습에서 만든 역할 정의와 JD를 참고해서 온보딩 플랜을 만들어보세요.

**Step 1**: 웰컴 이메일 생성

```
GreenTech 시니어 그로스 마케터 신규 입사자 웰컴 이메일 작성.

발신: HRBP 김지은
수신: [이름]님 (시니어 그로스 마케터)
입사일: 다음 주 월요일

포함:
- 환영 (2문장)
- 첫날 안내 (시간/장소/복장/점심)
- 입사 전 받을 것들 (IT 계정, Slack, Notion)
- 버디 소개
- 담당 HR 연락처

톤: 따뜻하고 실용적. 회사 문화(자율·성장)가 느껴지게.
```

**Step 2**: 체크리스트 생성

```
시니어 그로스 마케터 온보딩 체크리스트 작성.

도구: HubSpot, GA4, Notion, Slack, Google Workspace
협업: 세일즈팀, 개발팀, 디자인팀

1주차 / 2주차 / 3~4주차 / 2개월 / 3개월 구분.
각 기간 8~10개 항목.
컬럼: 항목 | 담당자 | 기한 | 완료

출력: Markdown 표.
```

**Step 3**: 90일 플랜 생성

```
GreenTech 시니어 그로스 마케터 90일 온보딩 플랜.

1~30일 목표:
- B2B SaaS 마케팅 현황 파악 (기존 캠페인, 채널, KPI)
- 세일즈팀과 첫 얼라인먼트 미팅
- 첫 번째 콘텐츠 아이템 기여

31~60일 목표:
- ABM 캠페인 파일럿 기획·실행
- 마케팅 리포트 첫 번째 독립 작성

61~90일 목표:
- 분기 마케팅 플랜 초안 제출
- KPI (파이프라인 기여 XX%) 달성 기반 마련

각 단계: 액션 아이템(담당자 포함) + 체크포인트 질문 3개
출력: Markdown.
```

**Step 4**: 결과를 `onboarding-package-growth-marketer.md`로 저장하세요.

**Step 5**: 온보딩 FAQ 5개 추가

```
마케터 신규 입사자가 가장 자주 묻는 질문 5개와 답변 작성.

카테고리: IT·도구 설정, 마케팅 예산 신청, 외부 행사 참가, CRM 접근 권한, 보고 주기
출력: 각 Q&A 3~4줄 답변, Markdown.
```

## 핵심 포인트

1. **온보딩 3단계**: 학습(1~30일) → 기여(31~60일) → 성과(61~90일)
2. **웰컴 이메일**: 불안 해소에 집중. 첫날 구체적 정보 필수
3. **체크리스트**: 기간·담당자·기한이 없으면 체크리스트가 아님
4. **90일 플랜**: 신규 입사자와 관리자가 함께 합의해야 함. HR은 구조 제공
5. **FAQ**: 반복 답변을 줄이는 가장 효율적인 HR 문서
6. Copilot 온보딩 문서는 **역할명과 도구만 바꾸면 모든 포지션에 재활용** 가능
