# 06. HR 엑셀과 데이터 — 수식 자동화부터 개인정보 마스킹까지

## 학습 목표

- 급여밴드, 근속연수, 휴가 잔여 등 HR 핵심 수식을 Copilot으로 즉시 생성
- VLOOKUP, XLOOKUP, COUNTIFS, PIVOT 등 실무 수식 패턴 이해
- 엑셀 개인정보 마스킹 기법으로 안전한 데이터 공유
- 인사 대시보드 시트 구조를 설계하고 완성

**예상 소요**: 60분 (실습 포함)

---

## 6.1 HR 데이터 업무에서 엑셀이 쓰이는 곳

HR 담당자가 실제로 엑셀을 쓰는 업무를 정리하면 이렇습니다.

| 업무 | 주요 데이터 | 자주 쓰는 함수 |
|------|------------|---------------|
| 인원 현황 집계 | 직원 마스터 데이터 | COUNTIF, COUNTIFS |
| 근속연수 계산 | 입사일, 기준일 | DATEDIF, YEAR |
| 연차 잔여 계산 | 입사일, 사용 일수 | IF, MAX, DATEDIF |
| 급여밴드 분류 | 직급, 연봉 | IF, IFS, VLOOKUP |
| 조직도 집계 | 부서, 팀, 직급 | PIVOT, COUNTIFS |
| 채용 현황 리포트 | 포지션별 진행 단계 | COUNTIFS, IFERROR |

이 모든 수식을 머릿속에 외울 필요가 없습니다. Copilot에 원하는 결과를 설명하면 됩니다.

## 6.2 HR 엑셀 수식 — 핵심 패턴

### 패턴 1. 근속연수 계산

**상황**: B열에 입사일이 있고, 오늘 기준 근속연수를 D열에 표시하고 싶습니다.

**Copilot 프롬프트**:
```
엑셀 수식 작성.

B2 셀에 입사일(날짜 형식)이 있어.
C2 셀에 기준일(오늘: TODAY() 함수 사용)이 있어.

필요한 수식:
1. 근속연수 (년 단위, 소수점 1자리): D2
2. 근속 개월수 (정수): E2
3. 근속 일수: F2
4. 근속 등급 표시: G2
   - 1년 미만: "수습/신입"
   - 1년 이상 3년 미만: "주니어"
   - 3년 이상 5년 미만: "미들"
   - 5년 이상: "시니어"

한국어 함수명 기준, 완성 수식으로.
```

**결과 수식 예시**:

| 셀 | 수식 | 설명 |
|----|------|------|
| D2 | `=ROUND(DATEDIF(B2,TODAY(),"Y")+(DATEDIF(B2,TODAY(),"YM")/12),1)` | 근속연수 (소수점 1자리) |
| E2 | `=DATEDIF(B2,TODAY(),"M")` | 총 근속 개월수 |
| F2 | `=DATEDIF(B2,TODAY(),"D")` | 총 근속 일수 |
| G2 | `=IFS(E2<12,"수습/신입",E2<36,"주니어",E2<60,"미들",TRUE,"시니어")` | 근속 등급 |

### 패턴 2. 연차 잔여일 계산

**근로기준법 제60조 기준** 연차 부여 공식입니다.

**Copilot 프롬프트**:
```
엑셀 수식 작성 (근로기준법 제60조 기준).

B2: 입사일
C2: 기준일 (TODAY())
D2: 이미 사용한 연차 일수

필요한 수식:
1. E2: 법정 연차 발생일수
   - 1년 미만: 개근 1개월당 1일 (최대 11일)
   - 1년 이상 ~ 3년 미만: 15일
   - 3년 이상: 15일 + 2년 초과마다 1일 추가 (최대 25일)
2. F2: 잔여 연차 = E2 - D2
3. G2: 잔여 연차가 5일 이하이면 "촉진 대상", 아니면 빈칸

한국어 함수명. 완성 수식으로.
```

**결과 수식 예시**:

| 셀 | 수식 |
|----|------|
| E2 (1년 미만) | `=IF(DATEDIF(B2,C2,"M")<12, MIN(DATEDIF(B2,C2,"M"), 11), MIN(15 + INT((DATEDIF(B2,C2,"Y")-1)/2), 25))` |
| F2 | `=E2-D2` |
| G2 | `=IF(F2<=5,"촉진 대상","")` |

> **주의**: 위 수식은 단순화 버전입니다. 실제 운영 시 1년 미만 구간의 월별 발생과 만 1년 도달 시 소멸 여부 등 HR 시스템과 함께 검토하세요.

### 패턴 3. 급여밴드 분류

**상황**: 직급별 급여밴드를 정의해두고, 직원별 연봉이 밴드 내에 있는지 확인합니다.

**Copilot 프롬프트**:
```
엑셀 수식 작성.

시트1: 직원 데이터
- A열: 직원ID
- B열: 직급 (사원/대리/과장/차장/부장)
- C열: 연봉 (원 단위)

시트2: 급여밴드 기준표
- A열: 직급
- B열: 밴드 하한 (원)
- C열: 밴드 상한 (원)
- D열: 밴드 중간값 (원)

시트1에 추가할 수식:
1. D열: 해당 직급의 밴드 중간값 (시트2 참조, VLOOKUP 사용)
2. E열: 밴드 대비 현재 위치 (Compa-ratio = 현재연봉/중간값, %)
3. F열: 밴드 상태
   - 중간값 80% 미만: "Under"
   - 80%~120%: "In Band"
   - 120% 초과: "Over"

완성 수식으로.
```

**결과 수식 예시**:

| 셀 | 수식 |
|----|------|
| D2 | `=VLOOKUP(B2,시트2!$A:$D,4,0)` |
| E2 | `=ROUND(C2/D2*100,1)` |
| F2 | `=IFS(E2<80,"Under",E2<=120,"In Band",TRUE,"Over")` |

### 패턴 4. 조직별 인원 집계 (COUNTIFS)

**Copilot 프롬프트**:
```
엑셀 수식 작성.

직원 마스터 시트 컬럼:
- B열: 부서명
- C열: 팀명
- D열: 재직상태 ("재직"/"휴직"/"퇴직")
- E열: 직급

필요한 수식:
1. 부서별 재직 인원 수 (COUNTIFS)
2. 팀별 재직 인원 수 (COUNTIFS, 부서+팀 조합)
3. 직급별 재직 인원 수 (COUNTIFS)
4. 휴직자 수 (부서 무관)

완성 수식 + 어느 셀에 어떻게 쓰는지 설명 포함.
```

### 패턴 5. XLOOKUP으로 직원 정보 조회

**Copilot 프롬프트**:
```
엑셀 XLOOKUP 수식 작성.

직원 마스터 시트 (A열: 직원ID, B열: 이름, C열: 부서, D열: 직급, E열: 이메일)

조회 시트에서:
- A2에 직원ID 입력
- B2에 이름 자동 표시
- C2에 부서 자동 표시
- D2에 직급 자동 표시
- E2에 이메일 자동 표시
- 없는 ID 입력 시 "직원 없음" 표시

XLOOKUP 사용. 완성 수식으로.
```

**결과 수식 예시**:

```excel
B2: =XLOOKUP(A2,직원마스터!$A:$A,직원마스터!$B:$B,"직원 없음")
C2: =XLOOKUP(A2,직원마스터!$A:$A,직원마스터!$C:$C,"")
D2: =XLOOKUP(A2,직원마스터!$A:$A,직원마스터!$D:$D,"")
E2: =XLOOKUP(A2,직원마스터!$A:$A,직원마스터!$E:$E,"")
```

## 6.3 개인정보 마스킹 기법

HR 데이터를 팀장이나 타 부서와 공유할 때, 개인정보를 마스킹해야 합니다.

### 마스킹이 필요한 상황

| 공유 대상 | 마스킹 필요 항목 |
|-----------|----------------|
| 임원 보고용 집계 | 개인 연봉 숨기기, 개인 성과 점수 숨기기 |
| 팀장 공유 (타 부서 포함) | 직원 이메일, 상세 급여 |
| 외부 컨설턴트 | 이름, 이메일, 주민번호 등 모든 개인 식별 정보 |
| 서베이 결과 원본 | 응답자 ID, 부서 (팀이 작으면 식별 가능) |

### 엑셀 마스킹 수식

**이름 마스킹 (홍*동 형태)**:

**Copilot 프롬프트**:
```
엑셀 수식 작성.

A2 셀에 이름이 있어 (예: 홍길동, 김민지, 박수아).
이름 가운데 글자를 *로 마스킹하는 수식 B2에 작성.

예: 홍길동 → 홍*동, 김민지 → 김*지
이름이 2글자이면: 첫 글자 + * (예: 박진 → 박*)
이름이 4글자 이상이면: 첫 글자 + ** + 마지막 글자

한국어 함수명. 완성 수식으로.
```

**이메일 마스킹 (앞 3자리 + ***@도메인)**:

```
A2에 이메일 주소 있어 (예: honggildong@company.com).
앞 3자리만 보이고 나머지는 ***로 마스킹.
예: honggildong@company.com → hon***@company.com

엑셀 수식으로. LEFT, FIND, MID 함수 활용.
```

**연봉 마스킹 (밴드로만 표시)**:

```
A2에 연봉 (원 단위 정수).
B2에 아래 기준으로 밴드 표시:
- 3,000만 미만: "2천만대"
- 3,000만 이상 ~ 5,000만 미만: "3~4천만대"
- 5,000만 이상 ~ 7,000만 미만: "5~6천만대"
- 7,000만 이상 ~ 1억 미만: "7~9천만대"
- 1억 이상: "1억 이상"

IFS 함수 사용. 완성 수식으로.
```

## 6.4 피벗 테이블 활용

피벗 테이블은 수식 없이 집계를 만들 수 있는 강력한 도구입니다. Copilot으로는 피벗 구성 방법을 안내받을 수 있습니다.

**Copilot 프롬프트**:
```
엑셀 피벗 테이블 구성 가이드 작성.

원본 데이터 컬럼:
직원ID | 이름 | 부서 | 팀 | 직급 | 재직상태 | 입사일 | 성별 | 연봉

만들고 싶은 피벗 3가지:
1. 부서별 직급 분포 (행: 부서, 열: 직급, 값: 인원수)
2. 팀별 재직/휴직/퇴직 인원 (행: 팀, 값: 재직상태별 COUNTIF)
3. 연봉밴드별 직급 분포 (행: 연봉밴드, 열: 직급, 값: 인원수)

각 피벗에 대해:
- 피벗 테이블 삽입 단계별 설명
- 어떤 필드를 행/열/값/필터에 넣는지
- 결과 해석 방법

출력: Markdown.
```

## 6.5 인사 대시보드 시트 구조 설계

### 대시보드가 필요한 이유

CEO나 임원이 HR 현황을 한눈에 볼 수 있는 시트입니다. 개인정보 없이 집계 지표만 표시합니다.

**Copilot 프롬프트**:
```
HR 인사 대시보드 엑셀 시트 구조 설계.

대시보드에 표시할 KPI:
1. 전체 재직 인원 (최신)
2. 부서별 인원 분포 (표)
3. 직급별 분포 (표)
4. 이번 달 신규 입사자 수
5. 이번 달 퇴직자 수
6. 현재 채용 중 포지션 수
7. 평균 근속연수 (전체 / 직급별)
8. 연차 잔여 현황 (전체 평균)

설계 내용:
- 각 KPI를 어느 셀 위치에 배치할지
- 원본 데이터 시트와의 연결 수식
- 색상 코딩 권고 (직관적 가시성)
- 매월 자동 업데이트 되는 구조

출력: Markdown (시트 레이아웃 + 수식 설명).
```

---

## 실습 — 인사 대시보드 시트 만들기

### 시나리오

> GreenTech (60명)의 HRBP 이하나 씨가 경영진 월간 보고를 위한 인사 현황 대시보드를 만들어야 합니다.

### Step 1. 직원 마스터 데이터 구조 생성

**Copilot 프롬프트**:
```
HR 직원 마스터 데이터 CSV 샘플 생성.

컬럼: 직원ID | 부서 | 팀 | 직급 | 재직상태 | 입사일 | 근속등급

조건:
- 총 15명 (가상 데이터)
- 직원ID: EMP001~EMP015
- 이름 없이 (개인정보 배제)
- 부서: 개발팀/마케팅팀/세일즈팀/운영팀 4개
- 직급: 사원/대리/과장/차장 4개
- 재직상태: 재직 12명 / 휴직 2명 / 퇴직 1명

CSV 형식으로 출력 (헤더 포함).
```

결과를 `employees-sample.csv`로 저장하세요.

### Step 2. 핵심 수식 생성

**Copilot 프롬프트**:
```
위 CSV 데이터를 엑셀에서 쓴다고 가정.

다음 집계 수식 작성:
1. 재직 인원 총합: =COUNTIF(F열,"재직")
2. 부서별 재직 인원 (COUNTIFS 사용)
3. 직급별 재직 인원 (COUNTIFS 사용)
4. 이번 달 입사자 (입사일이 이번 달인 사람 수)
5. 평균 근속연수 (입사일 기준 AVERAGE와 DATEDIF)

각 수식: 실제 셀 주소 포함, 설명 포함.
```

### Step 3. 개인정보 마스킹 수식 추가

```
직원 마스터 시트에서 외부 공유용 시트를 만들기 위한 마스킹 수식:

1. 직원ID 변환: EMP001 → "직원 #001" 형식
2. 이메일(있다면): 앞 3자리만 + ***@도메인
3. 팀 규모가 2명 이하인 경우 팀명 표시 X (개인 식별 방지)

수식 + 이유 설명 포함.
```

### Step 4. 대시보드 레이아웃 텍스트 설계

```
엑셀 대시보드 시트 레이아웃을 텍스트로 설계.

KPI 카드 6개 배치:
A1: "총 재직 인원" / A2: 집계값
C1: "이번 달 입사" / C2: 집계값
E1: "이번 달 퇴직" / E2: 집계값
A4: "평균 근속연수" / A5: 집계값
C4: "채용 중 포지션" / C5: 집계값
E4: "연차 소진율" / E5: 집계값

아래에 부서별 인원 표 + 직급별 분포 표.

각 KPI 카드의 엑셀 수식 + 조건부 서식(목표 대비 색상) 설명 포함.
```

## 핵심 포인트

1. **DATEDIF**: 근속연수·연차 계산의 핵심 함수 (날짜 간 차이 계산)
2. **VLOOKUP vs XLOOKUP**: 급여밴드 조회에는 XLOOKUP이 더 유연
3. **COUNTIFS**: 부서별·직급별·상태별 복합 조건 집계의 기본
4. **마스킹**: 이름 중간 글자 `*`, 이메일 앞 3자리만, 연봉은 밴드로
5. **대시보드**: 개인정보 없이 집계 지표만 — 원본 시트와 연결
6. **Copilot 활용**: 수식 외울 필요 없음. 원하는 결과를 한국어로 설명하면 됨

> **주의**: Copilot이 생성한 수식은 반드시 샘플 데이터로 검증 후 사용하세요. 특히 DATEDIF 함수의 "Y"/"M"/"D" 인자는 직접 셀에서 결과를 확인하는 것이 안전합니다.
