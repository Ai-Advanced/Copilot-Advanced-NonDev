## Copilot 편향 검토 프롬프트 (복붙용)

```
아래 JD를 편향 언어 관점에서 검토해줘.

검토 항목:
1. 성별 편향 (남성/여성 코딩 언어)
2. 연령 편향 (나이 암시 표현)
3. 학력/출신 편향 (학벌, 출신 지역)
4. 신체 조건 편향 (외모, 체력)
5. 채용절차법 위반 소지 (혼인, 자녀, 재산, 종교)
6. 자격 요건 과잉 (직무 무관 요건)

결과 형식:
- 발견된 표현 | 편향 유형 | 개선안
- 문제 없으면 "해당 없음" 명시
- 편향 제거된 최종 JD 전체 출력

[--- JD 시작 ---]
(JD 붙여넣기)
[--- JD 끝 ---]
```

## 편향 표현 대체 레퍼런스

| 편향 표현 | 유형 | 대체 표현 |
|-----------|------|-----------|
| 젊고 패기 있는 | 연령 | 주도적이고 성장 지향적인 |
| 디지털 네이티브 | 연령 | 디지털 툴에 익숙한 |
| 체력이 강한 | 신체 | (실제 업무 요건으로 대체) |
| 단정한 외모 | 외모 | 삭제 |
| 명문대 졸업 | 학벌 | 삭제 또는 관련 전공 |
| 군필 또는 면제자 | 성별 | 삭제 |
| 강한 추진력 | 젠더 | 실행력과 목표 달성 역량 |
| 부드러운 소통 | 젠더 | 협업과 커뮤니케이션 역량 |
| 결혼 여부 | 혼인 | 삭제 |
| 자녀 계획 | 혼인 | 삭제 |
| SKY 이상 우대 | 학벌 | 삭제 |
| 외향적인 성격 | 성격 편향 | 팀 협업에 적극적인 |
| 협조적인 분 | 순응 편향 | 협업 역량이 뛰어난 |
