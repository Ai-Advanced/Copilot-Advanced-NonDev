# 재무 / 회계팀을 위한 GitHub Copilot 2일 심화 과정

> **대상**: 재무팀, 회계팀, FP&A, 세무 담당자, 경영관리 담당자
> **기간**: 2일 (각 3~4시간, 총 6~8시간)
> **선행 조건**: [00-basics/](../00-basics/) 5개 문서 완료 필수

---

## 이 과정이 필요한 이유

재무/회계 업무는 **정확성이 생명**입니다. 단 1원의 오차도 감사 지적 사유가 됩니다.
그런데 동시에, 매달 반복되는 마감 업무, 수백 개의 수식, 수십 장의 리포트가 쌓입니다.

Copilot은 이 반복 부담을 줄여줍니다. 단, 재무 담당자는 AI가 생성한 결과를
**반드시 검증**해야 합니다. 이 과정은 "빠르게 초안 만들기"와 "정확하게 검증하기"를
동시에 훈련합니다.

### 이 과정으로 얻는 것

| 업무 | Before | After |
|------|--------|-------|
| 엑셀 수식 작성 | 30분 검색 + 시행착오 | Copilot 프롬프트 1개로 5분 |
| VBA 매크로 | 외주 또는 개발자 의뢰 | 직접 생성 + 수정 |
| 월결산 SQL | 매달 동일 쿼리 재작성 | 저장된 쿼리 + Copilot 변형 |
| 재무제표 리포트 | 수동 복붙, 2~3시간 | Python/VBA 자동 생성 |
| 세무 문서 초안 | 양식 찾기 + 작성 60분 | Copilot 초안 15분 + 검토 |

## Day 1 개요 (3~4시간)

### 01. 재무/회계 관점의 Copilot 활용 (60분)

재무 업무에서 Copilot이 어떤 영역에서 시간을 절약하는지, Before/After 3개 시나리오로 확인합니다. SOX 감사, K-IFRS 데이터 취급 시 주의 사항도 다룹니다.

### 02. 엑셀 수식 마스터리 (90분)

VLOOKUP/XLOOKUP/INDEX-MATCH, SUMIFS/COUNTIFS, NPV/IRR/PMT, 배열수식(FILTER/SORT/UNIQUE)을 재무 실전 데이터로 학습합니다. Copilot에게 수식을 잘 요청하는 방법을 집중 훈련합니다.

### 03. VBA 매크로 기초 (60분)

Copilot으로 VBA 코드를 생성하고 리팩토링합니다. 월별 리포트 시트 자동 생성, PDF 저장 자동화, 오류 핸들링을 다룹니다.

### 04. Day 1 종합 실습 (30~60분)

"월 마감 자동화 준비" 시나리오로 수식 세트 + VBA 매크로를 실전 조합합니다.

## Day 2 개요 (3~4시간)

### 05. 재무용 SQL (60분)

매출/원가 집계, 계정과목 롤업, 기간 비교(YoY/QoQ), 환율 조인, 재무제표 SQL 20개 패턴을 다룹니다.

### 06. Python 회계 자동화 (60분)

pandas로 은행 명세서 자동 분개, 매입매출 매칭, 예산 vs 실적 편차 분석 스크립트를 만듭니다.

### 07. 리포트 자동화 (45분)

다중 시트 통합, PDF 자동 생성, 이메일 자동화 파이프라인을 구성합니다.

### 08. 캡스톤 (60~90분)

데이터 수집(SQL) → 정제(Python/VBA) → 재무제표 생성(Excel) → 이상치 검증 → 임원 리포트 → PDF/이메일 발송까지, 월 결산 자동화 전체 흐름을 완성합니다.

## 재무 데이터 취급 원칙

이 과정 전체에 걸쳐 반복 강조하는 원칙입니다. 시작 전 반드시 숙지하세요.

### 원칙 1. Copilot 결과는 초안이다

Copilot이 생성한 수식, 쿼리, 스크립트는 **반드시 사람이 검증**합니다.
재무 계산에서 1%의 오차도 용납되지 않습니다.

```
검증 체크리스트 (매번):
[ ] 총계 일치 (합계 행 검증)
[ ] 전기 대비 변동 설명 가능한가
[ ] 음수/양수 방향이 올바른가 (비용은 음수? 양수?)
[ ] 원 단위 처리 일관성 (1원 단위 vs 천원 단위)
[ ] 세율/이자율 적용 기준 명확한가
```

### 원칙 2. Copilot이 모르는 것들

- **사내 계정과목 체계**: Copilot은 여러분 회사의 계정과목 코드를 모릅니다. 맥락 파일에 명시하세요.
- **최신 세율**: 법인세율, 부가세, 지방소득세 계산은 반드시 최신 국세청 기준으로 검증하세요.
- **K-GAAP vs K-IFRS 차이**: 재고자산 평가, 리스 회계 등은 기준서 직접 확인이 필요합니다.
- **환율 고시**: 한국은행 고시 환율은 Copilot이 알 수 없습니다. 항상 외부 소스로 가져오세요.

### 원칙 3. 감사 추적 가능성

자동화 스크립트가 생성한 숫자는 **어디서 왔는지 추적 가능**해야 합니다.
원본 데이터 → 변환 로직 → 최종 숫자의 연결 고리를 항상 유지하세요.

### 원칙 4. 민감 데이터 보호

실습에는 **가상/익명 데이터만 사용**합니다. 실제 거래처명, 직원 급여, 고객 정보를
Copilot Chat에 입력하지 마세요. 회사 정보보안 정책을 확인하세요.

## 자주 묻는 질문 (FAQ)

**Q. Python을 전혀 모르는데 Day 2를 따라갈 수 있나요?**

네. 이 과정은 Python을 "배우는" 것이 아니라 Copilot이 생성한 스크립트를 "활용하는" 것입니다. 코드의 동작 원리는 설명과 주석으로 이해하고, 실습은 복붙 → 실행 → 결과 검증 흐름으로 진행합니다.

**Q. 회사 ERP가 SQL을 지원하지 않으면 어떻게 하나요?**

ERP에서 Excel이나 CSV로 데이터를 내보낼 수 있다면 충분합니다. SQL 챕터는 데이터베이스 직접 접근이 없어도 VS Code에서 SQLite로 실습 가능하도록 설계되어 있습니다.

**Q. 실제 회사 데이터를 Copilot Chat에 입력해도 되나요?**

실제 거래처명, 직원 급여, 고객 정보, 미공개 재무 수치는 절대 입력하지 마세요. 계정과목 코드, 테이블 스키마, 익명화된 샘플 데이터는 입력 가능합니다. 회사 정보보안 정책을 반드시 먼저 확인하세요.

**Q. Copilot이 만든 수식/쿼리를 그냥 써도 되나요?**

안 됩니다. 재무 데이터의 정확성은 회사 의사결정과 감사에 직결됩니다. 생성된 결과는 반드시 합계 검증, 전기 비교, 단위 일관성 체크를 거친 후 사용하세요.
