## 5대 업무 영역별 한 줄 프롬프트 공식

### 엑셀 수식
```
[범위 설명] + [원하는 결과] + [사용할 함수] + [오류 처리 방식] 수식 작성.
```
**예**: `A열=날짜, B열=금액. 2026-01의 합계. SUMIFS 사용. 수식만.`

### VBA 매크로
```
목적: [무엇을 자동화]. 동작 1-2-3. 오류 처리 포함. 전체 코드 + 주석.
```
**예**: `목적: 월별 시트 12개 생성. 동작: 양식 복사→이름 변경→중복 건너뜀. 전체 코드.`

### SQL
```
테이블 [스키마]. 목표: [무엇을 뽑나]. 결과 컬럼: [열 목록]. 정렬: [기준].
```
**예**: `gl_entries(날짜, 계정, 차변, 대변). 2026-01 계정별 잔액. 계정코드 오름차순.`

### Python (pandas)
```
입력: [파일/형식]. 처리: 1-2-3. 출력: [결과 파일]. 주석 포함.
```
**예**: `입력: bank.csv. 처리: 적요 키워드→계정 매핑→분개 생성. 출력: journal.csv.`

### 문서 작성
```
[문서 종류] 작성. 대상: [독자]. 포함: [항목들]. 톤: [수치 위주/공식적]. 단위: 억원.
```
**예**: `임원 실적 보고 Markdown. 대상: CFO. 포함: KPI표/이슈/전망. 수치 중심.`

## Copilot이 자주 틀리는 재무 항목

| 오류 유형 | 예시 | 검증 방법 |
|----------|------|----------|
| 세율 오류 | 법인세율 25%를 단순 적용 (과표 구간 무시) | 과표 구간별 누진 계산 직접 확인 |
| 반올림 오차 | ROUND vs ROUNDDOWN 혼용 | 원 단위 정책 일관성 체크 |
| 대차 방향 혼동 | 비용 증가를 Credit으로 처리 | 분개 차변=대변 합계 검증 |
| 회계연도 착각 | 12월 결산 vs 3월 결산 혼용 | 항상 회계연도 명시 |
| 환율 고시 | 임의 환율 사용 | 한국은행 고시 환율로 대체 |
| IFRS vs K-GAAP 혼용 | 리스 회계 방식 혼동 | 적용 기준서 명시 후 재질의 |

## 검증 5초 체크리스트

수식/SQL/스크립트 결과 나왔을 때 반드시:

- [ ] **합계 일치**: 행 합계 = 열 합계 = 총계
- [ ] **부호 확인**: 비용이 양수인지 음수인지 일관성
- [ ] **단위 확인**: 원/천원/백만원/억원 혼용 없는지
- [ ] **기간 확인**: WHERE 조건의 날짜 범위가 정확한지
- [ ] **이전 결과 비교**: 지난달 대비 설명 불가능한 급변 없는지

## 자주 쓰는 엑셀 함수 한 줄 요약

| 함수 | 용도 |
|------|------|
| `=SUMIFS(합계범위, 조건범위1, 조건1, ...)` | 다중 조건 합계 |
| `=XLOOKUP(값, 범위, 반환범위, "미등록")` | 안전한 룩업 |
| `=IFERROR(수식, 대체값)` | 오류 처리 |
| `=EOMONTH(날짜, 0)` | 해당 월 말일 |
| `=NETWORKDAYS(시작, 종료)` | 영업일 수 |
| `=NPV(할인율, 현금흐름범위)` | 순현재가치 |
| `=IRR(현금흐름범위)` | 내부수익률 |
| `=PMT(이자율/12, 기간, 원금)` | 월 상환액 |
| `=YEARFRAC(시작, 종료, 1)` | 연수(분수) |
| `=FILTER(범위, 조건)` | 동적 필터 (365) |

## Python pandas 1분 참고

# CSV 읽기 (한글 인코딩)
df = pd.read_csv("file.csv", encoding="utf-8-sig")
