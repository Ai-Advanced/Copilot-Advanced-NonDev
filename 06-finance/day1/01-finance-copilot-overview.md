# 01. 재무/회계 담당자를 위한 Copilot 활용 개요

## 학습 목표

- 재무/회계 업무에서 Copilot이 시간을 절약하는 **15가지 활용 영역** 파악
- Before/After 시나리오 3개로 실질적 효과 체감
- 재무 데이터의 민감성과 SOX/K-IFRS 관점에서의 **데이터 취급 주의 사항** 이해
- "Copilot이 틀릴 수 있는 재무 영역"을 미리 파악해서 검증 습관 형성

**예상 소요**: 60분 (실습 포함)

---

## 1.1 재무/회계 업무, 얼마나 반복적인가

재무팀의 일주일을 돌아보면 대부분 비슷한 업무가 반복됩니다.

| 주기 | 반복 업무 | 평균 소요 시간 |
|------|----------|--------------|
| 매일 | 전표 입력, 은행 잔액 확인, 미결 전표 처리 | 1~2시간 |
| 주간 | 지출 결의 처리, 예산 잔액 확인 | 2~3시간 |
| 월간 | 월 결산, 부서별 실적 집계, 리포트 작성 | 3~5일 |
| 분기 | 분기 재무제표 작성, 예산 재예측 | 5~7일 |
| 연간 | 결산, 외부감사 대응, 세무 신고 | 수주 |

이 반복 업무의 **40~60%는 데이터 조회 + 수식 작성 + 리포트 편집**입니다.
바로 Copilot이 가장 큰 도움을 줄 수 있는 영역이기도 합니다.

---

## 1.2 재무/회계 Copilot 15가지 활용 영역

### 영역 1. 엑셀 수식 즉석 생성

**상황**: XLOOKUP, SUMIFS, OFFSET 등 복잡한 수식을 매번 검색하는 데 20~30분.

**Copilot 활용**:
```
A열=전표일자, B열=계정코드, C열=차변, D열=대변.
계정코드가 '4000'인 대변 합계를 구하는 SUMIFS 수식 작성.
F2 셀 기준, 절대참조 사용.
```
5초 만에 검증 가능한 수식 제공. 설명까지 포함.

---

### 영역 2. VBA 매크로 생성 및 수정

**상황**: 매달 12개 시트를 손으로 복사하고 이름 바꾸는 작업 30분.

**Copilot 활용**: "양식 시트를 복사해서 2026-01~2026-12 시트를 자동 생성하는 VBA 매크로" 한 줄 요청으로 완성 코드 수령.

---

### 영역 3. SQL로 ERP/DB 데이터 추출

**상황**: 개발팀에 SQL 작성 요청 → 1~2일 대기 → 수정 요청 반복.

**Copilot 활용**: 테이블 스키마와 원하는 결과를 설명하면 즉석에서 SQL 초안 생성. 스스로 수정 가능.

---

### 영역 4. Python 자동 분개

**상황**: 은행 명세서 CSV 600건을 수동으로 계정 분류하는 데 반나절.

**Copilot 활용**: 적요 키워드 기반 자동 계정 매핑 스크립트. 처음 1시간만 세팅하면 이후 3분으로 단축.

---

### 영역 5. 재무제표 초안 자동 생성

**상황**: 손익계산서 양식을 매달 복붙으로 업데이트, 합계 수식 수동 확인.

**Copilot 활용**: openpyxl 스크립트로 집계 데이터에서 재무제표 자동 생성 + 서식 적용.

---

### 영역 6. 예산 편차 분석 자동화

**상황**: 예산 파일과 실적 파일을 수동으로 VLOOKUP 연결, 매달 2~3시간.

**Copilot 활용**: pandas 스크립트로 두 파일 병합 + 편차 계산 + 하이라이트 Excel 출력.

---

### 영역 7. 감사 샘플 추출

**상황**: 외부 감사 요청으로 특정 기간, 특정 금액 범위의 거래 샘플 수작업 추출.

**Copilot 활용**: 층화 샘플링 스크립트. 금액 기준 버킷별 샘플 비율로 자동 추출, audit trail 포함.

---

### 영역 8. 규정/기준서 초안 작성

**상황**: 회계 처리 기준서, 지출결의 절차서 등 내부 문서 작성에 2~3시간.

**Copilot 활용**: 항목 목록만 제시하면 K-IFRS 관점의 절차서 초안 15분 내 완성. 실무자가 검토/수정만.

---

### 영역 9. 세무 신고 준비 체크리스트

**상황**: 부가세 신고, 법인세 신고 준비 항목을 매번 새로 정리.

**Copilot 활용**: 신고 유형을 알려주면 단계별 체크리스트, 준비 서류 목록, 일정 표 즉석 생성.

---

### 영역 10. 현금흐름 예측 모델

**상황**: 13주 현금흐름 예측 스프레드시트를 매주 수동 업데이트.

**Copilot 활용**: 입금/출금 패턴 설명으로 수식 구조 및 롤링 예측 수식 설계 지원.

---

### 영역 11. 이상치 탐지 자동화

**상황**: 월말 결산 전 비정상 전표(중복, 이상 금액)를 눈으로 일일이 확인.

**Copilot 활용**: 이상치 탐지 로직을 Python 스크립트로 구현. 중복 전표, 라운드 넘버 집중, 주말 입력 등 자동 플래그.

---

### 영역 12. 임원 보고 자료 초안

**상황**: 월말 CFO 보고 자료 작성에 반나절. 수치가 바뀌면 전체 재작업.

**Copilot 활용**: 보고 구조 템플릿을 한 번 만들어두면, 수치만 교체하는 방식으로 작업 시간 70% 단축.

---

### 영역 13. 감사 대응 설명 자료

**상황**: 외부 감사인 질의 응답 자료를 매번 새로 작성.

**Copilot 활용**: 감사 영역 + 관련 K-IFRS 기준 + 내부 프로세스를 프롬프트로 주면 조서 설명 자료 초안 생성.

---

### 영역 14. 여러 파일 통합

**상황**: 각 부서에서 제출한 Excel 파일 20개를 수동으로 복붙하여 통합.

**Copilot 활용**: VBA 매크로 또는 Python 스크립트로 폴더 내 모든 파일을 자동 통합. 출처 파일명 자동 기록.

---

### 영역 15. 사내 공문/이메일 초안

**상황**: 마감 안내, 예산 편성 지침, 감사 협조 요청 이메일을 매번 새로 작성.

**Copilot 활용**: 상황과 포함 내용을 알려주면 공식적 톤의 이메일 초안 5분 내 완성.

## 1.3 Before / After 시나리오 3개

### 시나리오 A. 월결산 부서별 실적 집계

**Before**: 각 부서 ERP에서 데이터 Export → Excel 20개 파일 수동 복붙 → SUMIFS 수식으로 집계 → 합계 검증 → 총 4~5시간.

**After**:
```
VBA 매크로 작성:
C:\Finance\Input 폴더의 모든 .xlsx 파일에서
"실적" 시트의 B열:E열 2행~마지막 행을
"통합" 시트에 자동 통합.
파일명을 F열에 기록.
첫 파일 헤더만 포함.
```
→ Copilot이 VBA 완성 코드 생성 → 사람이 검증 → 실행 → **10분으로 단축.**

검증 체크:
- 통합 행 수 = 각 파일 행 수 합계인가?
- 임의 부서 하나를 원본과 비교해서 수치 일치 확인

---

### 시나리오 B. 외화 매출 원화 환산

**Before**: USD 매출 500건을 날짜별 고시 환율 수동 조회 → VLOOKUP → 환산 → 합계. 1시간 30분.

**After**:
```
SQL 쿼리 작성.
테이블:
- sales(id, sale_date, amount_usd, customer_id)
- exchange_rates(rate_date, currency, krw_rate)

USD 매출을 거래일 환율로 원화 환산.
환율 없는 날은 가장 최근 이전 환율 사용 (LAG 윈도우 함수).
결과: sale_date, amount_usd, krw_rate, amount_krw
```
→ 쿼리 생성 → 스테이징 DB에서 실행 → **20분으로 단축.**

검증 체크:
- 환율이 NULL인 행 없는지 확인
- 대표 날짜 1~2개 고시 환율과 대조

---

### 시나리오 C. 법인카드 경비 분류

**Before**: 법인카드 이용 내역 CSV 300건을 수동으로 열어 계정과목 입력. 반나절.

**After**:
```python
# Copilot 요청: pandas 스크립트
# 입력: card_statement.csv (날짜, 가맹점명, 금액)
# 분류 규칙: 가맹점명에 키워드가 포함되면 계정 자동 분류
# 키워드 딕셔너리 사용
# 매칭 안 되면 "기타경비"로 분류
# 출력: classified_expenses.csv
```
→ Copilot이 스크립트 생성 → 키워드 딕셔너리만 사내 가맹점에 맞게 수정 → 실행 → **30분으로 단축.**

검증 체크:
- "기타경비"로 분류된 건은 사람이 직접 확인
- 고금액 건(예: 50만원 이상)은 계정 맞는지 교차 확인

## 1.4 재무 데이터 취급 주의 사항

### SOX / K-SOX 관점

SOX(Sarbanes-Oxley Act) 또는 한국의 내부회계관리제도(K-SOX)를 적용받는 기업은
재무 데이터 처리 과정에서 **감사 추적 가능성**이 필요합니다.

Copilot 활용 시 주의 사항:

1. **자동화 스크립트는 문서화**: 어떤 로직으로 어떤 데이터를 처리했는지 스크립트 주석 또는 별도 문서로 유지
2. **원본 데이터 보존**: 자동 처리 전 원본 파일 백업 필수
3. **변경 이력 관리**: Git 또는 파일 버전 관리로 스크립트 변경 이력 추적
4. **접근 권한 분리**: 데이터 처리 스크립트가 쓰기 권한을 가진 DB에 직접 연결하지 않도록
5. **결과 검증 증적**: 검증 수행 사실을 기록 (누가, 언제, 어떤 방법으로)

### K-IFRS 관련 주의

Copilot은 K-IFRS 기준서의 세부 내용을 알고 있지만, **해석은 사람이 해야 합니다.**

| 영역 | Copilot 한계 | 필수 확인 |
|------|-------------|---------|
| 수익 인식 (K-IFRS 15) | 계약별 수행의무 식별 불가 | 계약서 직접 검토 |
| 리스 회계 (K-IFRS 16) | 내재이자율 산정 불가 | 실제 계약 조건 확인 |
| 금융상품 (K-IFRS 9) | ECL 모델 파라미터 모름 | 신용위험 평가 별도 |
| 법인세 (K-IFRS 12) | 일시적 차이 자동 식별 불가 | 세무조정 내역 검토 |

### 프롬프트에 넣으면 안 되는 것들

```
절대 입력 금지:
- 실제 거래처 사업자번호 / 계좌번호
- 직원 주민등록번호 / 급여 실액
- 미공개 재무 수치 (상장사의 경우 공시 전)
- 고객 개인정보 (이름, 연락처)
- 내부 ERP 접근 비밀번호

입력 가능 (익명화 후):
- 계정과목 코드 (구체적 금액 없이)
- 스키마/헤더 구조
- 가상의 샘플 데이터 3~5줄
```

## 1.5 Copilot이 틀리는 재무 영역 (사전 경보)

이 과정 전체에서 반복 강조하는 내용입니다. 미리 알면 검증이 쉬워집니다.

### 실수 유형 1. 세율 단순 적용

**예시**: "법인세 계산 수식 만들어줘"라고 하면, Copilot이 종종 **단일 세율(예: 22%)**을 적용합니다.

**실제**: 법인세는 과표 구간별 누진세율 적용 (예: 2억 이하 9%, 2억~200억 19% 등, 매년 확인 필요).

**검증**: 산출 세액을 국세청 계산 방식과 직접 비교.

### 실수 유형 2. 반올림 정책 혼용

**예시**: Copilot이 어떤 수식은 ROUND를 쓰고 어떤 수식은 ROUNDDOWN을 씁니다.

**실제**: 원화 정수 처리는 사내 정책으로 통일 (예: 부가세는 원 단위 절사).

**검증**: 수식에 사용된 반올림 함수를 모두 검색해서 일관성 확인.

### 실수 유형 3. 차변/대변 방향 오류

**예시**: "비용 증가 분개 작성"에서 Copilot이 차변/대변을 반대로 작성하는 경우.

**실제**: 자산/비용 증가 = 차변, 부채/자본/수익 증가 = 대변.

**검증**: 생성된 분개의 차변 합계 = 대변 합계 체크. 계정 성격과 방향 교차 확인.

### 실수 유형 4. 회계 기간 경계 오류

**예시**: "2025년 4분기 매출" 요청 시 WHERE 조건을 `>= '2025-10-01' AND < '2026-01-01'`이 아닌 `<= '2025-12-31'`로 작성 (날짜 형식에 따라 마지막 날의 시간 포함 여부).

**검증**: BETWEEN vs `>=`, `<` 조합의 차이 이해. 시간 포함 날짜 컬럼은 `< '2026-01-01'` 방식 권장.

### 실수 유형 5. IFRS vs K-GAAP 혼용

**예시**: 재고자산 평가 방법을 K-GAAP 기준(선입선출/평균법)으로 설명하면서 K-IFRS에서 허용하는 방법을 잘못 안내.

**실제**: K-IFRS에서는 LIFO(후입선출법) 사용 금지.

**검증**: 회계 처리 기준은 항상 기준서 원문 또는 공인회계사 확인.

## 1.6 Copilot 활용을 위한 첫 번째 설정

### Copilot Instructions 파일 만들기

VS Code에서 Copilot에게 "우리 회사 맥락"을 항상 주입하려면 `.github/copilot-instructions.md` 파일을 만듭니다. 이 파일의 내용은 모든 Copilot Chat 세션에 자동으로 포함됩니다.

재무팀용 예시:

```markdown
## 회사 재무 맥락

회계연도: 1월 1일 ~ 12월 31일
기능통화: KRW (대한민국 원)
금액 단위: 원 (정수, 소수점 없음)
회계 기준: K-IFRS (한국채택국제회계기준)
분기: Q1=1~3월, Q2=4~6월, Q3=7~9월, Q4=10~12월

계정과목 체계 (주요):
- 1011: 보통예금
- 1100: 매출채권
- 2100: 매입채무
- 4000: 매출
- 5110: 급여
- 5200: 매출원가

주의사항:
- 세율은 항상 현행 법률 기준으로 확인 필요 표시
- 외화 환산은 한국은행 기준 환율 사용
- 반올림은 원 단위 절사 (ROUNDDOWN)
```

이 파일 하나로 모든 프롬프트에서 회사 맥락을 다시 설명할 필요가 없어집니다.

## 실습

### 실습 1. 내 업무 반복 항목 목록화

지금 사용하는 Excel 파일이나 반복 업무 3가지를 고르고, 아래 항목을 채워보세요:

```
업무명: ________________________
현재 소요 시간: ________________
반복 주기: ____________________
Copilot 활용 가능성: (영역 1~15 중 해당) ___
예상 단축 시간: ________________
```

### 실습 2. Instructions 파일 초안 만들기

VS Code에서 새 파일 `copilot-instructions.md`를 열고, 아래 프롬프트로 초안을 만들어보세요:

```
우리 회사 재무팀의 GitHub Copilot Instructions 파일 초안 작성.

포함:
- 회계연도 기준
- 기능통화 및 금액 단위
- 회계 기준 (K-IFRS / K-GAAP)
- 주요 계정과목 코드 (임의로 5개)
- Copilot에게 주의시킬 사항 3개 (세율, 환율, 반올림)
```

생성된 초안을 실제 사내 기준에 맞게 수정하세요.

### 실습 3. Before/After 시나리오 선정

2일 과정이 끝났을 때 "이것 하나는 자동화하겠다"고 결심하는 업무를 지금 선정하세요. 다음 기준으로 고르면 좋습니다:

- 월 1회 이상 반복되는가?
- 현재 소요 시간이 1시간 이상인가?
- 입력 데이터가 일정한 형식인가? (Excel, CSV, DB 등)

→ 선정한 업무를 Day 2 캡스톤에서 실제로 자동화합니다.

## 핵심 포인트

1. 재무/회계 업무의 40~60%는 반복적이고 Copilot이 도움을 줄 수 있다
2. **15개 활용 영역** 중 나에게 맞는 3~5개를 먼저 집중 학습
3. Copilot 결과는 **항상 검증**: 합계 확인, 전기 비교, 단위 일관성 체크
4. **세율/환율/기준서** 내용은 Copilot을 참고 수준으로만 사용, 최종은 공식 소스 확인
5. `copilot-instructions.md`로 회사 맥락을 사전 주입하면 매 프롬프트가 짧아진다
