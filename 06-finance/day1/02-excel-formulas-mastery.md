## 2.1 Copilot에게 수식 프롬프팅 잘하기

수식 요청에서 가장 중요한 것은 **맥락을 정확하게 주는 것**입니다.

### 수식 프롬프트의 5요소

```
1. 데이터 위치: "A열에 날짜, B열에 계정코드, C열에 금액"
2. 목표 결과: "계정코드 4000인 것의 금액 합계"
3. 사용 함수: "SUMIFS 사용" (없으면 Copilot이 선택)
4. 결과 셀: "D2 셀에 입력할 수식"
5. 예외 처리: "빈 셀 무시, 오류 시 0 반환"
```

### BAD vs GOOD 비교

**BAD 프롬프트**
```
매출 합계 구하는 수식 알려줘
```
→ 어떤 컬럼인지, 어떤 조건인지, 어떤 함수를 원하는지 모름. 쓸모없는 답변.

**GOOD 프롬프트**
```
엑셀 수식 작성.

데이터 위치:
- A2:A500: 전표일자 (날짜 형식)
- B2:B500: 계정코드 (텍스트, 예: "4000")
- C2:C500: 부서코드 (텍스트, 예: "SALES")
- D2:D500: 금액 (숫자, 원 단위)

목표: 계정코드가 "4000"이고 부서코드가 "SALES"인 금액의 합계
결과 셀: G2
함수: SUMIFS 사용
조건값은 셀 참조(F1, F2)가 아닌 직접 입력 방식으로
```

→ 바로 붙여넣기 가능한 수식:
```
=SUMIFS(D2:D500, B2:B500, "4000", C2:C500, "SALES")
```

### 셀 예시를 주면 더 정확해진다

프롬프트에 실제 데이터 샘플 3~5줄을 넣으면 Copilot이 데이터 형식을 정확히 이해합니다:

```
샘플 데이터 (A1:D5):
A           B       C       D
전표일자    계정코드  부서코드  금액
2026-01-05  4000    SALES   5,000,000
2026-01-10  5110    HR      2,500,000
2026-01-15  4000    MFG     3,200,000
2026-01-20  5200    MFG     1,800,000
```

이 샘플을 프롬프트에 붙이면 컬럼명, 데이터 타입, 형식을 자동으로 파악합니다.

## 2.2 룩업 함수 (VLOOKUP / XLOOKUP / INDEX-MATCH)

### VLOOKUP의 한계와 XLOOKUP으로의 전환

VLOOKUP은 **왼쪽 방향 조회 불가**, **열 번호 하드코딩** 문제가 있습니다.
Microsoft 365에서는 XLOOKUP을 사용하세요.

#### VLOOKUP 기본 패턴
```
=VLOOKUP(조회값, 테이블범위, 열번호, FALSE)
```

실전 예: 거래처코드(A2)로 거래처명 조회
```
=VLOOKUP(A2, 거래처!$A:$B, 2, FALSE)
```

**VLOOKUP 함정**: 거래처 테이블에 열이 추가되면 열 번호가 틀어짐. `FALSE` 빠뜨리면 근사 일치로 잘못된 값 반환.

#### XLOOKUP (권장, Microsoft 365)

```
=XLOOKUP(조회값, 검색범위, 반환범위, "찾지못함", 일치모드, 검색모드)
```

실전 예: 계정코드(B2)로 계정명 조회, 없으면 "미등록" 표시
```
=XLOOKUP(B2, 계정마스터!$A:$A, 계정마스터!$B:$B, "미등록")
```

**XLOOKUP의 강점**:
- 오른쪽→왼쪽 조회 가능
- not_found 인수로 오류 처리 내장
- 여러 열 반환 가능

**Copilot 프롬프트**:
```
엑셀 수식 작성.

시트1: A열 계정코드, B열 계정명, C열 계정유형
시트2 D3 셀에 계정코드 입력 시 계정명(시트1 B열)과 계정유형(시트1 C열)을
두 수식으로 각각 E3, F3에 가져오기.
없는 코드면 "미등록" 표시.
XLOOKUP 사용. Microsoft 365 기준.
```

#### INDEX-MATCH (2019 이하 호환)

XLOOKUP을 사용하지 못하는 환경에서의 대안:

```
=INDEX(반환범위, MATCH(조회값, 검색범위, 0))
```

실전 예: 다중 조건 조회 (연도 + 분기 + 부서)
```
=INDEX(D2:D200, MATCH(1, (A2:A200=H1)*(B2:B200=H2)*(C2:C200=H3), 0))
```
※ Ctrl+Shift+Enter로 배열 수식 입력 (Microsoft 365에서는 일반 Enter)

**Copilot 프롬프트**:
```
엑셀 수식 작성. Excel 2019 호환.

데이터: A열=연도, B열=분기, C열=부서, D열=매출액 (A2:D200)
조건: 연도=H1, 분기=H2, 부서=H3

INDEX-MATCH 다중 조건 수식 작성.
배열 수식 버전과 비배열 버전(ISNUMBER+MATCH 조합) 둘 다 제시.
```

## 2.3 조건 집계 (SUMIFS / COUNTIFS / AVERAGEIFS)

재무 업무에서 가장 많이 쓰는 수식 범주입니다.

### SUMIFS 패턴 모음

기본 구조:
```
=SUMIFS(합계범위, 조건범위1, 조건1, 조건범위2, 조건2, ...)
```

**패턴 1. 특정 월, 특정 계정 합계**
```
=SUMIFS(D:D, A:A, ">="&DATE(2026,1,1), A:A, "<="&EOMONTH(DATE(2026,1,1),0), B:B, "4000")
```

**패턴 2. 와일드카드 조건 (계정코드 4로 시작하는 매출 계정 전체)**
```
=SUMIFS(D:D, B:B, "4*")
```

**패턴 3. 부서가 특정 목록에 속하는 합계 (SUMPRODUCT 활용)**
```
=SUMPRODUCT((ISNUMBER(MATCH(C2:C500,{"SALES","MFG","R&D"},0)))*D2:D500)
```

**패턴 4. 날짜 범위 + 조건 (분기 합계)**
```
=SUMIFS(D:D, A:A, ">="&DATE(YEAR(TODAY()),4,1), A:A, "<"&DATE(YEAR(TODAY()),7,1))
```

**Copilot 프롬프트**:
```
엑셀 SUMIFS 수식 5개 작성.

데이터: A열=전표일자(날짜), B열=계정코드, C열=부서코드, D열=금액(원)
A1:D1은 헤더, 데이터는 2행부터 500행까지.

수식 1: 2026년 1월, 계정 "4000", 부서 "SALES"의 합계 (G2)
수식 2: 2026년 상반기(1~6월) 전체 매출 합계 (계정코드 "4"로 시작, G3)
수식 3: 이번 달 경비 합계 (계정코드 "5"로 시작, 날짜 기준 EOMONTH 활용, G4)
수식 4: 부서가 "SALES" 또는 "MFG"인 금액 합계 (SUMPRODUCT 활용, G5)
수식 5: 금액이 1,000,000원 이상인 건수 (COUNTIFS, G6)

오류 처리(IFERROR) 포함. 설명도 한 줄씩 추가.
```

### COUNTIFS 재무 활용

```
# 특정 계정 전표 건수
=COUNTIFS(B:B, "4000", A:A, ">="&DATE(2026,1,1))

# 금액이 0인 전표 (오류 가능성)
=COUNTIFS(D:D, 0)

# 특정 부서의 비용 건수
=COUNTIFS(B:B, "5*", C:C, "HR")
```

## 2.4 재무 함수 (NPV / IRR / PMT / FV / PV)

### NPV (순현재가치)

```
=NPV(할인율, 미래현금흐름범위) + 초기투자액(음수)
```

주의: NPV 함수는 **첫 번째 현금흐름이 1기 말**이라고 가정합니다. 기초(0기) 투자액은 별도 더해야 합니다.

실전 예: 초기 투자 5억, 5년간 현금흐름 B2:F2, 할인율 8%
```
=NPV(0.08, B2:F2) + A2    (A2 = -500,000,000)
```

**Copilot 함정**: "NPV 계산 수식 만들어줘"라고 하면 초기 투자를 NPV 범위에 포함시켜 1기 말로 잘못 처리할 수 있습니다. 항상 **초기 투자를 분리**하도록 명시하세요.

### IRR (내부수익률)

```
=IRR(현금흐름범위, 추정값)
```

실전 예: A2=-500,000,000 (초기투자), B2:F2=연간 현금흐름
```
=IRR(A2:F2)
```

**주의**: IRR이 수렴하지 않으면 #NUM! 오류. 추정값 인수(기본 10%)를 조정하거나 XIRR 사용.

불규칙 현금흐름은 XIRR 사용:
```
=XIRR(현금흐름범위, 날짜범위)
```

### PMT (원리금 균등 상환)

```
=PMT(이자율/기간, 총기간수, 현재가치, [미래가치], [지불시점])
```

실전 예: 2억 대출, 연 4.5%, 60개월 상환
```
=PMT(0.045/12, 60, -200000000)
```

결과는 **음수**(지불액)로 반환됩니다. 절대값이 필요하면 ABS() 감쌈:
```
=ABS(PMT(0.045/12, 60, -200000000))
```

**Copilot 프롬프트**:
```
엑셀 대출 상환 테이블 수식 작성.

대출 조건:
- 대출금액: B1
- 연 이자율: B2
- 상환 기간(개월): B3

필요한 수식:
1. 월 상환액 (PMT, 음수 처리 없이 양수로)
2. 총 상환액 (월 상환액 × 기간)
3. 총 이자액 (총 상환액 - 대출금)
4. 원리금 상환표 (A행=회차, B행=월 상환액, C행=이자분, D행=원금분, E행=잔액)
   회차 1~B3까지 수식 패턴 제시

PPMT, IPMT 함수 활용. 오류 처리 포함.
```

## 2.5 날짜/시간 함수 (결산 실무)

재무 결산에서 날짜 처리는 매우 중요합니다. 기간의 시작/끝, 영업일 계산 등이 자주 쓰입니다.

### 핵심 날짜 함수

| 함수 | 용도 | 예시 |
|------|------|------|
| `EOMONTH(날짜, 월수)` | 월 말일 | `=EOMONTH(A1, 0)` → A1이 속한 달의 말일 |
| `EOMONTH(날짜, -1)+1` | 월 첫날 | `=EOMONTH(A1, -1)+1` → A1 달의 1일 |
| `YEARFRAC(시작, 종료, 기준)` | 두 날짜 간 연수 | `=YEARFRAC(A1, B1, 1)` → 실제 일수 기준 |
| `NETWORKDAYS(시작, 종료, [공휴일])` | 영업일 수 | `=NETWORKDAYS(A1, B1)` |
| `WORKDAY(날짜, 일수, [공휴일])` | N 영업일 후 날짜 | `=WORKDAY(A1, 5)` |
| `DATEDIF(시작, 종료, "Y")` | 기간 차이 | `=DATEDIF(입사일, TODAY(), "Y")` → 근속 년수 |

### 결산 일자 계산 패턴

```
# 이번 달 말일
=EOMONTH(TODAY(), 0)

# 다음 달 말일
=EOMONTH(TODAY(), 1)

# 전월 말일 (전기 마감일)
=EOMONTH(TODAY(), -1)

# 이번 분기 마지막 월 말일
=EOMONTH(DATE(YEAR(TODAY()), INT((MONTH(TODAY())-1)/3)*3+3, 1), 0)

# 회계연도 말일 (12월 결산)
=DATE(YEAR(TODAY()), 12, 31)
```

**Copilot 프롬프트**:
```
엑셀 날짜 수식 7개 작성. 기준 날짜 A1.

1. A1이 속한 월의 첫날
2. A1이 속한 월의 마지막 날
3. A1이 속한 분기의 첫날 (Q1=1/1, Q2=4/1 등)
4. A1이 속한 분기의 마지막 날
5. A1부터 당해 연도 말(12/31)까지 남은 영업일 수
6. A1로부터 30 영업일 후 날짜
7. A1이 몇 분기인지 (1, 2, 3, 4 반환)

수식만 작성. 공휴일 범위는 Holidays!A:A 시트로 가정.
```

## 2.6 배열 수식과 동적 배열 (Microsoft 365)

Microsoft 365부터 FILTER, SORT, UNIQUE, SEQUENCE 등의 **동적 배열 함수**를 사용할 수 있습니다. 재무 대시보드를 크게 단순화합니다.

### UNIQUE - 고유값 추출

```
=UNIQUE(B2:B500)
```
→ B열 계정코드의 고유 목록을 자동으로 아래 방향으로 펼침(spill).

### FILTER - 조건 필터링

```
=FILTER(A2:D500, B2:B500="4000", "데이터없음")
```
→ 계정코드가 4000인 행 전체를 추출.

**다중 조건 FILTER**:
```
=FILTER(A2:D500, (B2:B500="4000") * (C2:C500="SALES"))
```
※ AND 조건은 `*`, OR 조건은 `+` 사용.

### SORT + FILTER 조합

```
=SORT(FILTER(A2:D500, B2:B500="4000"), 4, -1)
```
→ 계정코드 4000인 행을 금액(4열) 내림차순 정렬.

### SUMIFS + UNIQUE 동적 집계표

```
# 고유 계정 목록 (G열)
=UNIQUE(B2:B500)

# 각 계정별 합계 (H열, G열 참조)
=SUMIFS(D:D, B:B, G2#)
```
`G2#`은 G2부터 펼쳐진 동적 배열 전체를 참조합니다.

**Copilot 프롬프트**:
```
Excel 365 동적 배열 수식 세트 작성.

데이터: A열=날짜, B열=계정코드, C열=부서코드, D열=금액 (A2:D500)

수식 1: 고유 계정코드 목록 (UNIQUE, G2에서 아래로 펼침)
수식 2: 고유 계정코드별 금액 합계 (SUMIFS + G2# 동적 참조, H2)
수식 3: 금액 상위 10개 행 전체 추출 (FILTER + LARGE + INDEX 조합)
수식 4: C열 부서가 "SALES"인 행만 날짜 오름차순 정렬 추출
수식 5: 월별 집계표 자동 생성
  - J2에 월 목록 (UNIQUE + MONTH 조합)
  - K2에 월별 합계

넘침(spill) 허용. 각 수식 설명 한 줄 포함.
```

## 2.7 오류 처리와 데이터 품질

재무 데이터에서 수식 오류는 **합계 오류로 직결**됩니다. 오류 처리를 습관화하세요.

### 주요 오류 유형과 처리

| 오류 | 원인 | 처리 |
|------|------|------|
| `#N/A` | 룩업 값 미발견 | `=IFERROR(VLOOKUP(...), "미등록")` |
| `#DIV/0!` | 0으로 나눔 | `=IFERROR(A/B, 0)` 또는 `=IF(B=0, 0, A/B)` |
| `#VALUE!` | 텍스트를 숫자로 | `=IFERROR(VALUE(A1), 0)` |
| `#REF!` | 참조 셀 삭제 | 수식 점검 필요 (자동 처리 없음) |
| `#NUM!` | IRR 수렴 실패 | XIRR 시도 또는 추정값 변경 |

### 텍스트로 저장된 숫자 처리

ERP에서 내보낸 데이터가 텍스트 형식인 경우:

```
=VALUE(TRIM(A1))                    # 기본 변환
=IFERROR(VALUE(TRIM(A1)), 0)       # 오류 시 0
=A1*1                               # 빠른 변환 (1을 곱함)
=--A1                               # 이중 부정 연산자
```

### 합계 검증 수식 (대차 일치 체크)

```
# 차변 합계 = 대변 합계 검증
=IF(SUMIFS(C:C, A:A, "차변")=SUMIFS(C:C, A:A, "대변"), "OK", "불일치")

# 차이금액
=SUMIFS(C:C, A:A, "차변")-SUMIFS(C:C, A:A, "대변")
```

**Copilot 프롬프트**:
```
엑셀 데이터 품질 검증 수식 세트 작성.

대상 데이터: 시산표 (A열=계정코드, B열=계정명, C열=차변잔액, D열=대변잔액)
2행부터 100행까지 데이터.

검증 수식:
1. 차변 합계 (C열 합계)
2. 대변 합계 (D열 합계)
3. 차변-대변 차액 (0이면 대차 일치)
4. 차이가 0이 아닐 때 "불일치" 경고 표시 (IF 조건부)
5. 자산계정(코드 1xxx)인데 대변잔액이 있는 건수 (비정상)
6. 부채계정(코드 2xxx)인데 차변잔액이 있는 건수 (비정상)

수식만. 셀 위치 명시.
```

## 2.9 Copilot 수식 생성의 실수 패턴과 검증법

Copilot이 수식을 만들 때 재무 담당자가 특히 주의해야 할 실수 패턴을 정리합니다.
미리 알면 검증 시간이 절반으로 줄어듭니다.

### 실수 패턴 1. 반올림 정책 미통일

Copilot이 어떤 수식에는 `ROUND`를, 어떤 수식에는 `ROUNDDOWN`을 혼용합니다.
원화 금액은 원 단위 처리 정책을 사내에서 통일해야 합니다.

```
일반적 정책:
- 부가세: 원 단위 절사 (ROUNDDOWN)
- 이자 계산: 원 단위 사사오입 (ROUND)
- 외화 환산: 소수점 없음 (ROUND(..., 0))

Copilot 프롬프트에 명시:
"금액은 원 단위 절사(ROUNDDOWN(..., 0)) 처리. ROUND 사용 금지."
```

검증 방법:
```
Ctrl+H (찾기/바꾸기)로 수식 파일 전체에서
"ROUND(" 를 검색하여 ROUNDDOWN이 아닌 ROUND 수식 목록화 후 정책 대조
```

### 실수 패턴 2. SUMIFS 범위 크기 불일치

SUMIFS에서 합계 범위와 조건 범위의 크기가 다르면 `#VALUE!` 오류가 발생합니다.
Copilot이 간혹 범위를 다르게 잡습니다.

```
잘못된 예 (Copilot 생성 결과):
=SUMIFS(D2:D100, A2:A500, "2026-01", B2:B100, "4000")
         ↑100행           ↑500행
         
올바른 예:
=SUMIFS(D2:D500, A2:A500, "2026-01", B2:B500, "4000")
```

검증: 수식 작성 후 셀 참조 범위를 눈으로 확인, 또는 `Ctrl+[`로 참조 셀 추적.

### 실수 패턴 3. 절대참조/상대참조 혼용

수식을 아래로 복사할 때 조건 범위가 같이 내려가버리는 경우입니다.

```
잘못된 예:
=SUMIFS(D2:D500, B2:B500, E2)
                           ↑ 상대참조: 수식 복사 시 E3, E4...로 이동

올바른 예 (기준 셀은 절대참조):
=SUMIFS($D$2:$D$500, $B$2:$B$500, E2)
```

Copilot 프롬프트에 명시:
```
"합계 범위와 조건 범위는 절대참조($), 조건값 참조만 상대참조로 작성."
```

### 실수 패턴 4. 날짜 비교 방식 오류

날짜를 텍스트로 비교하면 연도가 달라질 때 오류가 발생합니다.

```
잘못된 예 (Copilot이 종종 생성):
=SUMIFS(D:D, A:A, ">=2026-01-01", A:A, "<=2026-06-30")
// 텍스트 비교: 날짜 형식에 따라 작동 안 할 수 있음

올바른 예:
=SUMIFS(D:D, A:A, ">="&DATE(2026,1,1), A:A, "<="&EOMONTH(DATE(2026,6,1),0))
// DATE 함수로 날짜 생성 후 비교
```

### 실수 패턴 5. VLOOKUP FALSE 누락

VLOOKUP의 네 번째 인수를 빠뜨리면 근사 일치(TRUE)가 기본값으로 적용됩니다.
정렬된 데이터가 아닐 경우 틀린 값을 반환합니다.

```
잘못된 예:
=VLOOKUP(A2, 계정마스터!A:B, 2)
// FALSE 없음: 정렬 여부에 따라 오작동 가능

올바른 예:
=VLOOKUP(A2, 계정마스터!A:B, 2, FALSE)
// 정확 일치 보장

더 좋은 예 (XLOOKUP):
=XLOOKUP(A2, 계정마스터!A:A, 계정마스터!B:B, "미등록")
```

## 2.10 재무비율 수식 체계

재무제표 분석에서 반드시 알아야 할 재무비율을 Excel 수식으로 구현합니다.

### 수익성 지표

```
손익계산서 기준 (셀 위치 예시):
B2 = 매출액
B3 = 매출원가
B4 = 판관비
B5 = 영업이익 (= B2 - B3 - B4)
B6 = 당기순이익

매출총이익률: =(B2-B3)/B2*100
영업이익률:   =B5/B2*100
순이익률:     =B6/B2*100
```

수식에 0 나누기 보호 추가:
```
=IFERROR((B2-B3)/B2*100, 0)
```

### 안정성 지표

```
재무상태표 기준:
B10 = 유동자산
B11 = 유동부채
B12 = 총자산
B13 = 총부채
B14 = 자기자본

유동비율:     =B10/B11*100
부채비율:     =B13/B14*100
자기자본비율: =B14/B12*100
```

### Copilot 프롬프트 (재무비율 전체 세트)

```
엑셀 재무비율 수식 세트 작성. 오류 처리 포함.

입력 셀:
B2=매출, B3=매출원가, B4=판관비, B5=영업이익, B6=당기순이익
B10=유동자산, B11=유동부채, B12=총자산, B13=총부채, B14=자기자본

출력 (C열에 레이블, D열에 수식):
수익성: 매출총이익률, 영업이익률, 순이익률, 매출원가율, 판관비율
안정성: 유동비율, 부채비율, 자기자본비율
활동성: 총자산회전율 (매출/총자산)

모든 수식에 IFERROR 포함. % 표시는 셀 서식으로 처리
(수식에서 *100 제거, 셀 서식 = "0.00%").
```

## 핵심 포인트

1. **수식 프롬프트 5요소**: 데이터 위치 + 목표 + 함수 + 결과 셀 + 예외 처리
2. **XLOOKUP이 VLOOKUP보다 안전**: not_found 인수 내장, 방향 제약 없음
3. **NPV 함정**: 초기 투자를 범위 밖에서 더해야 정확
4. **동적 배열(FILTER/UNIQUE)**: Microsoft 365에서 대시보드 작업 시간 절반
5. **합계 검증 수식은 선택이 아닌 필수**: 차변=대변 일치 체크를 항상 포함
6. **반올림 정책 통일**: 사내 기준(원 단위 절사/사사오입) 결정 후 모든 수식에 일관 적용
7. **절대참조 습관**: 조건 범위는 `$A$2:$A$500`처럼 절대참조, 복사해도 흔들리지 않도록
