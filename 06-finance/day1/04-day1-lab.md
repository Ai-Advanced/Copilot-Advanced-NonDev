# 04. Day 1 종합 실습: 월 마감 자동화 준비

## 실습 목표

Day 1에서 배운 엑셀 수식과 VBA 매크로를 결합해서
**실무에 바로 쓸 수 있는 "월 마감 준비 파일"** 을 완성합니다.

수식으로 계산하고, VBA로 자동화하고, 검증까지 내장합니다.
이 실습이 끝나면 매달 마감 준비 시간이 절반 이하로 줄어듭니다.

**예상 소요**: 60분 (개인 속도에 따라 45~90분)

---

## 실습 시나리오

> 재무팀 김담당은 매달 말 다음 작업을 반복합니다:
> 1. 각 부서에서 경비 정산 파일을 받아 통합 원장에 집계
> 2. 계정과목별 실적을 예산과 비교해 편차 계산
> 3. 이상 항목 플래그 처리
> 4. 부서장 배포용 PDF 리포트 저장
>
> 이 4단계를 수식 + VBA로 반자동화합니다.

## 사전 준비

### 실습용 파일 구조 생성

먼저 Copilot에게 샘플 데이터를 만들어달라고 요청합니다.

**프롬프트 1. 샘플 원장 데이터**

```
엑셀에 바로 붙여넣기 가능한 탭 구분 CSV 데이터 생성.

시트: "원장"
헤더: 전표일자  계정코드  계정명  부서코드  차변  대변  적요
데이터 특성:
- 2026년 6월 데이터, 80행
- 계정코드/명: 4000/매출, 5110/급여, 5120/임차료, 5130/광고선전비, 5200/매출원가
- 부서코드: SALES, MFG, HR, ADM
- 금액: 500,000 ~ 30,000,000 (원 단위 정수)
- 매출(4000)은 대변, 비용(5xxx)은 차변에 입력

80행 출력. 헤더 포함.
```

**프롬프트 2. 샘플 예산 데이터**

```
엑셀에 바로 붙여넣기 가능한 탭 구분 데이터 생성.

시트: "예산"
헤더: 계정코드  계정명  부서코드  예산금액(연간)  예산금액(월)
데이터: 위 5개 계정 × 4개 부서 = 20행
예산금액(월) = 연간/12 (정수 처리)
```

### 파일 초기 설정

1. 새 Excel 파일 생성: `마감준비_2026-06.xlsx`
2. 시트 만들기: **원장, 예산, 집계, 검증, 리포트**
3. 각 시트에 샘플 데이터 붙여넣기

## Step 1. 집계 시트 수식 세트 (20분)

"집계" 시트에 아래 수식들을 작성합니다.
각 수식 전에 Copilot에게 요청하고, 결과를 붙여넣어 확인합니다.

### 1-1. 계정과목 고유 목록 자동 생성

**Copilot 프롬프트**:
```
Excel 365 수식 작성.

원장 시트 B열(계정코드)의 고유값 목록을 집계 시트 A3부터 아래로 자동 나열.
수식은 집계 시트 A3 셀에 입력.
UNIQUE 함수 사용. 정렬은 오름차순.
```

기대 결과:
```
집계!A3: =SORT(UNIQUE(원장!B:B))
```

### 1-2. 계정별 차변/대변 합계

**Copilot 프롬프트**:
```
엑셀 수식 작성.

원장 시트: B열=계정코드, E열=차변, F열=대변
집계 시트 A3부터 계정코드가 내려옴 (A3#이 동적 배열)

집계 시트 B3에: A3# 각 계정코드별 차변 합계 (SUMIFS + 동적 참조)
집계 시트 C3에: A3# 각 계정코드별 대변 합계
집계 시트 D3에: 잔액 (수익계정 4xxx는 대변-차변, 비용계정 5xxx는 차변-대변)
  - IF(LEFT(A3,1)="4", C3-B3, B3-C3) 패턴으로

B3, C3, D3 수식 모두 아래로 자동 확장 고려 (동적 배열 또는 ARRAYFORMULA).
```

### 1-3. 예산 대비 실적 편차

**Copilot 프롬프트**:
```
엑셀 수식 작성.

집계 시트:
- A열: 계정코드 (동적 배열 A3#)
- D열: 실적 잔액

예산 시트: A열=계정코드, D열=예산금액(월)

집계 시트 E3에: 해당 계정의 월 예산 (XLOOKUP으로 예산 시트에서 가져오기, 없으면 0)
집계 시트 F3에: 편차 (실적 - 예산)
집계 시트 G3에: 달성률 (%) - 예산이 0이면 "N/A", 아니면 실적/예산×100 소수점 1자리
```

### 1-4. 부서별 매출 집계

**Copilot 프롬프트**:
```
엑셀 수식 작성.

원장 시트: B열=계정코드, C열=계정명, D열=부서코드, F열=대변
집계 시트 I1에: 부서 목록 헤더 "부서코드"
집계 시트 I2부터: 고유 부서코드 목록 (UNIQUE)
집계 시트 J1: "매출"
집계 시트 J2부터: 각 부서의 계정코드 4000 대변 합계 (SUMIFS, I2# 동적 참조)
```

### 검증 체크 (Step 1 완료 후)

- [ ] 계정코드 목록이 올바르게 나타나는지 (5개 코드)
- [ ] 차변+대변 합계가 원장 시트 E열, F열 합계와 일치하는지
- [ ] 예산 가져오기에서 #N/A 없는지

## Step 2. 검증 시트 수식 세트 (15분)

"검증" 시트는 자동화 결과의 신뢰성을 담보합니다.
이 시트가 모두 PASS면 집계가 정확한 것입니다.

**Copilot 프롬프트**:
```
엑셀 검증 시트 수식 세트 작성.

검증 항목 (A열: 항목명, B열: 검증 수식, C열: 상태):

1. 원장 대차 일치
   원장 E열(차변) 합계 = F열(대변) 합계
   상태: 일치면 "✓ PASS", 불일치면 "✗ FAIL - 차이: " & 금액

2. 집계 잔액 합산 확인
   집계!D열 합계(비용) - 집계!D열 합계(수익) = 원장 차변 - 대변 합계
   상태: 동일하면 PASS, 다르면 FAIL + 차이 금액

3. 예산 미매핑 계정
   집계!E열이 0인 계정 건수 (예산 없는 계정)
   상태: 0이면 PASS, 있으면 "확인 필요: N건"

4. 음수 잔액 계정
   집계!D열 < 0 인 계정 건수
   상태: 0이면 PASS, 있으면 "이상 N건"

5. 전표 건수 확인
   원장 시트 데이터 행 수
   (수동 확인용, 숫자만 표시)

각 수식을 B열에 작성. 상태는 C열 IF/IFERROR 수식으로.
```

### 최종 검증 요약

**프롬프트**:
```
검증 시트에 종합 요약 수식 추가.

C8에: 위 5개 항목 중 "FAIL" 포함된 건수 (COUNTIF)
C9에: C8이 0이면 "✓ 전체 검증 통과. 리포트 생성 진행." 아니면 "✗ N건 오류. 수정 후 재실행."
```

## Step 3. VBA 매크로 2개 작성 (20분)

### 매크로 1. 리포트 시트 자동 갱신

**Copilot 프롬프트**:
```
Excel VBA 매크로 작성.

Sub RefreshMonthlyReport()

목적: 월 마감 집계 자동 갱신 절차

동작:
1. 검증 시트 C9의 값 확인 (FAIL이 포함되면 경고 메시지 + 종료)
2. 집계 시트를 기반으로 리포트 시트 갱신:
   a. 리포트!A1 = "2026년 6월 재무 실적 요약"
   b. 리포트!A3부터: 집계 시트의 계정코드, 계정명, 실적, 예산, 편차, 달성률 복사 (값만 붙여넣기)
   c. 리포트!B2 = 작성일시 (Now())
3. 리포트 시트에 자동 합계 행 추가 (마지막 행 + 1에 SUM 수식)
4. 완료 메시지

오류 처리: On Error GoTo 포함.
주석 포함.
```

### 매크로 2. PDF 저장 + 파일명 자동화

**Copilot 프롬프트**:
```
Excel VBA 매크로 작성.

Sub SaveMonthlyPDF()

목적: 리포트 시트를 PDF로 저장

동작:
1. 저장 경로: C:\MonthlyClose\ (없으면 자동 생성)
2. 파일명: YYYYMMDD_월간재무리포트_2026-06.pdf
3. 리포트 시트만 PDF 변환 (xlTypePDF)
4. 인쇄 영역 설정 (A1:G마지막행)
5. 저장 완료 후 Windows 탐색기로 해당 폴더 열기
6. 저장된 파일 경로를 검증 시트 D1에 기록

오류 처리 포함. 주석 포함.
```

### VBA 통합 실행 버튼

리포트 시트에 버튼을 추가해서 두 매크로를 순서대로 실행합니다:

**프롬프트**:
```
Excel VBA 매크로 작성.

Sub RunMonthlyClose()
' 월 마감 통합 실행: 갱신 → PDF 저장 순서로 호출
' 각 단계 시작 전 로그 기록 (검증!A15부터 아래 방향)
' 오류 발생 시 해당 단계 기록 후 종료

Call RefreshMonthlyReport
If Err.Number = 0 Then
    Call SaveMonthlyPDF
End If
```

## 문제 해결 가이드

### 수식이 #REF! 오류를 보여요

원장 시트 이름이 정확한지 확인하세요. 대소문자, 공백 주의.
수식 내 `원장!B:B` 부분에서 `원장`이 실제 시트 이름과 다르면 발생합니다.

### UNIQUE 함수가 없다고 해요

Microsoft 365가 아닌 경우 UNIQUE를 사용할 수 없습니다.
이 경우 Copilot에게 이렇게 요청하세요:
```
UNIQUE 대신 Excel 2019 호환 방법으로 고유값 목록 만드는 수식 또는 VBA 작성.
```

### VBA 매크로가 신뢰할 수 없다고 해요

파일 > 옵션 > 보안 센터 > 매크로 설정 > "알림을 표시하고 서명되지 않은 매크로 비활성화" 선택.
또는 파일을 열 때 나타나는 노란 보안 경고 바에서 "콘텐츠 사용" 클릭.

### PDF 저장 폴더 경로 오류

경로에 한글이 들어가면 일부 환경에서 오류가 납니다.
`C:\Reports\` 처럼 영문 경로로 변경하세요.

## 심화 도전 (여유 있는 경우)

Day 1 실습을 먼저 완료한 분은 아래 추가 과제에 도전하세요.

### 도전 1. 전월 비교 수식 추가

집계 시트에 전월 실적(별도 시트 "원장_5월" 참고)과 비교하는 열을 추가합니다.

```
Copilot 프롬프트:
집계 시트 H열에 전월(5월) 동일 계정의 잔액,
I열에 전월 대비 증감액 (당월 - 전월),
J열에 증감률 (%) 수식 추가.
전월 데이터는 "원장_5월" 시트, 동일 구조.
증감률 분모 0 처리 포함.
```

### 도전 2. 조건부 서식 연동

검증 시트의 결과에 따라 집계 시트 셀 색상이 바뀌는 조건부 서식을 VBA로 구현합니다.

```
Copilot 프롬프트:
검증 시트 C열(상태)이 "FAIL"을 포함하면
해당 행의 집계 시트 대응 셀을 빨간 배경으로 강조하는 VBA 매크로 작성.
```

### 도전 3. 대시보드 시트 자동 생성

수식과 차트를 포함한 1페이지 경영진용 대시보드 시트를 생성합니다.

```
Copilot 프롬프트:
"대시보드" 시트를 VBA로 자동 생성.
포함 항목:
- 매출/영업이익/달성률 KPI 3개 (대형 셀 강조)
- 계정별 예산 vs 실적 가로 막대형 차트
- 이상 항목 수 표시 (검증 시트에서 참조)
집계 시트와 검증 시트 데이터를 참조.
```
