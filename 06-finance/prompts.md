## 1. 엑셀 수식 프롬프트

### P-01. 다중 조건 합계 (SUMIFS)

```
엑셀 SUMIFS 수식 작성.

데이터 범위:
- A열: 날짜 (날짜 형식)
- B열: 계정과목 (텍스트)
- C열: 부문 (텍스트)
- D열: 금액 (원 단위 숫자)

조건: [2026년 1월], 계정과목 [매출], 부문 [영업1팀]에 해당하는 금액 합계.
결과 셀: F2
수식만 작성. 설명 불필요.
```

### P-02. 계층형 룩업 (XLOOKUP + IFERROR)

```
엑셀 수식 작성.

시트1 A열에 거래처코드, B열에 거래처명이 있음.
시트2 D3 셀에 거래처코드를 입력하면 시트1에서 거래처명을 가져오는 수식.
거래처코드가 없으면 "미등록" 표시.
함수: XLOOKUP 사용 (IFERROR 대신 XLOOKUP의 not_found 인수 활용).
```

### P-03. 기간별 잔액 계산 (SUMIFS 누적)

```
엑셀 수식 작성.

컨텍스트:
- A열: 전표일자
- B열: 계정과목코드
- C열: 차변금액
- D열: 대변금액

목표: B열이 [계정코드 101], 전표일자가 [2026-01-01]부터 [2026-01-31]까지인
      차변 합계에서 대변 합계를 뺀 기말 잔액 수식.
      기초잔액(E1)을 더해서 최종 잔액 산출.
      셀 참조는 절대참조($) 적절히 사용.
```

### P-04. 재무 함수 3종 (NPV/IRR/PMT)

```
엑셀 재무함수 3개 작성.

시나리오: 설비 투자 분석
- 초기 투자: 500,000,000원 (B2)
- 연간 현금흐름: C2:C6 (5년)
- 할인율: B1 (연 8%)
- 대출금: 200,000,000원, 연 5%, 60개월 상환

수식 1: NPV 계산 (초기 투자 반영)
수식 2: IRR 계산
수식 3: 월 상환액 PMT (원리금균등상환)

각 수식마다 "=수식" 형태로 작성, 사용 셀 명시.
```

### P-05. 날짜 함수 (결산 마감일 계산)

```
엑셀 날짜 수식 3개 작성.

1. A1에 연도(2026), A2에 월(3)이 있을 때, 해당 월의 마지막 날 (EOMONTH 사용)
2. 2026-01-01부터 2026-12-31까지 몇 년인지 (YEARFRAC 사용, 기준 1)
3. 오늘부터 다음 달 말까지 남은 영업일 수 (NETWORKDAYS 사용, 공휴일 없이)

수식만, 셀 참조 포함.
```

### P-06. 동적 배열 수식 (Microsoft 365)

```
Excel 365 동적 배열 수식 작성.

데이터: A1:E100 (헤더: 날짜/계정과목/부문/금액/비고)

목표:
1. 계정과목 고유값 목록 (UNIQUE 사용)
2. 금액 상위 10개 행 전체 추출 (FILTER + LARGE 조합)
3. 부문별 금액 합계 표 (SUMIFS 배열 처리, 부문 목록 자동 생성)

각 수식은 넘침(spill) 허용. 수식 설명 포함.
```

### P-07. 오류 처리 수식

```
엑셀 수식에서 오류 처리 패턴 작성.

상황:
- VLOOKUP 결과가 #N/A이면 "미등록" 표시
- 나눗셈 수식에서 분모가 0이면 0 표시 (IFERROR + IF 조합)
- 텍스트 형식으로 저장된 숫자를 VALUE()로 변환 + 변환 실패 시 0

3개 수식 모두 실제 수식 형태로 작성.
```

### P-08. 조건부 서식 수식

```
엑셀 조건부 서식에 사용할 수식 작성.

상황: 예산 대비 실적 편차율 열(F열)에 조건부 서식 적용
- 편차율 > 10%: 빨간 배경 (초과)
- 편차율 -10% ~ 10%: 배경 없음
- 편차율 < -10%: 노란 배경 (미달)

조건부 서식 "새 규칙 > 수식으로 결정" 입력용 수식 3개.
F2 셀부터 적용 기준으로 작성.
```

### P-09. INDEX-MATCH 이중 조건

```
엑셀 INDEX-MATCH 수식 작성.

테이블: A열=연도, B열=분기, C열=부문, D열=매출액
범위 A2:D200

조건: 연도=[2026], 분기=[Q2], 부문=[제조]에 해당하는 매출액 추출.
조건이 여러 개이므로 배열 수식(Ctrl+Shift+Enter) 또는 MATCH 중첩 방식으로 작성.
두 가지 방법 모두 제시.
```

### P-10. 재무비율 수식 세트

```
재무비율 계산 엑셀 수식 10개 작성.

셀 위치:
- 매출액: B2
- 매출원가: B3
- 판관비: B4
- 영업이익: B5 (= B2 - B3 - B4)
- 당기순이익: B6
- 유동자산: B10
- 유동부채: B11
- 총자산: B12
- 총부채: B13
- 자기자본: B14

계산할 비율:
1. 매출총이익률 (%)
2. 영업이익률 (%)
3. 순이익률 (%)
4. 유동비율 (%)
5. 부채비율 (%)
6. 자기자본비율 (%)
7. ROE (%)
8. ROA (%)
9. 매출원가율 (%)
10. 판관비율 (%)

각 수식을 C열에 입력하는 형태로 작성. 0으로 나누기 오류 처리 포함.
```

```
분석 대상: 영업이익 (핵심 드라이버 2개 변화에 따른 영향)
드라이버 1: 매출 성장률 (행 방향: -10%, -5%, 0%, +5%, +10%)
드라이버 2: 원가율 (열 방향: 60%, 65%, 70%, 75%, 80%)

구현:
1. 데이터 테이블 (What-If 분석 > 데이터 표) 설정 방법 설명
2. 수식 구조 (베이스 셀 → 테이블 수식 연결)
3. 조건부 서식으로 영업이익 구간별 색상 구분
   (0 이하: 빨강, 0~10%: 노랑, 10% 이상: 초록)

단계별 설명 + 수식.
```

### P-46. 현금 흐름 예측 모델

```
엑셀 13주 현금 흐름 예측 모델 수식 설계.

구조 (열: 1주~13주 / 행: 현금 항목):
입금:
- 매출 수금 (외상 30일 결제 가정: 이번 주 청구 × 수금률)
- 기타 입금

출금:
- 매입 결제 (외상 30일: 4주 전 매입 × 결제율)
- 급여 (월 2회: 10일, 25일)
- 임차료 (월 1회)
- 기타 출금

잔액:
- 기초 현금 + 입금 합계 - 출금 합계 = 기말 현금

수식 패턴 (OFFSET 또는 INDEX로 n주 전 데이터 참조).
최소 현금 경보선 설정 (조건부 서식).
```
