# 일반 오피스 워커 Copilot 핵심 치트시트

> 프린트해서 모니터 옆에 붙여두세요. A4 1장 분량입니다.

---

## Copilot 3가지 사용 방법

| 방법 | 여는 법 | 언제 쓰나 |
|------|---------|-----------|
| **Chat 사이드바** | `Ctrl+Alt+I` | 초안 생성, 요약, 번역, 질문 |
| **Inline Chat** | `Ctrl+I` (파일 안에서) | 선택한 내용 수정·개선 |
| **Tab 자동완성** | 자동 (Tab으로 수락) | 다음 줄 예측 |

## 5가지 핵심 프롬프트 패턴

### 1. 초안 생성
```
[문서 종류] 작성. 목적: [왜]. 독자: [누가]. 톤: [어떻게]. 길이: [얼마나].
```

### 2. 요약
```
아래 [문서/이메일/회의록]을 [형식]으로 요약. 길이: [줄 수]. 강조: [핵심 키워드].
[원문 붙여넣기]
```

### 3. 톤 조정
```
위 내용을 더 [정중/친근/단호/간결]하게 다시 써줘. 내용은 그대로.
```

### 4. 수식/스크립트 생성
```
엑셀 수식: [조건]에 맞는 [계산 목적]. 데이터 위치: [범위]. 함수: [사용할 함수].
PowerShell: [목적]. 입력: [경로]. 동작: [1.2.3]. 출력: [결과].
```

### 5. 번역
```
아래 한국어를 비즈니스 영어로 번역. 톤: [정중/격식]. [원문]
```

## 업무별 핵심 프롬프트 모음

### 이메일
```
[요청/사과/거절/감사/공지] 이메일 작성.
수신: [이름/직책] / 목적: [내용] / 톤: [정중/친근/단호] / 길이: [N문장]
```

### 회의록
```
아래 회의 노트를 정식 회의록으로 정리. 결정사항·액션아이템·담당자·마감일 표로.
```

### PPT 목차
```
[주제] PPT 목차 작성. 발표 시간: [N분]. 청중: [누구]. 총 [N]장. 각 슬라이드 핵심내용 2줄.
```

### 파일 자동화
```
PowerShell: [폴더 경로] 파일들을 [분류 기준]으로 [이동/이름변경/정리].
```

### 엑셀 수식
```
엑셀 수식: [범위]에서 [조건1]이고 [조건2]인 행의 [열] 합계. SUMIFS 사용.
```

## 자주 쓰는 후속 프롬프트

| 상황 | 프롬프트 |
|------|----------|
| 너무 길다 | `절반으로 줄여줘, 핵심만` |
| 너무 딱딱하다 | `좀 더 자연스럽고 친근하게` |
| 더 격식 있게 | `임원 보고용으로 더 격식 있게` |
| 형식 바꾸기 | `표 대신 불릿으로 / 불릿 대신 문단으로` |
| 항목 추가 | `[내용] 항목도 추가해줘` |
| 특정 부분 수정 | `[특정 문장]만 [방향]으로 바꿔줘` |

## 좋은 프롬프트 5가지 질문

- [ ] **누구에게?** (수신자/독자 명시)
- [ ] **무엇을?** (목적 구체적으로)
- [ ] **어떤 형식?** (표/불릿/이메일/보고서)
- [ ] **얼마나?** (줄 수/단어 수)
- [ ] **어떤 톤?** (정중/친근/단호/간결)

## 절대 하지 말 것

| 나쁜 습관 | 이유 |
|----------|------|
| `알아서 잘 써줘` | AI의 "알아서"는 평균적이고 뻔합니다 |
| Copilot 결과 무검토 발송 | AI는 틀릴 수 있습니다. 항상 1회 검토 |
| 민감 정보 입력 (주민번호, 계좌번호, 비밀번호) | Copilot에는 기밀 개인정보 넣지 않기 |
| 존댓말 남용 프롬프트 | 길어지고 모호해집니다. 명령형이 정확 |

## 오피스 업무 Copilot 활용 지도

```
아침 루틴            → 오늘 할 일 정리, 어제 업무 보고 초안
이메일               → 초안 생성 → 톤 조정 → 요약
회의 전              → 안건 작성, 초대 이메일
회의 후              → 회의록 정리, 액션아이템 추출, 공유 메시지
보고서 작성          → 목차 생성 → 섹션별 초안 → 문단 변환
PPT                  → 목차 → 슬라이드 초안 → 발표자 노트
파일 정리            → PowerShell 스크립트 생성 → 실행
엑셀 수식            → 목적 설명 → 수식 받기 → 붙여넣기
번역                 → 한→영 / 영→한 비즈니스 번역
```
