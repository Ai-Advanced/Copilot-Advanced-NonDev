# 01. 일반 오피스 하루 재분석 — Copilot이 바꾸는 20가지 반복 업무

## 학습 목표

- 사무직 하루 업무에서 반복 작업 20개를 찾아 Copilot 절감 가능 업무 15개로 매핑
- Before / After 비교 3가지로 실질적인 시간 절약 감각 익히기
- "내 업무 중 어디에 Copilot을 먼저 써볼까" 결정하기

**예상 소요**: 40분 (실습 포함)

---

## 1.1 오피스 워커의 하루 — 시간을 어디에 쓰나?

아침 9시부터 저녁 6시까지, 총무·경영지원·임원 비서·코디네이터가 실제로 쓰는 시간을 분석해봤습니다.

| 업무 유형 | 하루 평균 소요 | 반복성 |
|-----------|--------------|--------|
| 이메일 읽기 + 회신 작성 | 2~3시간 | 매일 |
| 회의 참석 + 회의록 정리 | 1~2시간 | 거의 매일 |
| 보고서/문서 작성 | 1~2시간 | 주 3~4회 |
| 일정 조율 + 확인 연락 | 30~60분 | 매일 |
| 파일 정리 + 이름 변경 | 20~40분 | 매일 |
| 엑셀 집계/데이터 정리 | 30~90분 | 주 3~5회 |
| PPT 자료 준비 | 1~3시간 | 주 1~2회 |
| 번역 + 영문 대응 | 20~60분 | 주 2~3회 |

**합산하면 하루 7~8시간 중 약 5~6시간이 반복적이거나 패턴이 있는 작업입니다.**

Copilot은 이 중 "초안 생성"이 필요한 모든 영역에서 시간을 절약해줄 수 있습니다.

---

## 1.2 반복 업무 20개 리스트업

아래 20가지는 실제 오피스 워커들에게서 수집한 반복 업무 목록입니다. 어느 것이 여러분에게도 해당하는지 체크해보세요.

### 이메일/커뮤니케이션
- [ ] 1. 매일 비슷한 내용의 요청 이메일을 조금씩 바꿔서 여러 명에게 보낸다
- [ ] 2. 영어 이메일을 받으면 번역하고 다시 영어로 회신을 쓴다
- [ ] 3. 행사/회의 초대 이메일을 참석자별로 보낸다
- [ ] 4. 공지사항을 여러 채널(이메일/슬랙/팀즈)에 포맷을 맞춰 올린다
- [ ] 5. 감사/축하/조의 이메일을 상황에 맞게 작성한다

### 회의 관련
- [ ] 6. 회의 전날 안건과 자료를 정리해서 공유한다
- [ ] 7. 회의가 끝나면 노트를 다듬어 공식 회의록으로 만든다
- [ ] 8. 회의록에서 각 담당자의 액션 아이템을 추려 별도로 정리한다
- [ ] 9. 회의 결과를 요약해서 슬랙/팀즈에 공유한다

### 보고/문서
- [ ] 10. 주간/월간 업무 보고서를 정해진 형식으로 만든다
- [ ] 11. 임원 보고용으로 긴 문서를 1~2페이지로 요약한다
- [ ] 12. 신입직원 온보딩, 업무 매뉴얼, 절차서를 작성·업데이트한다
- [ ] 13. 행사나 프로젝트의 기획안·결과 보고서를 작성한다

### 일정·조율
- [ ] 14. 여러 참석자의 가능 시간을 조율해서 회의 일정을 잡는다
- [ ] 15. 일정 변경이 생기면 관련자 전원에게 업데이트를 보낸다

### 파일·데이터
- [ ] 16. 날짜나 규칙에 맞게 파일 이름을 하나씩 바꾼다
- [ ] 17. 다운로드 폴더나 공유 드라이브의 파일들을 주기적으로 정리한다
- [ ] 18. 엑셀에서 부서별/항목별 합계나 개수를 수식으로 뽑는다
- [ ] 19. 데이터를 보고서용 문장으로 다듬는다

### PPT·발표
- [ ] 20. 발표 자료의 목차를 짜고 슬라이드별로 내용을 채운다

## 1.3 Copilot 절감 가능 15개 매핑

아래 15가지 업무는 **Copilot으로 초안 생성 시간을 70~90% 줄일 수 있습니다**.

| # | 업무 | Copilot 활용법 | 절감 시간 (추정) |
|---|------|----------------|-----------------|
| 1 | 요청·공지 이메일 작성 | 프롬프트로 초안 → 수정 | 10→2분 |
| 2 | 영문 이메일 번역·작성 | 번역 + 영문 초안 생성 | 15→3분 |
| 3 | 회의 초대 이메일 | 조건 입력 → 초안 생성 | 5→1분 |
| 4 | 감사·축하·조의 이메일 | 상황 설명 → 초안 생성 | 10→2분 |
| 5 | 회의 안건 문서 | 항목 나열 → 형식 정리 | 15→3분 |
| 6 | 회의록 정리 | 노트 붙여넣기 → 정리본 | 30→5분 |
| 7 | 액션아이템 추출 | 회의록 → 담당자별 표 | 10→2분 |
| 8 | 회의 결과 슬랙 메시지 | 회의록 → 요약 메시지 | 5→1분 |
| 9 | 주간/월간 보고서 | 구조 생성 → 내용 채우기 | 45→10분 |
| 10 | 임원 보고용 요약 | 문서 붙여넣기 → 요약 | 20→3분 |
| 11 | 파일 일괄 이름 변경 | 스크립트 생성 → 실행 | 30→2분 |
| 12 | 다운로드 폴더 정리 | 분류 스크립트 생성 → 실행 | 20→2분 |
| 13 | 엑셀 수식 작성 | 조건 설명 → 수식 받기 | 15→2분 |
| 14 | PPT 목차 + 초안 | 주제·청중 → 목차+내용 | 60→10분 |
| 15 | 업무 매뉴얼 작성 | 업무 설명 → 단계별 정리 | 40→8분 |

**합산**: 위 15가지만 매일 써도 하루 3~4시간을 더 가치 있는 일에 쓸 수 있습니다.

## 1.4 Before / After — 실제 체감 비교 3가지

### Case 1. 회의록 정리

**Before — Copilot 없이**

회의가 끝난다. 손으로 적은 노트를 펼친다. 회사 양식을 열고 일시·참석자부터 입력한다. 각 안건을 기억에 의존해 다시 정리한다. 액션 아이템을 찾아 담당자 이름과 마감일을 연결한다. 메일로 보낼 형식에 맞게 또 다듬는다.

**걸린 시간: 30~40분**

---

**After — Copilot과 함께**

회의 중 러프하게 적은 노트를 VS Code에 붙여넣는다. Chat에 다음 프롬프트 입력:

```
아래 회의 노트를 정식 회의록으로 정리해줘.

포함 항목:
- 회의 개요 (일시/장소/참석자)
- 안건별 논의 내용 (각 2~3줄)
- 결정 사항 (굵게 표시)
- 액션 아이템 (담당자 / 마감일) — 표 형태로
- 다음 회의 예정

[--- 회의 노트 ---]
오늘 14시 회의실 A. 참석: 김부장, 이팀장, 박대리
안건1 - 신입직원 웰컴키트 준비: 이팀장이 업체 리스트 보내주기로, 예산은 1인당 5만원, 박대리가 다음주 금요일까지 취합
안건2 - 사옥 이전 안내문: 김부장이 초안 작성, 7월 말 발송, 전직원 대상
안건3 - 하반기 워크샵 일정: 9월 중 경기도 연수원 검토, 이팀장이 견적 알아보기
[--- 끝 ---]
```

→ 30초 안에 완성된 회의록 초안이 나온다. 수정은 5~10분.

**걸린 시간: 10~15분 (2/3 절감)**

---

### Case 2. 이메일 작성

**Before — Copilot 없이**

협력사에 자료 제출을 요청하는 이메일. 어떻게 시작할지 고민하다 5분. 정중한지 너무 딱딱하지 않은지 고민하며 3번 다시 쓴다. 마감일을 부드럽게 넣는 표현에서 또 막힌다.

**걸린 시간: 15~20분**

---

**After — Copilot과 함께**

```
협력사에 자료 제출을 요청하는 이메일 초안 작성.

수신: ABC 물산 김민준 과장님
목적: 2026년 하반기 공급 계획서 제출 요청
마감: 7월 31일 (목)
톤: 정중하고 협조적으로, 부담 주지 않게
길이: 5~7문장
서명: 홍길동 / 경영지원팀
```

→ 20초 만에 초안 완성. 세부 내용만 확인 후 발송.

**걸린 시간: 3~5분 (75% 절감)**

---

### Case 3. 파일 이름 일괄 변경

**Before — Copilot 없이**

지난달 계약서 PDF 47개의 파일명을 "YYYYMMDD_회사명_계약서" 형식으로 바꿔야 한다. 하나씩 F2 키를 누르며 복사·붙여넣기. 실수하면 되돌리기 반복.

**걸린 시간: 30~40분 + 실수 리스크**

---

**After — Copilot과 함께**

```
Windows PowerShell 스크립트 작성.

목적: C:\Documents\계약서 폴더의 PDF 파일 일괄 이름 변경
현재 파일명 패턴: 랜덤 이름 (예: contract_final_v2.pdf)
변경 목표: YYYYMMDD_원본파일명 형식 (날짜는 파일 생성일자 기준)
예외: 이미 날짜로 시작하는 파일(8자리 숫자)은 건너뜀
실행 전 변경될 파일 목록 먼저 출력 (dry-run)
상단 주석에 사용법 포함
```

→ 스크립트 30초 생성 → dry-run 확인 → 실행 2초.

**걸린 시간: 5~7분 (85% 절감)**

## 1.5 Copilot을 써도 여전히 사람이 해야 하는 것

Copilot이 시간을 절약해준다고 해서 모든 판단까지 위임할 수는 없습니다. 다음은 **반드시 여러분이 직접 확인해야 하는 부분**입니다.

| Copilot이 하는 것 | 여러분이 해야 하는 것 |
|------------------|----------------------|
| 이메일 초안 작성 | 수신자·맥락·관계 고려한 최종 검토 |
| 회의록 정리 | 사실 관계 확인 (날짜, 이름, 결정 내용) |
| 수식 생성 | 실제 데이터에 적용 후 결과값 검증 |
| PPT 초안 생성 | 회사 브랜드·목적에 맞는 내용 확인 |
| 파일 정리 스크립트 | dry-run 결과 확인 후 실행 |
| 문서 요약 | 중요한 세부 내용이 빠지지 않았는지 확인 |

**핵심 원칙: Copilot은 초안, 책임은 내가.**

## 1.6 VS Code + Copilot 오피스 셋업

이 과정에서는 VS Code를 메인 도구로 씁니다. "코딩 도구인데 왜?"라고 생각할 수 있는데, VS Code는 사실 텍스트 편집기입니다. 코드뿐 아니라 Markdown, 이메일 초안, 회의록, 스크립트 — 모든 텍스트 작업에 씁니다.

### 추천 확장 프로그램 (오피스 워커용)

```
VS Code 왼쪽 사이드바 > 확장(Extensions) > 검색

필수:
- GitHub Copilot
- GitHub Copilot Chat

있으면 좋은 것:
- Markdown Preview Enhanced    (회의록·보고서 미리보기)
- Korean Language Pack         (한국어 UI)
- Rainbow CSV                  (CSV 파일 보기 편하게)
```

### 작업 폴더 설정

```
C:\workspace\office-copilot\
├── emails\          (이메일 초안 보관)
├── meeting-notes\   (회의록 보관)
├── reports\         (보고서 보관)
├── scripts\         (PowerShell 스크립트)
└── templates\       (자주 쓰는 템플릿)
```

VS Code에서 이 폴더를 열면(`파일 > 폴더 열기`) Copilot이 폴더 내 모든 파일의 내용을 참고해서 더 좋은 제안을 합니다.

## 실습

### 실습 1. 내 반복 업무 TOP 5 찾기

앞의 20개 리스트에서 체크한 항목 중, **시간이 가장 많이 걸리는 순서대로 5개**를 메모장에 적어보세요.

```
내 반복 업무 TOP 5:
1. ________________ → 하루/주 소요 시간: ___
2. ________________ → 하루/주 소요 시간: ___
3. ________________ → 하루/주 소요 시간: ___
4. ________________ → 하루/주 소요 시간: ___
5. ________________ → 하루/주 소요 시간: ___
```

이 5개가 이 과정에서 여러분이 집중할 영역입니다.

### 실습 2. 첫 번째 Copilot 체험

VS Code를 열고 `Ctrl+Alt+I`로 Chat 사이드바를 엽니다. 아래 프롬프트를 그대로 입력해보세요.

```
내가 일반 오피스 워커(총무/경영지원팀)인데, 오늘 Copilot으로 해볼 수 있는
실용적인 업무 자동화 아이디어 5가지를 추천해줘.
각 아이디어마다:
- 업무 이름
- 어떻게 Copilot을 쓰는지 (한 줄)
- 예상 절약 시간
형식: 표로
```

결과를 보면서 "이건 내 업무에도 쓸 수 있겠다"는 것에 형광펜으로 표시(또는 메모)하세요.

### 실습 3. Before/After 직접 측정

여러분이 TOP 5에 적은 업무 중 가장 단순한 것 하나를 직접 해봅니다.

1. 먼저 **Copilot 없이** 평소대로 해보고 시간을 재세요.
2. 같은 작업을 **Copilot 프롬프트**로 초안을 받아서 수정해보고 시간을 재세요.
3. 두 시간을 비교합니다.

이 비교 경험이 남은 과정 동안 "왜 Copilot을 배우는가"의 답이 됩니다.

---

## 핵심 포인트

1. 오피스 워커 하루 업무의 60~70%는 반복 패턴이 있어 Copilot 초안 생성이 가능하다
2. 가장 효과가 큰 영역: **이메일, 회의록, 보고서, PPT, 파일 자동화**
3. Copilot은 초안 생성 도구, **검증과 최종 판단은 사람의 몫**
4. VS Code는 코딩 도구가 아니라 **모든 텍스트 작업을 위한 편집기**
5. 이 과정 전체를 통해 만드는 결과물은 다음날부터 실제 업무에 바로 씁니다
