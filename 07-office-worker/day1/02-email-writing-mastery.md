# 02. 이메일 작성 완전 정복

## 학습 목표

- 정중·친근·단호 세 가지 톤을 자유롭게 전환하는 감각 익히기
- 목적별(요청/알림/회신/거절/사과) 이메일 초안을 Copilot으로 2분 안에 만들기
- 한국어·영어 이메일 모두 Copilot으로 처리하는 흐름 체득
- 감사·축하·조의 등 특수 상황 이메일 패턴 5가지 습득

**예상 소요**: 60분 (실습 포함)

---

## 2.1 왜 이메일이 가장 먼저인가

사무직 하루 업무 중 이메일이 차지하는 시간은 평균 2~3시간입니다. 그런데 실제로 내용을 생각하는 시간은 30분도 안 됩니다. 나머지 시간은 이렇게 씁니다.

- "어떻게 시작하지?" — 첫 문장을 고민하다 5분
- "이 표현이 너무 딱딱한가?" — 톤을 조정하다 10분
- "거절인데 어떻게 부드럽게 쓰지?" — 3번 다시 쓰다 15분
- "영어 이메일인데 표현이 맞나?" — 사전 검색하다 10분

이 모든 "초안 고민 시간"을 Copilot이 대신합니다. **여러분은 내용이 맞는지 검토만 하면 됩니다.**

---

## 2.2 이메일 톤 3가지 이해하기

같은 내용이라도 톤에 따라 완전히 다른 이메일이 됩니다. 먼저 세 가지 톤의 차이를 느껴봅시다.

**상황**: 협력사에 자료 제출 기한을 연장해달라는 요청

### 톤 1. 정중 (가장 일반적)

> 안녕하세요, 홍길동입니다.  
> 다름이 아니라 이번 공급 계획서 제출 기한과 관련하여 연락 드립니다.  
> 내부 검토 일정으로 인해 제출 기한을 7월 31일에서 8월 5일로 5일 연장해 주실 수 있으실지 여쭤보고 싶습니다.  
> 불편을 드려 죄송하며, 검토해 주시면 감사하겠습니다.

### 톤 2. 친근 (상대와 이미 안면이 있는 경우)

> 김 과장님, 안녕하세요!  
> 공급 계획서 건인데요, 저희 쪽 내부 검토가 조금 늦어져서요.  
> 제출 기한을 8월 5일로 5일만 미뤄도 될까요? 큰 영향 없으시다면 부탁드리려고요. 😊

### 톤 3. 단호 (2번 이상 기한이 지났을 때)

> 안녕하세요, 홍길동입니다.  
> 공급 계획서 제출 기한(7월 31일)이 이미 지났습니다.  
> 8월 5일까지 미제출 시 계약 검토 일정에 영향이 생길 수 있습니다.  
> 8월 3일(월) 오전 중으로 제출 또는 현황 공유 부탁드립니다.

**느낌이 보이시나요?** 같은 내용이지만 관계·상황에 따라 톤을 달리해야 합니다. Copilot에게 톤을 명시하면 자동으로 맞춰줍니다.

## 2.3 Copilot으로 이메일 초안 만드는 흐름

### 기본 흐름

```
1. VS Code에서 새 .md 파일 생성 (예: email-draft.md)
2. Ctrl+Alt+I 로 Chat 사이드바 열기
3. 프롬프트 입력
4. 결과 확인 → 필요하면 톤·내용 조정 프롬프트 추가
5. 완성된 초안을 이메일 클라이언트에 붙여넣기
```

### 프롬프트 기본 구조

```
[이메일 종류] 초안 작성.

수신: [이름/직책]
목적: [한 줄로]
배경: [필요한 경우 한 줄]
포함 내용:
- [항목1]
- [항목2]
톤: [정중/친근/단호/유감 중 택1]
길이: [N문장]
서명: [이름] / [부서]
```

## 2.4 목적별 이메일 — 5가지 상황 상세

### 상황 1. 요청 이메일

**프롬프트**:

```
요청 이메일 초안 작성.

수신: IT팀 박민수 대리님
목적: 신규 직원 3명의 계정(이메일/사내 시스템) 생성 요청
배경: 8월 1일 입사 예정, 첫날부터 바로 업무 시작 필요
포함:
- 대상자 이름과 부서 (이정민/마케팅, 김소연/영업, 최준혁/개발)
- 필요 계정 종류 (이메일, 그룹웨어, Slack)
- 완료 요청 기한: 7월 28일 (월)
톤: 정중하고 협조적으로
길이: 6~8문장
서명: 홍길동 / 경영지원팀 / 내선 1234
```

**Copilot 결과 예시**:

```
안녕하세요, 박민수 대리님.

경영지원팀 홍길동입니다.

다름이 아니라 8월 1일(금) 입사 예정인 신규 직원 3명의 계정 생성을 요청 드리고자 연락드립니다.

대상자는 다음과 같습니다:
- 이정민 / 마케팅팀
- 김소연 / 영업팀
- 최준혁 / 개발팀

생성이 필요한 계정은 이메일, 그룹웨어, Slack 세 가지입니다. 입사 첫날부터 즉시 업무가 가능해야 하는 관계로, 7월 28일(월)까지 완료해 주시면 감사하겠습니다.

관련하여 추가 확인이 필요하시면 내선 1234로 연락 주세요. 늘 수고해 주셔서 감사합니다.

홍길동 / 경영지원팀
```

### 상황 2. 알림/공지 이메일

**프롬프트**:

```
전직원 대상 공지 이메일 초안 작성.

목적: 사옥 이전 안내
주요 내용:
- 이전일: 2026년 8월 25일 (월)
- 이전 주소: 서울 강남구 테헤란로 123, 하이타워 15층
- 이전 전 정리: 7월 31일까지 불필요한 물품 자체 처리
- 이사 당일: 재택근무 (별도 공지)
- 문의: 총무팀 이미래 (imrae@company.com)
톤: 명확하고 친근하게
형식: 인사 → 핵심 내용 → 준비 사항 → 문의처
```

### 상황 3. 회신 이메일 (수락)

**프롬프트**:

```
아래 미팅 제안을 수락하는 회신 이메일 작성.

원본 요청: ABC 컨설팅 이준호 부장이 7월 24일(목) 오후 2시 미팅 제안
내 답변: 수락, 강남 사무실 8층 회의실 A에서 진행
추가 전달: 주차는 지하 2층, 발리데이션 필요하면 사전 문자 요청
톤: 협조적이고 따뜻하게
길이: 4~5문장
```

---

### 상황 4. 회신 이메일 (거절/완곡)

이게 가장 어렵습니다. 상대 감정을 상하지 않으면서 명확하게 거절해야 합니다. Copilot이 가장 잘 도와주는 영역이기도 합니다.

**프롬프트**:

```
정중하게 거절하는 이메일 초안 작성.

수신: XYZ 마케팅 정민아 팀장
원본 요청: 우리 제품 협찬 요청 (인스타그램 캠페인)
거절 사유: 올해 협찬 예산 소진, 재정 정책상 추가 불가
대안 제시: 유상 구매 시 파트너십 할인 가능
톤: 유감스럽지만 정중하게, 관계 유지에 신경 쓰면서
길이: 6문장 이내
```

**Copilot 결과 예시**:

```
안녕하세요, 정민아 팀장님.

연락 주셔서 감사합니다. 이번 협찬 캠페인에 저희 제품을 고려해 주신 것만으로도 영광입니다.

말씀 주신 협찬 건과 관련하여, 아쉽게도 올해 예정된 협찬 예산이 이미 소진되어 요청에 응해드리기가 어려운 상황입니다. 재정 정책상 예산 외 집행이 불가하여 정중히 양해 부탁드립니다.

다만, 유상 구매를 원하신다면 파트너십 할인을 제공해 드릴 수 있으며, 내년 협찬 계획 시 우선 검토 대상으로 안내해 드릴 수 있습니다. 괜찮으시다면 별도로 연락 드리겠습니다.

감사합니다.
```

---

### 상황 5. 사과 이메일

**프롬프트**:

```
공식 사과 이메일 초안 작성.

수신: DEF 건설 이강산 부장님
사과 내용: 공급 계획서를 약속한 기한(7월 18일)보다 3일 늦게 제출
원인: 담당자 부재로 인한 내부 검토 지연
조치: 즉시 제출 완료, 향후 재발 방지를 위한 담당자 지정
톤: 진심 어리게, 변명보다 조치 중심으로
길이: 7~9문장
```

## 2.5 이메일 톤 조정 — 후속 프롬프트 활용

처음 결과가 마음에 안 들 때는 처음부터 다시 쓰지 마세요. **후속 프롬프트**로 조정합니다.

### 너무 딱딱할 때

```
위 이메일이 너무 딱딱해. 좀 더 따뜻하고 친근하게 다시 써줘. 내용은 그대로.
```

### 너무 길 때

```
위 이메일을 4문장으로 줄여줘. 핵심 요청 사항과 마감일은 반드시 유지.
```

### 너무 약해 보일 때 (단호하게)

```
위 이메일이 너무 유약해 보여. 정중하되 확실한 마감일과 결과를 명시하는 톤으로 바꿔줘.
```

### 시작이 어색할 때

```
이메일 첫 문장만 바꿔줘. "안녕하세요"로 시작하지 말고, 바로 목적을 전달하는 방식으로.
```

### 서명 형식 변경

```
서명 부분을 아래 형식으로 변경해줘:
홍길동 (Gildong Hong)
경영지원팀 | 내선 1234 | gildong@company.com
```

## 2.6 영어 이메일 — 4가지 상황

### 영어 이메일이 어려운 이유

한국어로 쓰면 2분인데 영어로 쓰면 20분인 이유는 표현이 맞는지 불안하기 때문입니다. Copilot을 쓰면 그 불안이 사라집니다.

### 영어 요청 이메일

```
Write a professional request email in English.

To: Mr. James Wilson, Procurement Manager at ABC Corp
Purpose: Request for product sample and price list
Background: We are evaluating new office supply vendors for Q3
Please include:
- Specific products: A4 paper (500 sheets/ream), ballpoint pens (box of 12)
- Quantity for sample: 2 reams + 2 boxes
- Preferred delivery: by July 25
Tone: polite and professional
Length: 5~7 sentences
Sign-off: Best regards, Gildong Hong / General Affairs Team
```

### 영어 사과 이메일

```
Write a professional apology email in English.

To: Sarah Kim, Director at XYZ Partners
Situation: Our team missed the deadline for the quarterly report (due July 15, submitted July 19)
Reason: Unexpected data migration issues
Actions taken: Report submitted now, additional quality check completed
Tone: sincere, solution-focused, no excuses
Length: 6~8 sentences
```

### 영어 확인/회신 이메일

```
Write a brief confirmation email in English.

Confirming: Meeting on July 24 at 2 PM at our office (8F, Conference Room A)
Add: Parking is available on B2, please send a text for validation
Tone: warm and professional
Length: 3~4 sentences
```

### 한국어 이메일 → 영어 번역

직접 영어로 쓰는 대신, 한국어로 쓴 후 번역을 요청하는 방법도 있습니다.

```
아래 한국어 이메일을 자연스러운 비즈니스 영어로 번역해줘.
직역보다 의역 우선. 원어민 동료가 읽어도 어색하지 않게.

[--- 원문 ---]
안녕하세요, 김민준 과장님.

다름이 아니라 이번 분기 납품 일정 관련하여 확인 드리고자 합니다.
기존에 협의된 7월 30일 납품 일정이 당사 생산 일정 변동으로 인해
8월 5일로 변경이 가능한지 여쭤보고자 합니다.
불편을 드려 죄송하며, 검토 부탁드립니다.

홍길동 올림
[--- 끝 ---]
```

## 2.7 특수 상황 이메일 5가지

일반적인 업무 이메일은 아니지만 오피스 워커라면 반드시 써야 하는 상황들입니다.

### 1. 감사 이메일

```
감사 이메일 초안 작성.

대상: 오재원 부장님 (타 부서)
감사 이유: 우리 부서 연간 행사 준비에 시간과 노력을 아낌없이 지원해주심
구체적으로 도움이 된 점: 장소 섭외, 케이터링 업체 소개, 당일 현장 진행 도움
톤: 진심 어리게, 형식적이지 않게
길이: 4~5문장
```

### 2. 축하 이메일 (승진)

```
승진 축하 이메일 초안 작성.

수신: 박지혜 부장님 (이번에 상무로 승진)
관계: 같은 층 타 부서 동료
톤: 진심을 담아 따뜻하게, 과하지 않게
포함: 그동안의 노력에 대한 인정 + 앞으로 기대하는 것
길이: 3~4문장
한국어 격식체
```

### 3. 축하 이메일 (결혼/출산)

```
결혼 축하 이메일 초안 작성.

수신: 이나영 대리님
관계: 같은 팀 동료
톤: 따뜻하고 개인적인 느낌, 너무 공식적이지 않게
길이: 3~4문장
```

### 4. 조의 이메일

```
조의 이메일 초안 작성.

수신: 최현우 팀장님
상황: 부친상
관계: 다른 부서 팀장, 여러 번 협업한 관계
톤: 진심 어리고 절제되게, 불필요한 위로 문구 없이
길이: 4~5문장
한국어 격식체
```

### 5. 부재중 자동 회신

```
이메일 부재중 자동 회신 메시지 작성.

부재 기간: 2026년 8월 4일 (월) ~ 8월 8일 (금)
이유: 하계 휴가 (구체적으로 밝히지 않아도 됨)
긴급 연락: 대리 담당자 이민서 (minseo@company.com / 내선 5678)
복귀 후: 8월 11일(월)에 순서대로 확인·처리 예정 안내

한국어 버전과 영어 버전 둘 다 작성.
```

## 2.8 이메일 요약 — 받은 이메일 빠르게 처리

이메일을 쓰는 것만큼 중요한 게 **받은 이메일을 빠르게 파악하는 것**입니다.

긴 이메일을 받았을 때:

```
아래 이메일을 3줄로 요약해줘.

형식:
- 핵심 내용:
- 나에게 요청하는 것:
- 마감일 (있으면):

[--- 이메일 ---]
(이메일 전문 붙여넣기)
[--- 끝 ---]
```

이걸 활용하면 수신함에 쌓인 20개 이메일도 5분 안에 처리 목록을 만들 수 있습니다.

아래 10가지 상황 중 **여러분 업무에 가장 가까운 5가지**를 골라 실제 Copilot으로 초안을 만들어보세요. 프롬프트는 위의 예시를 참고하되, **여러분의 실제 상황**으로 바꿔서 입력하세요.

| # | 상황 | 포인트 |
|---|------|--------|
| 1 | 협력사에 자료 제출 기한 연장 요청 | 정중 톤 |
| 2 | 팀 전체에 새 결재 절차 공지 | 명확하고 간결하게 |
| 3 | 외부 미팅 일정 수락 회신 | 장소/주차 안내 포함 |
| 4 | 납품업체 미제출 자료 독촉 (2번째 연락) | 단호 톤 |
| 5 | 회의 준비 미흡으로 사과 + 보완 안내 | 진심 어리게 |
| 6 | 거래처에 협찬/협업 제안 거절 | 관계 유지하면서 거절 |
| 7 | 팀장 승진 축하 | 진심 담아, 짧게 |
| 8 | 동료 결혼 축하 | 개인적이고 따뜻하게 |
| 9 | 타 부서 도움 감사 이메일 | 구체적으로 감사 이유 명시 |
| 10 | 1주 휴가 전 부재중 자동 회신 설정 | 한/영 둘 다 |

### 점검 기준

각 이메일을 완성한 후 다음을 확인하세요:

- [ ] 수신자와 목적이 첫 문단에서 명확한가?
- [ ] 톤이 상황과 관계에 맞는가?
- [ ] 요청/결정 사항이 명확하게 들어갔는가?
- [ ] 마감일이나 다음 단계가 포함되었는가?
- [ ] 서명이 완결되어 있는가?

---

## 핵심 포인트

1. **톤 3가지 기억**: 정중(일반) · 친근(친한 사이) · 단호(기한 지났을 때)
2. **프롬프트 5개 항목**: 수신자 + 목적 + 포함 내용 + 톤 + 길이
3. **첫 결과 안 나오면 "위 이메일을 더 [방향]으로 바꿔줘"로 수정**
4. **영어 이메일은 한국어로 먼저 써서 번역 요청해도 된다**
5. 특수 상황(감사/축하/조의)도 Copilot이 초안을 만들어준다 — 검토만 하면 됨
