# 03. 일반 실무 엑셀 수식 — Copilot으로 수식 막힘 없애기

## 학습 목표

- 오피스 실무에서 가장 자주 쓰는 엑셀 수식 8가지를 Copilot으로 빠르게 생성하는 법 익히기
- SUMIFS, COUNTIFS, TEXTJOIN, 날짜 계산, 조건부 서식 등 핵심 함수 이해
- "이 데이터를 이렇게 뽑고 싶다"는 상황을 프롬프트로 바꾸는 감각 체득
- 실습: 근태 대시보드 만들기

**예상 소요**: 70분 (실습 포함)

---

## 3.1 왜 엑셀 수식이 어려운가

엑셀을 쓰면서 막히는 순간은 대개 이렇습니다.

- VLOOKUP인지 INDEX/MATCH인지 헷갈린다
- 조건이 두 개인 SUMIFS의 인수 순서가 기억이 안 난다
- 날짜 계산을 어떤 함수로 해야 하는지 모른다
- 이름과 부서를 하나의 셀에 합치고 싶은데 수식이 기억 안 난다

이런 상황마다 구글에서 검색하고 예제를 이해하고 내 데이터에 맞게 고치는 데 10~20분씩 씁니다.

**Copilot에게 상황을 설명하면 내 데이터 기준 수식을 바로 줍니다.** 수식 공식을 외울 필요가 없어집니다.

---

## 3.2 핵심 원칙: 수식 프롬프팅의 3단계

### 1단계. 상황 설명

```
엑셀 수식 작성 요청.

데이터 구조:
- A열: 날짜
- B열: 부서명
- C열: 직원명
- D열: 근무 시간

목적: B열이 "마케팅팀"이고 D열이 8 이상인 행의 개수를 세고 싶음.
```

### 2단계. 수식 받기

Copilot이 이렇게 응답합니다:

```
=COUNTIFS(B:B, "마케팅팀", D:D, ">=8")
```

**설명**: B열 전체에서 "마케팅팀"이고 동시에 D열이 8 이상인 행의 개수를 셉니다.

### 3단계. 적용 및 검증

수식을 엑셀에 붙여넣고 결과가 예상과 맞는지 확인합니다. 맞지 않으면 Copilot에 "조건이 틀린 것 같다, 확인해줘"라고 후속 질문합니다.

---

## 3.3 수식 8가지 — 실무 상황별 정리

### 수식 1. SUMIFS — 여러 조건 합계

**언제 씁니까**: "영업팀에서 이번 달에 완료된 항목의 금액 합계"처럼 조건이 2개 이상인 합계.

**프롬프트**:
```
엑셀 SUMIFS 수식 작성.

데이터:
- A열: 날짜 (2026-07-01 형식)
- B열: 부서 (예: "영업팀")
- C열: 상태 (예: "완료")
- D열: 금액 (숫자)

목적: B열이 "영업팀"이고 C열이 "완료"인 행의 D열 합계
수식만 작성, 한 줄 설명 포함.
```

**결과**:
```excel
=SUMIFS(D:D, B:B, "영업팀", C:C, "완료")
```

> **설명**: `SUMIFS(합산범위, 조건범위1, 조건1, 조건범위2, 조건2)` 순서입니다. 합산 범위가 맨 앞입니다.

**응용**: 특정 날짜 범위까지 조건 추가

```excel
=SUMIFS(D:D, B:B, "영업팀", C:C, "완료", A:A, ">="&DATE(2026,7,1), A:A, "<="&DATE(2026,7,31))
```

---

### 수식 2. COUNTIFS — 여러 조건 개수

**언제 씁니까**: "이번 달에 지각한 직원이 몇 명인가" 같은 조건부 카운트.

**프롬프트**:
```
엑셀 COUNTIFS 수식.

A열: 날짜, B열: 직원명, C열: 출근 상태 ("정상"/"지각"/"결근")
목적: C열이 "지각"이고 A열이 2026년 7월인 행의 개수.
```

**결과**:
```excel
=COUNTIFS(C:C, "지각", A:A, ">="&DATE(2026,7,1), A:A, "<"&DATE(2026,8,1))
```

---

### 수식 3. TEXTJOIN / CONCAT — 텍스트 결합

**언제 씁니까**: "이름 + 부서 + 직급을 하나의 셀에 합치고 싶다" 같은 텍스트 조합.

**프롬프트**:
```
엑셀 수식 작성.

A1: 성 (예: "김"), B1: 이름 (예: "철수"), C1: 부서 (예: "경영지원팀"), D1: 직급 (예: "대리")
원하는 결과: "김철수 (경영지원팀 대리)"
```

**결과**:
```excel
=A1&B1&" ("&C1&" "&D1&")"
```

또는 구분자가 있는 경우:

```excel
=TEXTJOIN(" | ", TRUE, A1, B1, C1, D1)
```

> 결과: "김 | 철수 | 경영지원팀 | 대리"

---

### 수식 4. DATEDIF — 날짜 차이 계산

**언제 씁니까**: 입사일로부터 오늘까지 근속 연수 계산, 계약 만료까지 남은 날 수.

**프롬프트**:
```
엑셀 날짜 수식 작성.

A1에 입사일이 있음 (예: 2022-03-15)
목적1: 오늘까지 근속 연수 (년 단위, 소수점 없이)
목적2: 오늘까지 근속 월 수
목적3: 계약 만료일(B1)까지 남은 일수
DATEDIF 함수 사용.
```

**결과**:
```excel
목적1 (근속 연수): =DATEDIF(A1, TODAY(), "Y")
목적2 (근속 월수): =DATEDIF(A1, TODAY(), "YM")  ← 연도 제외한 개월 수
목적3 (만료 남은 일수): =B1 - TODAY()
```

> **주의**: DATEDIF는 엑셀 함수 도움말에 나오지 않지만 작동합니다. 호환성을 위해 유지된 숨겨진 함수입니다.

---

### 수식 5. VLOOKUP / XLOOKUP — 다른 표에서 값 찾기

**언제 씁니까**: 직원 번호로 이름 찾기, 제품 코드로 가격 찾기처럼 한 표의 값으로 다른 표에서 연관 데이터를 가져올 때.

**프롬프트**:
```
엑셀 수식 작성.

Sheet1의 A열에 직원번호, B열에 이름이 있음 (기준 표)
Sheet2의 A열에 직원번호가 있을 때, Sheet2의 B열에 이름을 자동으로 채우는 수식.
최신 엑셀이라면 XLOOKUP 사용, 구버전이면 VLOOKUP 사용.
```

**결과 (XLOOKUP, 최신 버전)**:
```excel
=XLOOKUP(A2, Sheet1!A:A, Sheet1!B:B, "없음")
```

**결과 (VLOOKUP, 구버전 호환)**:
```excel
=VLOOKUP(A2, Sheet1!A:B, 2, FALSE)
```

> XLOOKUP이 더 직관적입니다. 엑셀 2019 이상이면 XLOOKUP 사용을 권장합니다.

---

### 수식 6. IF / IFS — 조건에 따른 값 반환

**언제 씁니까**: "근무 시간이 8시간 이상이면 '정상', 미만이면 '조기퇴근'"처럼 조건에 따라 표시 값을 바꿀 때.

**프롬프트**:
```
엑셀 수식 작성.

D열: 근무 시간 (숫자)
조건:
- 9시간 이상: "초과근무"
- 8~8.9시간: "정상"
- 8 미만: "조기퇴근"
IFS 함수 사용.
```

**결과**:
```excel
=IFS(D2>=9, "초과근무", D2>=8, "정상", D2<8, "조기퇴근")
```

---

### 수식 7. UNIQUE + SORT — 중복 제거 + 정렬 (Excel 365)

**언제 씁니까**: 부서 목록에서 중복 없이 고유한 부서명만 추출할 때.

**프롬프트**:
```
엑셀 수식 작성.

B열에 부서명이 반복적으로 들어 있음 (중복 있음)
목적: 고유한 부서명 목록을 가나다 순으로 정렬해서 추출
Excel 365 함수 사용 가능.
```

**결과**:
```excel
=SORT(UNIQUE(B2:B100))
```

> **주의**: UNIQUE, SORT 함수는 Microsoft 365 또는 Excel 2021 이상에서만 동작합니다.

---

### 수식 8. 조건부 서식 수식

**언제 씁니까**: "마감일이 오늘보다 지났으면 빨간색"처럼 데이터 상태를 색으로 표시하고 싶을 때.

**프롬프트**:
```
엑셀 조건부 서식에서 쓸 수식 작성.

목적: C열의 날짜가 오늘 기준 지났으면 해당 행 전체를 빨간색으로
조건부 서식 > 새 규칙 > "수식을 사용하여 서식을 지정할 셀 결정"에 넣을 수식.
```

**결과**:
```excel
=$C2 < TODAY()
```

> **사용법**: 조건부 서식 > 새 규칙 > "수식을 사용하여 서식을 지정할 셀 결정" > 위 수식 입력 > 빨간 배경 선택.

## 3.4 Copilot 엑셀 수식 프롬프팅 팁

### 팁 1. 열 구조를 구체적으로 설명하라

```
❌ 나쁜 예:
근태 데이터에서 지각 개수 세는 수식

✅ 좋은 예:
A열: 날짜, B열: 직원명, C열: 상태 ("정상"/"지각"/"결근"), D열: 부서
목적: C열이 "지각"인 행 개수. 단, D열이 "영업팀"인 행만.
```

### 팁 2. 결과 예시를 보여줘라

```
데이터 예시:
A1: 2026-07-01, B1: 김철수, C1: 지각, D1: 영업팀
A2: 2026-07-01, B2: 이영희, C2: 정상, D2: 마케팅팀

목적: 이 데이터에서 C열이 "지각"이고 D열이 "영업팀"인 행 개수.
```

### 팁 3. 버전을 명시하라

```
엑셀 버전: Microsoft 365 (최신 함수 사용 가능)
또는: 엑셀 2016 (XLOOKUP 없음, VLOOKUP 써야 함)
```

### 팁 4. 에러가 나면 함께 디버깅

수식을 붙여넣었는데 `#VALUE!` 또는 `#N/A` 에러가 났을 때:

```
아래 수식을 붙여넣었더니 #N/A 에러가 남.
데이터: A열에 숫자로 된 직원번호, Sheet1의 A열에는 텍스트 형식 직원번호
수식: =XLOOKUP(A2, Sheet1!A:A, Sheet1!B:B, "없음")
원인과 해결 방법을 알려줘.
```

> 이런 식으로 에러 메시지 + 데이터 형식까지 알려주면 Copilot이 원인까지 찾아줍니다.

## 3.5 데이터 유효성 검사 — 드롭다운 만들기

수식은 아니지만 업무에서 자주 쓰는 기능입니다. 셀에 드롭다운 목록을 만들면 입력 오류가 줄어듭니다.

**Copilot 프롬프트**:
```
엑셀에서 특정 셀에 드롭다운 목록을 만드는 단계별 방법을 알려줘.

목록 항목: 정상, 지각, 조기퇴근, 결근, 휴가
목적: C열 전체에 이 5가지 값만 입력되도록 제한
직접 입력 시 경고 표시
초보자도 따라할 수 있게 메뉴 경로 포함.
```

**Copilot 결과 (절차)**:
1. C열 전체를 선택합니다 (C열 헤더 클릭)
2. 상단 메뉴 > **데이터** > **데이터 유효성 검사**
3. **설정** 탭 > **허용**: "목록" 선택
4. **원본** 입력: `정상,지각,조기퇴근,결근,휴가` (쉼표로 구분)
5. **오류 메시지** 탭에서 경고 스타일과 메시지 설정
6. 확인

## 실습 — 근태 대시보드 만들기

### 데이터 준비

새 엑셀 파일을 열고 `Sheet1`에 아래 형식으로 데이터를 만들거나 붙여넣으세요. (최소 10개 행)

| A (날짜) | B (직원명) | C (부서) | D (상태) | E (근무시간) |
|----------|-----------|---------|---------|------------|
| 2026-07-01 | 김철수 | 영업팀 | 정상 | 8.5 |
| 2026-07-01 | 이영희 | 마케팅팀 | 지각 | 7.0 |
| 2026-07-01 | 박민수 | 경영지원팀 | 정상 | 9.0 |
| 2026-07-02 | 김철수 | 영업팀 | 결근 | 0 |
| 2026-07-02 | 이영희 | 마케팅팀 | 정상 | 8.0 |
| ... | ... | ... | ... | ... |

### 대시보드 만들기 단계

`Sheet2`를 열고 아래 항목을 수식으로 채웁니다. 막히면 Copilot에 프롬프트로 물어보세요.

**Step 1. 부서별 총 근무시간**

```
이번 달 부서별 총 근무시간 합계. SUMIFS 사용.
A열: 날짜, B열: 직원명, C열: 부서, E열: 근무시간
Sheet2의 A2에 부서명이 있을 때 B2에 해당 부서 총 근무시간 수식.
```

**Step 2. 부서별 지각 인원 수**

```
C열(부서)이 특정 부서이고 D열(상태)이 "지각"인 행 개수.
Sheet2의 A2에 부서명, C2에 수식 작성.
```

**Step 3. 상태 자동 색상 (조건부 서식)**

```
D열에서 "지각"인 셀을 노란색으로, "결근"인 셀을 빨간색으로 표시하는
조건부 서식 수식 2개를 알려줘.
```

**Step 4. 직원별 평균 근무시간**

```
B열(직원명)이 특정 이름인 행의 E열(근무시간) 평균.
AVERAGEIF 함수 사용. Sheet2의 E2에 직원명, F2에 수식.
```

### Copilot 프롬프팅 연습

대시보드를 만들면서 막히는 부분이 생기면 그 상황을 그대로 Copilot에 설명해보세요. 예를 들어:

```
엑셀에서 Sheet1의 데이터를 참조해서 Sheet2에 요약 표를 만들고 싶어.
Sheet1 구조: A열 날짜, B열 직원명, C열 부서, D열 상태, E열 근무시간
Sheet2에서 원하는 것: 부서별로 이번 달 정상/지각/결근 건수를 각각 세는 표.
사용 가능한 함수와 수식 알려줘.
```

이 프롬프트 하나로 대시보드의 핵심 수식을 한 번에 받을 수 있습니다.

---

## 핵심 포인트

1. **수식을 외울 필요 없다** — 상황을 설명하면 Copilot이 수식을 만들어준다
2. **프롬프트에 열 구조를 구체적으로** — A열: 날짜, B열: 부서 등 명시
3. **SUMIFS 인수 순서**: 합산 범위 → (조건 범위, 조건) 쌍들
4. **COUNTIFS 인수 순서**: (조건 범위, 조건) 쌍들 — 집계 범위 없음
5. **에러 나면 Copilot에 에러 메시지 + 데이터 형식 알려주고 디버깅 요청**
