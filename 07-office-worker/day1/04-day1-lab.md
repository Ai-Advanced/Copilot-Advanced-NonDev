# 04. Day 1 종합 실습 — 주간 부서 보고 준비

## 실습 개요

**시나리오**: 여러분은 경영지원팀 담당자입니다. 매주 금요일 오후, 다음 주 월요일 임원 주간 보고를 위한 부서 보고 자료를 준비해야 합니다. 오늘은 금요일 오후 3시. 지금부터 Copilot과 함께 1시간 안에 모든 준비를 마칩니다.

**준비 목록**:
1. 이번 주 수신한 이메일 3건에 회신 작성
2. 부서 주간 근태 데이터 엑셀 요약 시트 완성
3. 결과를 팀 슬랙 채널에 공유할 메시지 작성

**예상 소요**: 50분

---

## 실습 환경 준비

먼저 작업 폴더를 만들고 VS Code로 엽니다.

```
Windows PowerShell 또는 파일 탐색기:
C:\workspace\office-copilot\week-report\ 폴더 생성

VS Code > 파일 > 폴더 열기 > week-report 폴더 선택
```

이 폴더 안에 다음 파일들을 만들 것입니다:
- `emails\email-replies.md` — 이메일 회신 초안 3건
- `attendance-summary.md` — 근태 요약 (엑셀 수식 포함)
- `slack-message.md` — 팀 슬랙 공유 메시지

## 파트 1. 이메일 회신 3건 (20분)

### 이메일 1. 회의 참석 수락

**받은 이메일 상황**:
> 제목: [요청] 8월 임원 워크숍 사전 미팅 참석 부탁
> 발신: 전략팀 박준호 차장
> 내용: 8월 워크숍 준비를 위한 사전 조율 미팅을 7월 28일(월) 오전 10시에 진행하려고 합니다. 경영지원팀에서 총무 관련 부분(장소/케이터링/숙박)을 담당해주시기를 부탁드립니다. 참석 가능 여부와 준비 범위 확인 부탁드립니다.

`emails\email-replies.md` 파일을 열고 아래 프롬프트를 Chat에 입력합니다:

```
아래 이메일 요청에 회신하는 이메일 초안 작성.

원본 요청 요약:
- 발신: 전략팀 박준호 차장
- 내용: 8월 임원 워크숍 준비 사전 미팅 참석 요청 (7월 28일 월요일 오전 10시)
- 담당 범위: 장소/케이터링/숙박

내 답변:
- 미팅 참석 가능
- 준비 범위 확인 후 미팅에서 세부 논의 예정
- 장소·케이터링은 담당 가능, 숙박은 협력사 리스트 업데이트 필요 (미팅 전 완료 예정)

톤: 협조적이고 간결하게
길이: 5~6문장
서명: [내 이름] / 경영지원팀
```

결과를 파일에 붙여넣고 `## 이메일 1 — 박준호 차장 회신` 헤더 아래에 저장합니다.

### 이메일 2. 자료 제출 독촉 (단호)

**받은 이메일 상황**:
> 이전에 이미 한 번 요청했음. 총무 비품 신청서를 7월 15일까지 제출해달라고 각 부서에 공문을 보냈는데, 홍보팀과 개발팀이 아직 미제출.

```
자료 제출 독촉 이메일 초안 작성.

수신: 홍보팀 이선아 팀장, 개발팀 최민철 팀장 (동시 수신)
목적: 7월 15일 마감이었던 하반기 비품 신청서 미제출 독촉
현황: 현재 7월 18일, 3일 경과
영향: 7월 22일 발주 마감이라 이번 주 금요일(7월 19일)까지 미제출 시 하반기 비품 지원 불가
톤: 정중하되 단호하게, 마감과 결과를 명확하게
길이: 5문장 이내
서명: [내 이름] / 경영지원팀
```

결과를 `## 이메일 2 — 비품 신청서 독촉` 헤더 아래에 저장합니다.

**검토 포인트**: 이 이메일을 발송 전 반드시 확인하세요.
- [ ] 마감일(금요일)이 정확히 명시되었나?
- [ ] 미이행 시 결과(하반기 비품 지원 불가)가 포함되었나?
- [ ] 수신자 이름과 직책이 맞나?

## 파트 2. 엑셀 근태 요약 시트 (20분)

### 데이터 셋업

`attendance-summary.md` 파일을 열고, 아래 프롬프트로 이번 주 근태 데이터를 위한 엑셀 수식 세트를 만듭니다.

실제로는 엑셀 파일에서 작업하지만, 여기서는 **Copilot Chat으로 수식을 받아 → 엑셀에 붙여넣기**하는 흐름을 연습합니다.

**근태 데이터 구조** (Sheet1에 있다고 가정):

| A | B | C | D | E |
|---|---|---|---|---|
| 날짜 | 직원명 | 부서 | 상태 | 근무시간 |
| 2026-07-14 | 김철수 | 마케팅 | 정상 | 8.5 |
| 2026-07-14 | 이영희 | 영업 | 지각 | 7.5 |
| ... | ... | ... | ... | ... |

---

### 수식 세트 요청 — 한 번에 받기

아래 프롬프트를 Chat에 입력합니다:

```
엑셀 주간 근태 요약 수식 세트 작성.

Sheet1 데이터 구조:
- A열: 날짜
- B열: 직원명
- C열: 부서
- D열: 상태 (정상/지각/조기퇴근/결근/휴가)
- E열: 근무시간

Sheet2에서 만들 요약 항목:
1. 이번 주 전체 출근자 수 (D열이 "결근" 또는 "휴가"가 아닌 행 수, 중복 없이)
2. 부서별 지각 건수 표 (C열 부서, COUNTIFS)
3. 부서별 평균 근무시간 (AVERAGEIFS)
4. 이번 주 결근자 이름 목록 (D열이 "결근"인 B열 값)

엑셀 365 기준, 수식만 작성. 각 수식에 한 줄 설명 포함.
```

---

### 결과 활용

Copilot이 제공하는 수식들을 `attendance-summary.md`에 저장합니다. 형식 예시:

```markdown
## 주간 근태 요약 수식

### 1. 전체 출근자 수
=COUNTA(UNIQUE(FILTER(B:B, (D:D<>"결근")*(D:D<>"휴가"))))
설명: D열이 결근/휴가가 아닌 행에서 중복 없는 직원명 개수

### 2. 부서별 지각 건수
=COUNTIFS(C:C, "마케팅", D:D, "지각")
설명: C열이 특정 부서이고 D열이 지각인 행 개수

### 3. 부서별 평균 근무시간
=AVERAGEIFS(E:E, C:C, "마케팅")
설명: 마케팅팀의 E열 평균값

### 4. 결근자 이름 목록
=TEXTJOIN(", ", TRUE, FILTER(B:B, D:D="결근"))
설명: 결근 상태인 직원명을 쉼표로 연결
```

실제 엑셀에 수식을 붙여넣어 검증합니다.

---

### 조건부 서식 요청

수식을 넣은 후 시각화를 위한 조건부 서식도 요청합니다:

```
엑셀 조건부 서식 수식.

목적1: D열에서 "결근"인 셀 행 전체를 빨간 배경으로
목적2: D열에서 "지각"인 셀 행 전체를 노란 배경으로
목적3: E열(근무시간)이 9 이상인 셀을 파란 글씨로

조건부 서식 > 새 규칙 > 수식 사용 방식으로 적용하는 수식 3개.
적용 범위: $A:$E (행 전체 강조는 $D2 형식으로 고정 주의)
```

## 파트 3. 슬랙 공유 메시지 작성 (10분)

### 주간 보고 요약 → 슬랙 메시지

이제 이메일 3건 완료 + 근태 데이터 요약 완료 상황입니다. 이것을 팀 슬랙 채널에 공유합니다.

`slack-message.md` 파일을 열고:

```
아래 주간 업무 내용을 팀 슬랙 채널에 올릴 짧은 메시지로 정리.

내용:
- 이메일 처리: 박준호 차장 미팅 참석 확정, 비품 신청 독촉 발송, ABC인테리어 감사 및 미팅 제안
- 근태 데이터: 이번 주 정상 출근율 94%, 지각 2건, 결근 1건
- 다음 주 주요 일정: 7월 28일 월요일 임원 워크숍 사전 미팅 10시

형식:
- 이모지 사용 (적당히)
- 불릿 포인트
- 10줄 이내
- 마지막에 "좋은 주말 되세요!" 같은 인사
- 채널: #경영지원팀-주간공유
톤: 친근하고 간결하게
```

---

### 임원 보고용 1줄 요약

슬랙 메시지 외에, 월요일 임원 보고를 위한 1줄 요약도 만들어둡니다:

```
아래 이번 주 경영지원팀 활동을 임원 보고용으로 한 문장으로 요약.

주요 내용:
- 하반기 비품 신청 독촉 완료 (2개 부서 미제출 → 금요일 마감)
- 8월 임원 워크숍 사전 준비 착수 (장소/케이터링/숙박 담당)
- 사무 가구 납품 완료 및 협력사 차기 미팅 제안

원칙: 수치 위주, 사실만, 판단 없이.
```

**이메일 2 (독촉)**
- [ ] 마감일(이번 주 금요일)이 정확히 명시됐나?

- [ ] 수신자가 2명(CC 또는 TO)으로 설정될 예정인가?

**이메일 3 (감사+제안)**
- [ ] 감사 이유가 구체적인가?
- [ ] 미팅 제안이 포함됐나?
- [ ] 연락처가 포함됐나?

- [ ] 수식을 실제 엑셀에 붙여넣어 결과가 나오는가?

- [ ] 이번 주 주요 처리 내용 3가지가 포함됐나?

- [ ] 10줄 이내인가?

## 핵심 포인트

1. **초안 고민 시간 0** — 상황만 설명하면 Copilot이 초안을 만든다
2. **톤 조정은 후속 프롬프트로** — "더 단호하게", "4문장으로 줄여줘"
3. **수식도 마찬가지** — 데이터 구조 + 목적을 설명하면 수식이 나온다
4. **검토는 반드시** — 발송 전 수신자·사실관계·마감일을 꼭 확인
5. **오늘 만든 파일들이 여러분의 재사용 템플릿** — 다음 주에 조금만 수정해서 씁니다
