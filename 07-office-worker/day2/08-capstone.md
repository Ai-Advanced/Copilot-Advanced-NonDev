# 08. 캡스톤 — 월간 부서 운영 자동화

**완성 후 Azure로:** 아래 산출물 검증을 마치면 [공통 배포 캡스톤](../../09-azure-capstone/README.md)에서 업무 안내 포털을 게시합니다. [직군별 요구사항·프롬프트](../../09-azure-capstone/roles.md)를 사용하며, 기존 과정과 별도 편성입니다.

## 캡스톤 개요

**시나리오**: 여러분은 경영지원팀 담당자입니다. 매월 말, 다음 달 초에 처리해야 하는 정기 업무 패키지가 있습니다. 이번 캡스톤에서는 이 패키지 전체를 Copilot으로 완성합니다.

**만들어야 할 것**:
1. 이번 달 정기 회의록 정리 + 액션 아이템 공유
2. 월간 부서 운영 리포트 이메일 (임원 보고)
3. 중요 문서 월간 백업 스크립트
4. 다음 달 주요 행사 임원 브리핑 PPT 초안
5. 다음 달 정기 회의 일정 조율 이메일

**예상 소요**: 60~80분 (각 파트를 실제로 완성하는 시간 포함)

**준비**:
```
VS Code > 폴더 열기 > C:\workspace\office-copilot\monthly-package\
```

## 파트 1. 정기 회의록 정리 + 공유 (15분)

### 1-1. 월간 운영 회의 노트

아래 회의 노트를 사용하거나 실제 여러분의 최근 회의 노트로 대체하세요.

```
7/31 경영지원팀 월간 운영 회의
참석: 김상무(주관), 박팀장, 이대리, 최사원, 홍길동

1. 7월 업무 결산
- 총무: 비품 신청 완료, 사옥 3층 에어컨 AS 완료
- 비용: 6월 법인카드 정산 완료, 7월 건 마감 8/5
- 행사: 8/15 창립기념일 행사 준비 진행 중 (케이터링 업체 선정 완료, 케이터링비 48만원)

2. 8월 주요 일정
- 8/1: 신입 3명 입사 (계정 생성 완료 확인 필요)
- 8/15: 창립기념일 행사 (10층 대회의실, 예산 50만원 이내)
- 8/22~23: 임직원 워크숍 (제주, 30명, 버스 이동)
- 8/25: 사옥 이전 (강남구 테헤란로 123, 하이타워 15층)

3. 이슈 및 요청사항
- 사옥 이전 관련 IT 장비 이전: IT팀과 협의 필요 (박팀장)
- 워크숍 버스 견적: 아직 2곳 미확인 (홍길동, 8/5까지)
- 신규 직원 웰컴키트 구매: 1인당 5만원, 3명분 = 15만원 (이대리, 8/1 입사 전)

4. 기타
- 8월 추석 전후 일정 감안해서 10월 워크숍 추가 검토 제안 (박팀장 → 9월 회의에서 재논의)
- 다음 월간 회의: 8/28 (목) 14:00
```

### 1-2. 회의록 정리 프롬프트

```
아래 월간 경영지원팀 회의 노트를 공식 회의록 Markdown으로 정리해줘.

포함:
1. 회의 개요 (일시/참석자/주관자)
2. 7월 업무 결산 (항목별 한 줄 요약)
3. 8월 주요 일정 표 (날짜/내용/담당자/비고)
4. 이슈 및 요청사항 (현황 + 담당자 + 마감일)
5. 액션 아이템 표 (번호/내용/담당자/마감일/상태)
6. 다음 회의 정보

[--- 회의 노트 ---]
(위 노트 붙여넣기)
[--- 끝 ---]
```

### 1-3. 팀 공유 슬랙 메시지

회의록 완성 후 팀에 공유할 메시지:

```
위 회의록을 팀 슬랙 #경영지원팀-공지 채널에 올릴 메시지로 요약.

포함:
- 7월 주요 완료 사항 3개
- 8월 핵심 일정 3개
- 각자 액션 아이템 간략히
- 전체 회의록 링크 안내 (플레이스홀더)

이모지 적당히, 10줄 이내, 친근하게
```

## 파트 2. 월간 부서 운영 리포트 이메일 (15분)

임원(김상무)에게 월간 운영 결과를 보고하는 공식 이메일입니다.

### 2-1. 리포트 이메일 프롬프트

```
월간 부서 운영 리포트 이메일 작성.

수신: 김 상무님
발신: 경영지원팀 박 팀장 (서명 플레이스홀더)
목적: 7월 경영지원팀 운영 결과 보고 + 8월 주요 일정 사전 공유

이메일 구조:
1. 인사 + 보고 목적 (2문장)
2. 7월 주요 성과 (불릿 3~4개)
   - 총무/비용/행사 각 1줄씩
   - 특이사항: 사옥 이전 준비 착수
3. 8월 주요 일정 표
   - 날짜 | 내용 | 준비 현황
4. 현재 진행 중인 이슈 (2개)
5. 임원 승인/확인이 필요한 사항 (있으면)
6. 마무리 인사

톤: 간결하고 사실 위주, 임원 보고용 격식
포함 내용: 파트 1에서 정리한 회의록 내용 기반
```

### 2-2. 이메일 요약본 (임원 1분 읽기용)

긴 이메일 위에 붙일 TL;DR (핵심 요약):

```
위 이메일의 핵심 내용을 이메일 맨 위에 넣을 3줄 요약으로 작성.

형식:
📌 이번 달 요약 (1분 읽기용)
• [성과 1줄]
• [8월 핵심 일정 1줄]
• [필요한 결정/승인 1줄]

임원이 빠르게 파악할 수 있도록 수치 위주로.
```

## 파트 3. 중요 문서 월간 백업 스크립트 (15분)

매월 말 중요 문서들을 백업하는 스크립트입니다.

### 3-1. 백업 스크립트 요청

```
Windows PowerShell 월간 백업 스크립트 작성.

목적: 중요 업무 폴더 월간 백업
백업 원본:
- C:\workspace\office-copilot\ (업무 워크스페이스)
- C:\Documents\Contracts\ (계약서 폴더)
- C:\Documents\Reports\ (보고서 폴더)

백업 대상: D:\MonthlyBackup\YYYY-MM\ 폴더
백업 방식: 원본을 통째로 복사 (robocopy 또는 Copy-Item 사용)
백업 폴더 이름: YYYY-MM-DD_[원본폴더명] 형식

추가 기능:
- 3개월 이상 된 백업은 자동 삭제 (백업 폴더 내)
- 백업 완료 후 로그 파일 생성 (backup-log-YYYYMMDD.txt)
- 로그에 포함: 백업 시작/종료 시간, 각 폴더 파일 수, 총 용량

$DryRun = $true 변수, 상단 사용법 주석 포함.
```

### 3-2. 백업 스크립트 개선

스크립트를 받은 후 추가 요청:

```
위 스크립트에 아래 기능을 추가해줘:

1. 백업 시작 전 D:\MonthlyBackup 폴더 여유 공간 확인
   - 여유 공간이 5GB 미만이면 경고 메시지 + 확인 후 진행
2. 스크립트 완료 후 Windows 알림(toast notification) 표시
   - "월간 백업 완료 — [날짜] [파일 수]개 파일 백업 성공"
```

## 파트 4. 임원 브리핑 PPT 초안 (20분)

다음 달(8월) 주요 일정을 임원에게 브리핑하는 PPT 초안입니다.

### 4-1. PPT 목차 생성

```
임원 브리핑 PPT 목차 작성.

주제: 2026년 8월 경영지원팀 주요 일정 및 준비 현황 브리핑
청중: 임원 (상무 이상)
발표 시간: 10분
총 슬라이드: 7~9장

슬라이드 구성:
1. 표지
2. 8월 주요 일정 한눈에 보기 (캘린더 형식)
3. 창립기념일 행사 (8/15) 준비 현황
4. 임직원 워크숍 (8/22~23) 준비 현황
5. 사옥 이전 (8/25) 준비 현황
6. 신규 입사자 맞이 준비
7. 임원 결정 필요 사항
8. Q&A

각 슬라이드: 제목 + 핵심 내용 2~3불릿 + 발표자 노트 2문장
```

### 4-2. 핵심 슬라이드 상세 초안

```
위 목차의 슬라이드 7번 (임원 결정 필요 사항) 상세 초안 작성.

이 슬라이드의 목적: 임원에게 결정·승인을 요청하는 사항들을 명확히 전달

포함할 내용:
1. 사옥 이전 이사 전문업체 계약 승인 (예산 280만원)
2. 10월 2차 워크숍 추가 검토 승인 여부 (예산 검토 후 9월 보고 예정)
3. 하반기 복리후생 예산 조정 건 (현재 예산 대비 15% 증액 요청)

형식:
- 각 항목: 내용 + 필요한 결정 + 예산/일정 영향
- 발표자 노트: 각 항목을 30초씩 설명하는 스크립트
```

### 4-3. 오프닝 + 클로징 스크립트

```
이 브리핑의 오프닝(30초)과 클로징(30초) 발표 스크립트 작성.

오프닝:
- 배경: 월례 임원 브리핑, 아침 9시 시작
- 포함: 간단한 인사, 오늘 브리핑 목적, 주목할 포인트 1개
- 톤: 자신감 있고 간결하게

클로징:
- 포함: 핵심 요청 사항 한 번 더 강조 + Q&A 안내
- 톤: 명확하고 신뢰감 있게
```

## 파트 5. 정기 회의 일정 조율 이메일 (10분)

다음 달 월간 운영 회의 일정을 조율하는 이메일입니다.

### 5-1. 일정 조율 이메일

```
월간 회의 일정 조율 이메일 작성.

수신: 박팀장, 이대리, 최사원 (경영지원팀 전원)
목적: 8월 월간 운영 회의 일정 확인
현재 예정: 8월 28일 (목) 오후 2시
확인 요청: 일정 가능 여부 또는 불가 시 대안 날짜 제안 (8/27~29 중)
회의 소요 시간: 약 1시간
장소: 6층 소회의실 B (또는 화상)

톤: 가볍고 협조적으로
길이: 4문장 이내
```

### 5-2. 일정 확정 안내 (조율 완료 후)

조율이 완료됐다고 가정하고 확정 안내 이메일도 미리 만들어둡니다:

```
회의 일정 확정 안내 이메일 작성.

수신: 경영지원팀 전원 + 참석 임원 (김상무)
확정 내용: 8월 28일 (목) 오후 2시, 6층 소회의실 B
참석자: 김상무, 박팀장, 이대리, 최사원, 홍길동
사전 준비 사항: 7월 업무 완료 현황 간단 정리 (양식 없음)
캘린더 초대 안내: 별도 발송 예정

톤: 간결하고 명확하게
길이: 3~4문장
```

## 2일 과정 수료 확인

캡스톤까지 완성했다면 아래 체크리스트를 확인해보세요.

### Day 1 습득 기술

- [ ] Copilot으로 이메일 초안을 2분 안에 만든다
- [ ] 톤 조정 (정중/친근/단호)을 후속 프롬프트로 할 수 있다
- [ ] 영어 이메일을 한국어로 먼저 쓰고 번역을 요청할 수 있다
- [ ] 엑셀 수식 SUMIFS, COUNTIFS를 Copilot으로 생성할 수 있다
- [ ] 주간 보고를 이메일 + 슬랙 메시지 + 엑셀 수식으로 만들 수 있다

### Day 2 습득 기술

- [ ] 러프한 회의 노트를 정식 회의록으로 10분 안에 변환할 수 있다
- [ ] 액션 아이템을 담당자/마감일 표로 자동 추출할 수 있다
- [ ] PPT 목차를 30초 안에 생성하고 슬라이드 초안을 만들 수 있다
- [ ] PowerShell 파일 정리 스크립트를 Copilot으로 생성하고 실행할 수 있다
- [ ] 월간 부서 운영 자동화 패키지를 혼자 완성할 수 있다

---

## 앞으로의 활용 방향

### 이번 주 바로 써볼 것 (쉬운 것부터)

1. 내일 보내야 하는 이메일을 Copilot으로 초안 작성
2. 가장 최근 회의의 노트를 Copilot으로 회의록 변환
3. 다운로드 폴더 정리 스크립트 실행

### 이번 달 안에 만들어둘 것

1. 자주 쓰는 이메일 5종 템플릿 파일 (재사용용)
2. 다음 달 월간 보고 패키지 템플릿
3. 부서 업무별 표준 회의록 템플릿

### 한 달 후 목표

Copilot 없이 하던 반복 업무 시간의 50% 이상을 절약하고, 그 시간을 더 가치 있는 일에 쓰고 있음을 스스로 느끼는 것.

---

## 핵심 포인트

1. 월간 업무 패키지는 한 번 만들면 **매월 재사용 가능한 템플릿**이 된다
2. 이 과정에서 배운 이메일 + 회의록 + PPT + 파일 자동화는 **서로 연결된 하나의 워크플로우**다
3. Copilot은 초안 생성기, **사실 관계 검증과 최종 판단은 항상 내 몫**
4. 완벽한 프롬프트보다 **빠른 초안 + 반복 개선**이 더 빠르다
5. 오늘 배운 것을 내일 한 번이라도 실제 업무에 써보는 것이 가장 중요하다
