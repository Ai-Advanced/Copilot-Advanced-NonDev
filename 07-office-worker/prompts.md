## 📬 1. 이메일 작성

### 1-1. 요청 이메일 (정중)

```
아래 상황에 맞는 요청 이메일 초안 작성.

수신: [수신자 이름/직책]
목적: [무엇을 요청하는가]
배경: [왜 필요한가 한 문장]
마감: [언제까지 필요한가]
톤: 정중하고 간결하게, 과하지 않게
길이: 5~7문장
서명: [보내는 사람 이름] / [부서명]
```

### 1-2. 요청 이메일 (단호)

```
아래 상황에 맞는 요청 이메일 초안 작성.

수신: [수신자]
목적: [요청 내용]
상황: [이전에 요청했으나 응답 없음 / 긴급 상황]
톤: 단호하고 명확하게, 무례하지 않게
포함: 구체적 마감일, 미이행 시 다음 단계 안내
길이: 4~6문장
```

### 1-3. 알림/공지 이메일

```
부서 전체 공지 이메일 작성.

공지 내용: [무엇을 알릴 것인가]
대상: [부서명 또는 전직원]
일시: [언제]
장소/링크: [어디서]
참고 사항: [유의할 점]
톤: 명확하고 친근하게
형식: 제목 → 본문 → 문의처
```

### 1-4. 회신 이메일 (긍정)

```
아래 이메일에 긍정적으로 회신하는 초안 작성.

원본 요청 내용: [요청 요약]
내 답변: [수락 / 확인 완료 / 진행 예정]
추가 전달 사항: [있으면 기재]
톤: 협조적이고 따뜻하게
길이: 3~5문장
```

### 1-5. 회신 이메일 (거절 · 완곡)

```
아래 요청을 정중하게 거절하는 이메일 초안 작성.

요청 내용: [무엇을 요청받았는가]
거절 사유: [이유 한 줄]
대안 제시: [가능하면 대안 포함, 없으면 "없음"으로 표시]
톤: 유감스럽지만 단호하게, 관계 유지에 신경 써서
길이: 5문장 이내
```

### 1-6. 사과 이메일

```
사과 이메일 초안 작성.

상황: [무슨 일이 있었는가]
잘못된 부분: [구체적으로]
조치 내용: [이미 했거나 할 것]
재발 방지: [한 문장]
톤: 진심 어리게, 변명 없이
길이: 6~8문장
```

### 1-7. 감사 이메일

```
감사 이메일 초안 작성.

대상: [누구에게]
감사 이유: [무엇에 대해]
구체적 도움이 된 점: [어떻게 도움이 됐는지]
톤: 진심을 담아, 과하지 않게
길이: 4~5문장
```

### 1-8. 축하 이메일

```
[승진/수상/입사/결혼/출산] 축하 이메일 초안 작성.

수신자: [이름]
축하 내용: [구체적 사유]
톤: 따뜻하고 진심 어리게
길이: 3~4문장
한국어, 격식체 유지
```

### 1-9. 조의 이메일

```
조의 이메일 초안 작성 (가족상 또는 동료 부고).

수신자: [이름/직책]
관계: [발신자와의 관계]
톤: 절제되고 진심 어리게, 불필요한 미사여구 없이
길이: 4~5문장
한국어, 격식체
```

### 1-10. 영문 이메일 (요청)

```
Write a professional request email in English.

To: [name/title]
Purpose: [what you are requesting]
Background: [one-sentence context]
Deadline: [when you need it by]
Tone: polite, concise, not overly formal
Length: 5~7 sentences
Sign-off: Best regards, [name] / [department]
```

### 1-11. 영문 이메일 (사과)

```
Write a professional apology email in English.

Situation: [what happened]
What went wrong: [specific issue]
Action taken: [what has been done or will be done]
Tone: sincere, no excuses, solution-focused
Length: 6~8 sentences
```

### 1-12. 이메일 톤 조정 (더 정중하게)

```
아래 이메일 초안을 더 정중하고 격식 있게 다시 써줘.
의미와 내용은 그대로 유지하고 톤만 조정.

[--- 원본 ---]
(이메일 붙여넣기)
[--- 끝 ---]
```

### 1-13. 이메일 톤 조정 (더 간결하게)

```
아래 이메일을 핵심만 남기고 절반 길이로 줄여줘.
정중함은 유지하되 불필요한 수식어·반복 제거.

[--- 원본 ---]
(이메일 붙여넣기)
[--- 끝 ---]
```

### 1-14. 이메일 요약 (수신함 정리용)

```
아래 이메일 내용을 3줄로 요약해줘.
형식:
- 핵심 요청/내용:
- 필요한 내 액션:
- 마감일 (있는 경우):

[--- 이메일 ---]
(붙여넣기)
[--- 끝 ---]
```

## 📋 2. 회의 준비 · 회의록

### 2-1. 회의 안건 작성

```
아래 내용을 바탕으로 회의 안건(Agenda) 문서 작성.

회의 제목: [회의명]
일시: [날짜 시간]
참석자: [이름 목록]
목적: [이 회의로 결정해야 할 것]
안건:
1. [항목1]
2. [항목2]
3. [항목3]

각 안건에 예상 소요 시간과 발표자 표시.
형식: Markdown 표 또는 번호 목록.
```

### 2-2. 회의록 요약 (노트 → 정리본)

```
아래 회의 노트를 정식 회의록으로 정리해줘.

형식:
- 회의 개요 (일시/장소/참석자)
- 안건별 논의 내용 (2~3줄)
- 결정 사항 (굵게 표시)
- 액션 아이템 (담당자 / 마감일 표 형태)
- 다음 회의 예정

[--- 회의 노트 ---]
(붙여넣기)
[--- 끝 ---]
```

### 2-3. 액션 아이템 추출

```
아래 회의록에서 액션 아이템만 추출해서 표로 정리해줘.

표 열: 번호 | 액션 내용 | 담당자 | 마감일 | 상태(미완료)

[--- 회의록 ---]
(붙여넣기)
[--- 끝 ---]
```

### 2-4. 회의 초대 이메일

```
회의 초대 이메일 초안 작성.

회의 목적: [한 줄 설명]
일시: [날짜 시간]
장소/링크: [오프라인 장소 또는 화상회의 링크]
예상 소요: [분]
사전 준비 사항: [있으면 기재]
톤: 명확하고 간결하게
```

### 2-5. 회의 결과 공유 메시지 (슬랙/팀즈)

```
아래 회의 결과를 슬랙/팀즈 채널에 공유할 짧은 메시지로 작성.

분량: 10줄 이내
형식: 이모지 적절히 사용, 불릿 포인트, 핵심만
포함: 주요 결정 사항 + 각자 액션 아이템

[--- 회의 결과 요약 ---]
(붙여넣기)
[--- 끝 ---]
```

## 📊 3. 보고서 · 문서 작성

### 3-1. 주간 업무 보고서

```
주간 업무 보고서 Markdown 초안 작성.

보고 기간: [날짜 범위]
보고자: [이름/부서]

구조:
1. 이번 주 완료 업무 (불릿, 3~5개)
2. 진행 중 업무 (불릿, 완료 예정일 포함)
3. 다음 주 예정 업무 (불릿)
4. 이슈/리스크 (있으면)
5. 지원 요청 사항 (있으면)

톤: 간결하고 사실 위주
```

### 3-2. 월간 부서 운영 보고

```
월간 부서 운영 보고서 목차 및 각 섹션 초안 작성.

부서: [부서명]
보고 월: [YYYY년 MM월]
수신: [임원/상위 부서]

섹션:
1. 이달의 주요 성과 (3개 하이라이트)
2. 진행 중인 프로젝트 현황 (표: 프로젝트명 / 진도율 / 이슈)
3. 인원/자원 현황
4. 다음 달 주요 일정
5. 건의/요청 사항

형식: Markdown, 임원 보고용으로 간결하게
```

### 3-3. 행사/이벤트 기획안 초안

```
아래 조건으로 행사 기획안 초안 작성.

행사명: [이름]
목적: [왜 하는가]
대상: [참석 대상]
일시: [날짜 시간]
예산: [규모]

포함 항목:
- 행사 개요 (목적/기대효과)
- 진행 순서 (타임테이블)
- 필요 준비물/장비 체크리스트
- 담당자별 역할 분담표
- 예산 배분 (개략)
```

### 3-4. 절차 매뉴얼 작성

```
아래 업무의 표준 절차 매뉴얼(SOP) 작성.

업무명: [업무 이름]
대상 독자: 신입 직원
형식: 번호 단계별 절차, 각 단계에 주의사항 포함
수준: 처음 하는 사람도 혼자 할 수 있도록

업무 개요:
[업무에 대해 간단히 설명]
```

### 3-5. 데이터 표/리스트 → 보고서 문단

```
아래 데이터 표를 임원 보고용 서술형 문단으로 변환해줘.

톤: 간결하고 객관적으로
길이: 3~5문장
강조: 가장 중요한 수치 2~3개

[--- 표 데이터 ---]
(붙여넣기)
[--- 끝 ---]
```

## 📅 4. 일정 · 조율

### 4-1. 일정 조율 이메일

```
일정 조율 요청 이메일 초안 작성.

목적: [무슨 미팅/행사]
대상: [상대방]
제안 시간대: [후보 3개 (날짜+시간)]
소요 시간: [분]
장소/방식: [오프라인/온라인]
톤: 정중하고 유연하게
```

### 4-2. 일정 확정 안내

```
일정이 확정되었음을 알리는 짧은 이메일 작성.

확정 내용: [날짜, 시간, 장소/링크]
참석 대상: [이름들]
사전 준비 사항: [있으면]
톤: 간결하고 명확하게
길이: 3~4문장
```

### 4-3. 일정 변경 요청

```
기존 일정 변경을 정중하게 요청하는 이메일 작성.

기존 일정: [날짜 시간]
변경 이유: [간단히]
대안 제시: [새로운 후보 2~3개]
톤: 불편을 드려 죄송하다는 뉘앙스 포함, 정중하게
```

### 4-4. 월간 일정표 초안 (Markdown)

```
아래 일정들을 Markdown 월간 일정표로 정리해줘.

월: [YYYY년 MM월]
일정 목록:
[날짜별로 나열]

형식: 날짜 | 요일 | 내용 | 담당자 | 비고 5열 표
빈 날도 줄로 표시
```

### 4-5. 연간 행사 캘린더 초안

```
부서 연간 행사 캘린더 초안 작성.

부서: [부서명]
연도: [YYYY]

정기 행사 포함:
- [행사1]
- [행사2]
- [행사3]

형식: 월별 섹션으로 나누고 각 행사에 예상 날짜/목적/담당자 포함
```

## 📁 5. 파일 · 폴더 관리

### 5-1. 파일 이름 일괄 변경 스크립트

```
Windows PowerShell 스크립트 작성.

목적: [폴더 경로]의 [확장자] 파일들을 일괄 이름 변경
변경 규칙: [예: YYYYMMDD_원본파일명 / 부서명_날짜_제목]
예외: 이미 규칙에 맞는 파일은 건너뜀
실행 전 미리보기 기능 포함 (dry-run 옵션)
상단 주석: 사용법 3줄
```

### 5-2. 파일 확장자별 분류 스크립트

```
Windows PowerShell 스크립트 작성.

목적: [폴더 경로] 안의 파일들을 확장자별 하위 폴더로 이동
분류 규칙:
- 이미지: jpg, jpeg, png, gif, bmp → Images 폴더
- 문서: pdf, docx, doc, pptx, xlsx → Documents 폴더
- 영상: mp4, mov, avi → Videos 폴더
- 나머지: Others 폴더
중복 파일명 처리: 번호 붙이기 (예: 파일(1).pdf)
```

### 5-3. 오래된 파일 보관 스크립트

```
Windows PowerShell 스크립트 작성.

목적: [원본 폴더]에서 [N]일 이상 된 파일을 [보관 폴더]로 이동
날짜 기준: 파일 수정일
이동 후 원본은 삭제하지 말 것 (이동만)
로그 파일 생성: 이동된 파일 목록 + 날짜 기록
```

### 5-4. 폴더 백업 스크립트

```
Windows PowerShell 스크립트 작성.

목적: [원본 폴더]를 [백업 폴더]에 날짜 포함 이름으로 복사
백업 폴더명: YYYYMMDD_backup
기존 백업 보존 (덮어쓰지 않음)
백업 완료 후 콘솔에 완료 메시지 출력
```

### 5-5. 중복 파일 탐지 스크립트

```
Windows PowerShell 스크립트 작성.

목적: [폴더 경로] 안에서 동일한 파일명을 가진 파일 찾기
출력: 파일명, 위치 경로, 크기를 CSV 파일로 내보내기
삭제는 하지 말 것 — 탐지 및 보고만
```

## 📑 6. PPT · 발표 자료

### 6-1. PPT 목차 생성

```
아래 발표 주제의 PPT 목차 작성.

주제: [발표 주제]
발표 시간: [분]
청중: [누구에게]
목적: [설득/보고/교육/공유 중 택1]

형식:
- 슬라이드 번호와 제목
- 각 슬라이드에 들어갈 핵심 내용 2~3줄 요약
- 표지/목차/마무리 슬라이드 포함
총 슬라이드 수: [N장] 내외
```

### 6-2. 슬라이드 상세 초안

```
아래 슬라이드의 상세 내용 초안 작성.

슬라이드 제목: [제목]
핵심 메시지: [이 슬라이드에서 전달할 한 가지]
```

### 좋은 프롬프트 체크리스트

- [ ] 누구에게 (수신자/독자)를 명시했나?
- [ ] 무엇을 원하는지 (목적) 구체적인가?
- [ ] 어떤 형식 (표/불릿/문단/이메일)인지 명시했나?
- [ ] 얼마나 길게 (줄 수/단어 수) 원하는지 밝혔나?
- [ ] 어떤 톤 (정중/친근/단호)인지 포함했나?
