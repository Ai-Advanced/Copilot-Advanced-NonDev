## 차트 스펙

### CHART-001. KPI 카드 패널

| 항목 | 내용 |
|------|------|
| **차트 유형** | KPI 카드 (숫자 + 변화율) |
| **목적** | "이번 달 핵심 지표를 한눈에 파악하고 싶다" |
| **위치** | 상단 전체 너비 |
| **카드 개수** | 4개 |

**카드별 상세**:

| 카드 | 지표명 | 계산 공식 | 비교 기준 | 단위 |
|------|--------|---------|---------|------|
| 1 | 신규 가입자 | COUNT(DISTINCT user_id) WHERE event_type='subscribe' | 전월 동기 | 명 |
| 2 | MRR | SUM(mrr) WHERE event_type IN ('subscribe','upgrade','downgrade') | 전월 | USD |
| 3 | 30일 리텐션 | 가입 후 30일 이내 재활동 / 코호트 크기 | 전월 코호트 | % |
| 4 | 이탈률 | cancel user / 월초 활성 구독자 × 100 | 전월 | % |

**색상 규칙**:
- 신규 가입, MRR, 리텐션: 전월 대비 상승 → 초록, 하락 → 빨강
- 이탈률: 전월 대비 상승 → 빨강, 하락 → 초록 (반전)

### CHART-002. MRR 월별 트렌드

| 항목 | 내용 |
|------|------|
| **차트 유형** | 라인 차트 (시계열) |
| **목적** | "MRR이 어떻게 성장하고 있는가?" |
| **데이터 소스** | subscriptions |
| **X축** | year_month (월별, DATE_TRUNC('month', event_date)) |
| **Y축** | MRR 합계 (USD, $표기) |
| **집계** | SUM(mrr) per month, 최신 active event 기준 |
| **시간 범위** | 최근 12개월 (전역 필터 연동) |
| **보조선** | 목표 MRR 선 (별도 파라미터 입력) |
| **호버** | 월, MRR, 전월 대비 증감율 |
| **드릴다운** | 클릭 시 해당 월 MRR 분解 (new/expansion/contraction/churn) |
| **업데이트 주기** | 일별 |

**SQL 기반**:
```sql
SELECT DATE_TRUNC('month', event_date)::DATE AS year_month,
       SUM(mrr) AS mrr
FROM subscriptions
WHERE event_type IN ('subscribe', 'upgrade', 'downgrade')
  AND event_date >= {{start_date}}
GROUP BY DATE_TRUNC('month', event_date)
ORDER BY year_month;
```
