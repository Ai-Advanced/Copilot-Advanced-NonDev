# 강사용 준비·운영 안내

[수강생 과정](README.md) · [서버 앱 선택 심화](server-app.md)

## 수업 전에 확정할 것

교육 추가 시간, 참가 인원, 허용 리전, 계정 제공 주체, 공개 허용 범위, 비용 예산, 자원 삭제일을 정합니다.
각 참가자에게 기존 2일 과정 뒤의 배포 확장임을 안내합니다. 실제 Azure 리허설 전에는 제공 시간을 확정하지 않습니다.

## 기본 정적 웹 환경

1. 회사 운영 구독과 분리된 교육 구독을 사용합니다. Azure 리소스 공급자 등록과 조직 정책은 관리자가 사전에 처리합니다.
2. 참가자별 `prefix`와 `rg-copilot-<prefix>` 그룹을 배정합니다. 그룹에 `purpose=copilot-training`, `learner=<prefix>` 태그를 설정합니다.
3. Azure Portal에서 해당 그룹에 `<prefix>-web` **Free Static Web App**을 만듭니다. 배포 원본은 `Other`로 선택하여 불필요한 GitHub 자동 배포를 만들지 않습니다.
4. 참가자는 자신의 사이트 조회와 배포 토큰 조회에 필요한 권한만 받습니다. 구독 Owner 권한이나 역할 할당 권한은 주지 않습니다. 조직에서 승인한 역할·범위를 실제 수강생 계정으로 확인합니다.
5. `lab.example.json`을 복사한 개인 설정을 안내합니다. 토큰은 배포 스크립트가 조회하며 강사가 채팅·문서에 전달하지 않습니다.
6. [완성 예시](examples/books/index.html)를 한 계정으로 끝까지 리허설합니다. 생성·배포·수정·정리 권한을 강사 계정만으로 확인하지 않습니다.

Free 플랜도 구독 내 다른 리소스의 비용을 막아주지 않습니다.
예산 알림은 결제 상한이 아니므로 정책·권한·생성 가능한 자원 종류·정리 일정을 함께 관리합니다.
공개 허용이 안 되는 조직은 별도 인증·접근 제어 환경을 먼저 설계합니다. Free 데모를 사내 서비스로 간주하지 않습니다.

## 운영 체크리스트

- [ ] 참가자별 그룹·사이트·계정 대응표를 비공개로 보관
- [ ] 터미널 로그인, 프록시·방화벽, SWA CLI 설치 확인
- [ ] 업로드 폴더에 가상 데이터만 있는지 확인
- [ ] URL에서 기능 확인과 수정·재배포를 각각 수행
- [ ] 장애 시 완성 예시로 배포 문제와 구현 문제를 분리
- [ ] 보관 요청이 없으면 해당 참가자의 정확한 사이트를 Portal에서 삭제
- [ ] 공유 그룹·리소스를 일괄 삭제하지 않고 비용 발생 자원을 별도로 확인
- [ ] 유출 가능성이 있는 배포 토큰은 재발급하고 관련 로그·파일 점검

## 교육 종료 기록

참가자 식별 코드, 확인한 기능, 배포 버전, 삭제 여부 또는 보관 책임자·종료일을 기록합니다.
실제 참가자의 계정·리소스 식별자·운영 주소는 공개 저장소나 교육 후기 문서에 올리지 않습니다.

## 선택 심화 환경

Python 앱은 별도의 Linux App Service와 교육용 요금제가 필요합니다.
비용 승인을 받은 참가자에게만 제공하고, 정적 웹 과정의 무료 범위와 혼동하지 않도록 합니다.
생성·런타임·시작 명령·배포 권한은 [서버 앱 안내](server-app.md)의 조건으로 사전 준비합니다.

## 실제 Azure 검증 기준선 — 2026-10-07

관리자 계정으로 격리된 임시 리소스를 생성한 뒤 교재의 배포 절차를 검증했습니다.
리소스 생성은 Azure CLI로 수행했으며, Portal의 화면 조작을 검증한 기록은 아닙니다.

| 과정 | 확인한 결과 |
| --- | --- |
| 정적 웹 | East Asia의 Free Static Web App에 `Deploy-Static.ps1`로 배포. 검색·상세·중복 방지·빈 결과·새로고침 초기화·4개 화면 너비 확인 |
| Python 선택 심화 | Korea Central의 Linux App Service B1/Python 3.12에 두 파일 ZIP 배포. 합계 250, 부서별 120/80/50, 잘못된 입력 400·없는 경로 404·POST 405 확인 |
| 수정·재배포 | 두 앱 모두 별도 학습자 사본을 `lab-v1` → `lab-v2`로 수정하여 재배포하고 실제 HTTPS URL에서 기능 재확인 |
| 정리 | 검증용 사이트·앱·전용 Plan과 두 리소스 그룹의 삭제 완료 확인 |

학생 최소 권한 계정, 참가자별 PC·프록시, 동시 수강 규모, 다른 구독의 정책·할당량은 별도 리허설 대상입니다.
당일 비용 조회에 청구 행이 없었지만 집계 지연이 있으므로 **실제 비용 0원으로 해석하지 않습니다.**
실제 계정·리소스 이름·접속 주소·배포 토큰은 이 기록에 포함하지 않습니다.
