어떻게 배우나요?

1

공통 기초 약 1시간

모든 직군 필수 선행. Copilot 개요, VS Code 설치, 기본 사용법(Tab·Chat·Inline), 프롬프트 3S 원칙, 비개발자가 만나는 파일 형식 5가지.

FAQ

자주 묻는 질문

더 궁금한 점은 Repo Issue로 남겨주세요.

Q. GitHub Copilot과 ChatGPT, 뭐가 달라요?

둘 다 AI지만 동작하는 위치가 다릅니다. ChatGPT는 브라우저에서 대화창을 통해 쓰고, Copilot은 VS Code 같은 편집기 내부에서 지금 열어놓은 파일의 맥락을 이해하며 동작합니다. 그래서 "지금 이 파일에" 바로 붙일 수 있는 결과가 나옵니다. 결정적으로 다른 지점이 이 맥락 이해입니다.

Q. 우리 회사가 GitHub 안 쓰는데 배울 가치가 있나요?

네. Copilot 라이선스는 회사 GitHub 사용과 무관하게 개인·조직 단위로 구매할 수 있습니다. 사내 코드 저장소가 GitLab이든 Bitbucket이든 사내 서버든 상관없이, VS Code로 파일을 여는 그 순간부터 Copilot이 동작합니다. 엑셀·워드 문서, 사내 위키, SQL 쿼리 정도만 다뤄도 학습한 것의 80%는 그대로 씁니다.

Q. AI가 만든 결과를 그대로 써도 되나요?

절대 안 됩니다. AI는 그럴듯한 거짓말(hallucination)을 합니다 — 존재하지 않는 함수, 잘못된 통계 수치, 오래된 API를 자신 있게 제안하기도 합니다. 이 커리큘럼은 처음부터 끝까지 "AI는 초안, 검증은 사람" 원칙을 관통합니다. 결과를 실행해보고, 숫자를 대조하고, 공식 문서와 비교하는 습관 자체를 함께 훈련합니다.

Q. Copilot Individual · Business · Enterprise 중 뭐가 필요한가요?

이 커리큘럼의 모든 실습은 Individual($10/월) 하나면 100% 가능합니다. 회사에서 이미 Business·Enterprise 라이선스를 받고 있다면 그것을 그대로 쓰세요 — 기능은 상위 호환이라 문제없습니다. 데이터 유출 정책이 엄격한 조직은 Business 이상을 권장합니다 (프롬프트가 학습에 사용되지 않음).

Q. 강사 없이 혼자 할 수 있나요?

네. 이 커리큘럼은 혼자 학습 · 팀 워크숍 · 팀 스터디 세 가지 방식 모두를 상정하고 만들어졌습니다. 혼자라면 하루 3~4시간 × 2일. 각 챕터 끝의 실습은 반드시 직접 수행하세요 — 눈으로 읽기만 해서는 손에 남지 않습니다. 캡스톤 프로젝트가 그 검증대입니다.

Q. 우리 팀에 워크숍 방식으로 진행하고 싶은데요?

권장 구성: 강사 1명 + 참가자 10~15명, 1일 통합 또는 2일 분산. 각 직군 폴더의 prompts.md(치트시트)와 resources/templates/가 워크숍용 실습 자료로 그대로 쓰입니다. 매주 1챕터씩 4~6주에 걸쳐 스터디로 완주하는 방식도 잘 맞습니다. 라이선스는 MIT — 사내 자유 사용 가능합니다.
